# FAST カルテテンプレ

> **方針**：ER は **コンパクト優先**。所見（O）だけを書き、解釈は **アセスメント（A）** へ。
> FAST は繰り返す検査なので、**時刻と何回目か** を必ず書く。

- 対象：外傷初療の FAST / E-FAST
- 更新日：2026-10-25

---

## 1. テンプレ（コピペ用）

```
【FAST】（　:　、　回目）
心嚢 −/＋　モリソン −/＋　脾周囲 −/＋　膀胱直腸窩 −/＋
胸腔 右 −/＋ 左 −/＋　lung sliding 右 有/無 左 有/無
→ 陰性 / 陽性（　）
```

---

## 2. 記載例

**陰性**
```
O：FAST（10:15、1回目）心嚢− モリソン− 脾周囲− 膀胱直腸窩− 胸腔 右−左− sliding 両側あり → 陰性
```

**陽性**
```
O：FAST（10:40、2回目）モリソン＋、他−、sliding 両側あり → 陽性（モリソン）。1回目は陰性。
A：腹腔内出血 → 循環不安定なら止血術（手術・IVR）を考慮。
```

---

## 3. 注意

- 描出不良は「−」ではなく **「描出不良」** と書く
- 陰性でも出血は否定できない → 循環が変わったとき・時間をおいて **再検**
- 後腹膜・骨盤の出血は FAST では見えない
- 胸腔＋は血胸、lung sliding 無は気胸を疑う（E-FAST）
- FAST は液体の有無だけを見る。**腹水でも陽性** → O は陽性のまま書き、A で出血と鑑別
  - 出血を疑う：再検で増える、内部エコーあり（血餅）、CT 値 ≥30HU（腹水は 0–20HU）
  - 不安定で区別がつかなければ診断的腹腔穿刺
- 若い女性の骨盤内の少量液体は生理的なこともある
