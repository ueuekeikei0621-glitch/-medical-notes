# 外傷と心停止が重なるとき（どっちのルールで動く？）

> [!IMPORTANT]
> 決め手は **「心停止が先か、けがが先か」**。
> - **心停止が先**（倒れて頭を打った）→ **ICLS** で動く ＋ 頸椎に気をつける
> - **けがが先**（けがのせいで心臓が止まった）→ **外傷性心停止の流れ**（原因の治療を圧迫より優先）
> - **わからない** → ICLS を回しながら、外傷の原因も同時に探す

---

## 1. 見分け方

| 手がかり | 心停止が先（内因性） | けがが先（外傷性心停止） |
|---|---|---|
| 受傷機転 | **立った高さから転倒**・倒れて頭を打った | **高エネルギー**（交通事故・高所墜落・刺創） |
| 倒れる前 | 胸痛・動悸・失神・目撃者が「急に倒れた」 | けがの直後から悪くなった |
| けがの重さ | 軽い（頭の切り傷・こぶ） | 重い（胸・腹・骨盤・大量出血） |
| 初期波形 | **VF** が多い | **PEA**（心静止）が多い |

- 例：**運転中に意識を失って事故** → 心停止（内因性）が先のことがある
- 例：**階段から落ちて胸を強く打った** → けがが先

---

## 2. 心停止が先 → ICLS ＋ 頸椎への配慮

- 流れは **ICLS のまま**（圧迫・2 分ごとの波形・ショック・アドレナリン）
- **頸椎のけがが疑わしければ**：
  - 気道は **下顎挙上**（頭を後ろに倒さない）
  - 開かなければ **頭部後屈・あご先挙上**（**気道が優先**。AHA の考え方）
  - 挿管は **MILS**（もう 1 人が頭を両手で押さえる）
- 頸椎を気にして **圧迫や換気を遅らせない**

---

## 3. けがが先 → 外傷性心停止の流れ

**原因の治療を、胸骨圧迫より優先する**（英国蘇生協議会 2025）。ERC は「原因を **同時に** 取り除く」。

| 原因 | すること |
|---|---|
| **大量出血** | 圧迫止血・止血帯・骨盤固定・**輸血** |
| **気道・低酸素** | 気道確保・酸素 |
| **緊張性気胸** | **両側の胸の減圧**（脱気・開胸減圧） |
| **心タンポナーデ** | 心嚢穿刺・開胸（蘇生的開胸） |

- 圧迫・ショック（VF なら）・薬も回すが、**原因の治療を遅らせない**
- アドレナリンは内因性の心停止ほど役に立たない（出血で中身が空のため）
- JATEC の考え方（**TAF3X・大量出血・FAST**）がそのまま原因探しに使える
- 外傷チーム・外科・救急科の上級医が指揮する

---

## 4. わからないとき

- **ICLS を回しながら**、外傷の原因を同時に探す：**E-FAST**（心嚢液・気胸・腹腔内出血）・外出血・骨盤
- 見つかった原因はすぐ治す
