# 外傷初療 Primary Survey（ABCDE）実践ノート

> **方針**：Primary survey は **「見つけたら、その場で治す」**。A に問題があるうちは B に進まない。
> 全部を完璧に見るより、**各文字の「まずこれだけ」** を確実にやる。状態が変わったら **A に戻る**。
> FAST の書き方は [FAST テンプレ](fast-karte-template.md) へ。

- 対象：外傷初療（JATEC の Primary survey）
- 更新日：2026-11-13

---

## 0. 全体の流れ

```
到着前の準備 → 第一印象（15秒）→ A → B → C → D → E → 再評価 → 二次評価（Secondary survey）
```

| 文字 | 合言葉 | まずこれだけ | 探している「すぐ死ぬ」病態 |
|---|---|---|---|
| A | 喋れる？ 音は？ | 声・異常音・口の中 | 気道閉塞 |
| B | 見て・聴いて・触って | 呼吸数・SpO2・呼吸音の左右差・頸静脈・皮下気腫 | 緊張性気胸・開放性気胸・フレイルチェスト・大量血胸 |
| C | **SHOCK** で見つけて **FIX-C** で動く | 皮膚・脈・外出血 → FAST・ルート・X 線・止血 | 出血性ショック・心タンポナーデ |
| D | **まいど** | 麻痺・意識（GCS）・瞳孔 | 切迫するD（脳ヘルニア） |
| E | 脱がせて温める | 全部脱がせる・体温・保温 | 低体温 |

---

## 1. 到着前の準備

- 感染防御：手袋・ガウン・ゴーグル・マスク
- 酸素（リザーバーマスク）・吸引・モニター
- 加温した輸液（細胞外液）・太い留置針
- エコーの電源を入れておく（**電源ボタンは本体の裏**）
- 挿管の準備、ポータブル X 線を呼んでおく
- 役割分担：リーダー・頭側（A 担当）・ルート・記録

---

## 2. 第一印象（最初の 15 秒）

患者に触れながら **ABCDE をざっと** 見る。詳しく見るのはこの後。

| すること | わかること |
|---|---|
| 「わかりますか？ お名前は？」と呼びかける | 返事ができる → A は開通、D もある程度保たれている |
| 胸の動き・呼吸の速さを見る | B（速い・浅い・苦しそう） |
| 橈骨動脈を触る＋手の皮膚を触る | C（脈が速い・弱い、皮膚が冷たい・湿っている） |
| 全身をパッと見る | 大きな外出血・変形 |

- 声に出してチームに伝える。例：「**気道 OK、呼吸速い、ショックあり、意識やや悪い**」
- 重症なら **すぐ応援を呼ぶ**

---

## 3. A：Airway（気道）＋頸椎保護

**合言葉：喋れる？ 音は鳴ってる？**

1. 呼びかけて **喋れるか** を見る（普通の声で話せれば、とりあえず気道 OK）
2. **異常な音** を聴く

| 音 | 考えること |
|---|---|
| いびきのような音 | 舌根沈下 |
| ゴロゴロ | 血液・吐物・分泌物 |
| ヒューヒュー（吸うときに鳴る、stridor） | 上気道が狭い（腫れ・異物） |
| 声がかすれる・こもる | 気道熱傷・喉頭の損傷・腫れ |

3. **口の中** を見る：血液・吐物・折れた歯・異物
4. 顔の熱傷・すす・鼻毛の焦げ → **気道熱傷**（あとで急に腫れて詰まる → 早めに挿管）

**頸椎保護は A と同時に**：1 人が頭を両手で固定（用手的正中中間位）、またはネックカラー。

**異常があったら（上から順に）**
1. 吸引
2. **下顎挙上**（頸椎を守るため、頭を反らせる「頭部後屈あご先挙上」はしない）
3. エアウェイ
4. 気管挿管（確実な気道確保）
5. 挿管できない → 輪状甲状靱帯切開

**挿管（確実な気道確保）を考えるとき**
- A の異常が治らない
- B が悪い（酸素化・換気が保てない）
- 重症のショック
- 切迫するD（GCS 8 点以下など）

報告例：「**A OK、頸椎保護中**」／「A いびき様 → 下顎挙上で改善」

---

## 4. B：Breathing（呼吸）

**合言葉：見て・聴いて・触って（＋ 呼吸数と SpO2）**

最初に全員 **リザーバーマスクで酸素 10 L/分以上**。

| 順 | すること | 見るもの | 異常なら |
|---|---|---|---|
| 1 | 数える | **呼吸数**・**SpO2** | 頻呼吸・低酸素 |
| 2 | 見る | 胸郭の動きの **左右差**・胸の一部が逆に動く（奇異呼吸）・胸の傷・**頸静脈怒張** | 気胸・フレイルチェスト・開放性気胸 |
| 3 | 聴く | **呼吸音の左右差**（左右の腋窩で、左 → 右 → 左 と比べる） | 片側が弱い → 気胸か血胸 |
| 4 | 触る | **皮下気腫**（握雪感：雪を握るようなプチプチ）・圧痛・胸の動揺・**気管の偏位** | 気胸・肋骨骨折 |
| 5 | 叩く（余裕があれば） | 打診 | 鼓音 → 気胸、濁音 → 血胸 |

エコー（E-FAST）：lung sliding がない → 気胸、胸腔に液体 → 血胸。

**B で絶対に見逃したくないもの**

| 病態 | サイン | すぐやること |
|---|---|---|
| **緊張性気胸** | 片側の呼吸音↓ ＋ 頸静脈怒張 ＋ 皮下気腫 ＋ 気管が反対側へ偏位 ＋ ショック | **X 線を待たない**。緊急脱気（穿刺）→ 胸腔ドレナージ |
| 開放性気胸 | 胸の傷から空気が出入りする（吸い込む音） | 3 辺テーピング → 胸腔ドレナージ |
| フレイルチェスト | 胸の一部が呼吸と逆に動く | 酸素・鎮痛、必要なら挿管して陽圧換気 |
| 大量血胸 | 片側の呼吸音↓・打診で濁音・ショック | 胸腔ドレナージ（C の問題として輸血・止血も） |

報告例：「**B 呼吸数 28、SpO2 92%（O2 10L）、右呼吸音減弱、右皮下気腫あり、頸静脈怒張あり → 緊張性気胸疑い**」

---

## 5. C：Circulation（循環）

**合言葉：SHOCK で見つけて、FIX-C で動く**

### 5-1. SHOCK（ショックを見つける）

| 文字 | 意味 | 見るもの |
|---|---|---|
| **S** | Skin（皮膚） | 冷たい・湿っている（冷汗）・青白い |
| **H** | HR（脈） | 速い・弱い |
| **O** | Outer bleeding（外出血） | 体の外への活動性の出血 |
| **C** | CRT・Consciousness（意識） | 爪を 5 秒押して離し、色が戻るまで **2 秒より長い**／意識がおかしい |
| **K** | Ketsuatsu（血圧） | 血圧が低い |

- **1 つでもあればショックと考えて動く**
- **血圧は最後に下がる**。血圧が普通でも、皮膚と脈がおかしければショック
- 外傷のショックは **まず出血** と考える

### 5-2. FIX-C（ショックに対して動く）

| 文字 | 意味 | すること |
|---|---|---|
| **F** | FAST | 心嚢・モリソン窩・脾周囲・膀胱直腸窩 ＋ 左右の胸腔。陰性でも **時間をおいて再検** |
| **I** | IV（静脈路） | 太い針で **2 本**、採血（血液型・クロスマッチも）。加温した細胞外液を **成人 1 L（小児 20 mL/kg）** 急いで入れて反応を見る。取れなければ骨髄路 |
| **X** | X-ray | **胸部** と **骨盤** のポータブル X 線 |
| **C** | Compression（止血） | 外出血は **圧迫**（四肢で止まらなければターニケット）、骨盤骨折は **シーツで巻く**／骨盤バインダー。最後は手術・IVR |

### 5-3. 出血源は「MAP」で探す

| 出血源 | 何で見る |
|---|---|
| **M**assive hemothorax（大量血胸） | 胸部 X 線・E-FAST |
| **A**bdomen（腹腔内出血） | FAST |
| **P**elvis（骨盤骨折・後腹膜） | 骨盤 X 線（**FAST では見えない**） |

- ほかに：外出血、太ももの骨（大腿骨）の骨折も大きく出血する
- 骨盤は **手で揺らして確かめない**（出血が増える）→ X 線で見る

### 5-4. 出血がないのにショック → 出血以外を考える

| ショック | サイン | すること |
|---|---|---|
| 心タンポナーデ | 頸静脈怒張、FAST で心嚢液 | 心嚢穿刺・心嚢開窓 |
| 緊張性気胸 | B を参照 | 脱気・胸腔ドレナージ |
| 神経原性ショック（脊髄損傷） | **脈が遅い**、皮膚が **温かい** | 輸液、昇圧薬 |

### 5-5. 輸液の反応を見る

| 反応 | 意味 | 次 |
|---|---|---|
| よくなって保てる（responder） | 出血は止まっているかもしれない | 二次評価へ |
| 一度よくなるが、また悪くなる（transient responder） | まだ出血している | **輸血＋止血**（手術・IVR） |
| よくならない（non-responder） | 大量に出血している | **輸血＋すぐ止血**、挿管 |

不安定なら「**入れて、入れて、止めろ**」：挿管して、輸血して、止血する。

報告例：「**C HR 120、BP 92/60、冷汗あり、CRT 3 秒、外出血なし → ショック。FAST モリソン陽性、胸部・骨盤 X 線は異常なし → 腹腔内出血**」

## 6. D：Dysfunction of CNS（中枢神経）

**合言葉：まいど**

| 文字 | 意味 | すること |
|---|---|---|
| **ま** | 麻痺 | 「手を握って」「足を動かして」→ 左右差（片麻痺）はないか |
| **い** | 意識 | **GCS**（下の表） |
| **ど** | 瞳孔 | 大きさ・左右差（**1 mm 以上の差 = 瞳孔不同**）・対光反射 |

**GCS（E ＋ V ＋ M、3〜15 点）**

| 点 | E（開眼） | V（言葉） | M（運動） |
|---|---|---|---|
| 6 | | | 言われたとおりに動かす |
| 5 | | 日時・場所・人がわかる | 痛い所に手を持ってくる |
| 4 | 自分で開けている | 会話が混乱している | 痛みから手足を引く |
| 3 | 呼ぶと開ける | 言葉は出るが会話にならない | 異常な屈曲（除皮質） |
| 2 | 痛みで開ける | 意味のない声だけ | 伸展（除脳） |
| 1 | 開けない | 声が出ない | 動かない |

挿管中は V を「T」と書く。

**切迫するD（どれか 1 つでもあれば）**
- GCS 合計 **8 点以下**
- 経過中に GCS が **2 点以上下がる**
- **脳ヘルニアのサイン**：瞳孔不同・片麻痺・Cushing 現象（血圧が上がって、脈が遅くなる）

→ すること：**挿管**（確実な気道確保）・酸素化と換気・**脳外科をすぐ呼ぶ**。頭部 CT は **ABC が安定してから**（二次評価の最初）。

意識が悪いのは頭のせいとは限らない（低酸素・ショック・低血糖でも悪くなる）→ **先に ABC を整える**。

報告例：「**D GCS E3V4M6 = 13、瞳孔 3/3 mm 対光反射 両側あり、麻痺なし → 切迫するD なし**」

---

## 7. E：Exposure & Environmental control（脱衣と体温管理）

**合言葉：脱がせて、見て、すぐ温める**

1. 服を **全部** 脱がせる（はさみで切る）→ 大きな傷・出血・変形をざっと見る
2. **体温** を測る
3. 見たら **すぐ毛布** をかける。輸液は加温、部屋も暖かく

- なぜ大事か：体が冷えると **血が止まりにくく** なる（低体温・アシドーシス・凝固障害 = 外傷の「死の三徴」）
- 背中は二次評価で log roll（体を丸太のように一緒に横へ向ける）して見る

報告例：「**E 体温 35.8℃、保温開始、左大腿に変形あり**」

---

## 8. Primary survey のあと

- 処置をしたら **もう一度 A から見直す**（再評価）
- 状態が変わったら **いつでも A に戻る**
- ABC が安定 → **二次評価**（頭から足まで・AMPLE 聴取・CT）
- 不安定なまま CT に行かない

```
【Primary survey】（　:　）
第一印象：
A：開通 / 異常（　）→ 処置（　）　頸椎保護 済
B：RR　　SpO2　%（O2　L）　呼吸音 左右差 −/＋　胸郭運動 左右差 −/＋　皮下気腫 −/＋　頸静脈怒張 −/＋　気管偏位 −/＋
C：HR　　BP　/　　冷汗 −/＋　CRT　秒　外出血 −/＋ → ショック −/＋
　 FAST（　回目）−/＋（　）　胸部X線（　）　骨盤X線（　）　ルート　本　輸液　mL → 反応（　）
D：GCS E V M（=　）　瞳孔 右　mm / 左　mm　対光反射 右　左　麻痺 −/＋（　）→ 切迫するD −/＋
E：体温　℃　保温 済　外表（　）
```

**書き方のルール**
- 見ていない所は「−」ではなく **「未」**
- 処置をしたら、**何をして、どう変わったか** を書く（例：下顎挙上でいびき様音 消失）

**記載例（腹腔内出血）**
```
【Primary survey】（14:05）
第一印象：呼びかけに返答あり、頻呼吸、橈骨動脈 速く弱い、冷汗あり
A：開通（発声あり、異常音なし）　頸椎保護 済
B：RR 26　SpO2 95%（O2 10L）　呼吸音 左右差−　胸郭運動 左右差−　皮下気腫−　頸静脈怒張−　気管偏位−
C：HR 124　BP 88/56　冷汗＋　CRT 3秒　外出血− → ショック＋
　 FAST（1回目）モリソン＋　胸部X線 異常なし　骨盤X線 異常なし　ルート 2本　細胞外液 1000mL → 一時改善後に再低下
D：GCS E4V5M6（=15）　瞳孔 3/3mm 対光反射 両側＋　麻痺− → 切迫するD−
E：体温 35.9℃　保温 済　外表 右季肋部に打撲痕
アセスメント：腹腔内出血による出血性ショック（transient responder）→ 輸血開始、外科・IVR にコール。
```
