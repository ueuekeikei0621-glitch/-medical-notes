# 神経診察カルテテンプレ＋解説（病棟）

> **方針**：神経診察は **「どこが壊れているか（局在）」** を決めるためにやる。**「何の病気か（病因）」** は主に病歴（発症の仕方と経過）で決める。
> 所見（O）は **見たまま** 書き、「錐体路徴候」「失調」などの **解釈は まとめ か A** へ。
> 項目が多くて迷ったら **2 章の「3 つの軸」** に戻る。わからない言葉は **12 章の用語集** へ。

- 対象：成人の神経内科入院患者の神経診察。2 回目以降の経過記録は 10 章
- 実例：病棟で書いた神経学的所見（個人情報は削除）を 3 章で 1 行ずつ解説
- めまいの人の神経所見（6D・HINTS）は [めまいテンプレ](vertigo-karte-template.md) の 6 章
- 更新日：2026-11-19

## 1. そもそも神経診察は何のため？

| 目的 | 中身 | 例 |
|---|---|---|
| **① 局在（どこ）** | 中枢か末梢か → どの高さ → 左右どちら | 左片麻痺＋左の中枢性顔面麻痺＋左半側空間無視 → 右大脳半球 |
| ② 病因の手がかり | 所見の **分布** で病気が絞れる | 左右対称・手袋靴下型の感覚低下 → 代謝・中毒性の多発ニューロパチー／上位と下位の運動ニューロン徴候が混在 → ALS |
| ③ 重症度・生活への影響 | 歩けるか・飲み込めるか・転びやすいか | リハビリ・食事形態・転倒対策・退院先 |
| ④ **経過を比べる基準** | 「今の状態」を記録しておく | 脳梗塞の進行、GBS の悪化、治療の効果 |

**病歴で「何」、診察で「どこ」**

| 発症の仕方 | まず考える病因 |
|---|---|
| 突然（秒〜分） | 血管障害（梗塞・出血）・てんかん発作・外傷 |
| 急性（時間〜日） | 感染・炎症・代謝・中毒 |
| 亜急性（日〜週） | 炎症（GBS など）・感染・腫瘍 |
| 慢性進行（月〜年） | 腫瘍（週〜月）・変性疾患（年） |
| 発作性で繰り返す | てんかん・片頭痛・TIA・周期性四肢麻痺 |

- 診察は、病歴から立てた仮説（「ここが悪いはず」）を **確かめる作業**。全項目をやみくもに埋める作業ではない
- ④ のために、**ほかの人が同じ診察をしたら同じ結果になる書き方**（左右・尺度・やり方）をする

## 2. 枠組み：3 つの軸（項目・系統・レベル）

「錐体路・錐体外路・協調運動・脳神経…」が分かりにくいのは、**種類の違う名前が同じ並びに混ざっている** から。

| 軸 | 何の名前か | 例 |
|---|---|---|
| **A. 診察項目**（components） | **何をするか**（手技） | 高次脳機能、脳神経、MMT、反射、感覚、協調運動、起立・歩行 |
| **B. 系統**（system・pathway） | **どの回路が壊れたか** | 錐体路、錐体外路（大脳基底核）、小脳系、感覚系、前庭系、自律神経系 |
| **C. レベル・高位**（level） | **どの高さか**（場所） | 大脳、脳幹、小脳、脊髄、神経根、神経叢、末梢神経、神経筋接合部、筋 |

- 「反射」は A（手技）、「錐体路・錐体外路」は B（回路）、「脳神経」は C に近い（脳幹から出る末梢神経）名前
- 考える順番：**A でとった所見 → B（どの系統の異常か）にまとめる → C（どの高さ・どちら側か）に当てはめる**＝ **局在診断**
- **B と C が交わる所が病巣**。1 か所で説明できなければ、多発病変（多発脳梗塞・MS・転移など）かびまん性の病気を考える
- 多系統萎縮症（MSA）の「系統」はこの B のこと（小脳系・錐体外路系・自律神経系などが一緒に壊れる）

### 2-1. 診察項目（A）は どの系統（B）を見ているか

| 診察項目 | 主に見ている系統 |
|---|---|
| 意識 | 脳幹の網様体・両側の大脳 |
| 高次脳機能 | 大脳皮質とそのネットワーク |
| 脳神経 | 脳神経そのもの＋脳幹の核と伝導路 → **脳幹のどの高さか** を教えてくれる |
| 筋力（MMT） | 錐体路・下位運動ニューロン・神経筋接合部・筋（**筋力低下だけでは どれか決まらない**） |
| 筋トーヌス | 痙縮＝錐体路、固縮＝錐体外路、低下＝小脳・下位運動ニューロン |
| 腱反射・病的反射 | 亢進・病的反射＝錐体路、低下＝下位運動ニューロン・感覚神経 |
| 感覚 | 脊髄視床路（温痛覚）、後索（振動覚・位置覚）、大脳（複合感覚） |
| 協調運動 | 小脳系（＋深部覚・前庭。筋力低下があると判定できない） |
| 起立・歩行 | ほぼ全部の系統の合計 |
| 錐体外路の診察 | 大脳基底核 |

### 2-2. 筋力低下を見たら、最初に UMN か LMN かを分ける

| | 上位運動ニューロン（UMN：錐体路） | 下位運動ニューロン（LMN：前角〜末梢神経） |
|---|---|---|
| 分布 | 片側・まとまって（片麻痺・対麻痺）。典型的には上肢は伸筋、下肢は屈筋が弱い | 髄節・神経・筋ごと |
| 筋萎縮 | ほぼなし（廃用を除く） | あり |
| 線維束性収縮 | なし | あり（特に前角の障害） |
| 筋トーヌス | 痙縮（発症直後は低下） | 低下 |
| 腱反射 | 亢進 | 低下・消失 |
| 病的反射 | 出る（Babinski など） | 出ない |

### 2-3. 脳神経は「脳幹の住所」

- 中脳：III・IV、橋：V・VI・VII・VIII、延髄：IX・X・XI・XII（Rule of 4 の考え方）
- **手足の麻痺＋反対側の脳神経麻痺**（交代性麻痺）→ 脳幹。脳神経が麻痺している側に病巣
- **手足の麻痺＋同じ側の中枢性顔面麻痺・舌の偏り** → 反対側の大脳〜橋上部
- **手足の麻痺だけで、脳神経はすべて正常** → 小さい大脳病変（内包・放線冠）・延髄錐体・頸髄も考える
- だから脳神経は削りにくい（5 章）

### 2-4. ほかの分け方

| 分け方 | 中身 |
|---|---|
| 日本神経学会「神経学的検査チャート」 | 診療報酬の「神経学的検査」の記録用に作られた共通の書式。意識・高次脳機能・脳神経・運動・感覚・反射・協調運動・起立・歩行などを並べた **A 軸の標準** |
| Mayo Clinic Medical Neurosciences | 神経を **系統（縦）× レベル（横）** で整理する教科書。レベルはテント上・後頭蓋窩・脊髄・末梢の 4 つ。上の B × C と同じ考え方 |
| MS の EDSS | **機能系（Functional Systems）** ごとに点数をつける：錐体路・小脳・脳幹・感覚・膀胱直腸・視覚・大脳など。B 軸を点数にしたもの |
| 陰性徴候・陽性徴候（Jackson） | 陰性＝本来の働きがなくなる（麻痺・感覚低下）、陽性＝抑えが外れて出てくる（痙縮・腱反射亢進・不随意運動・しびれ）。**カルテの「陽性・陰性」（異常あり・なし）とは別の意味** |

## 3. 実例：神経学的所見を 1 行ずつ読む

右/左 の順で記載されている（`N/↑` ＝右 正常・左 亢進）。

### 3-1. 神経学的異常のまとめ

```
左錐体路徴候（左上下肢軽度筋力低下、左腱反射軽度亢進）
体幹失調（座位、立位、歩行時の軽度ふらつき）
```

- **錐体路徴候**：上位運動ニューロン（UMN）が壊れたときのサイン。筋力低下・腱反射亢進・病的反射・痙縮
  - 左に出ている → 錐体交叉（延髄の下端）より上なら **右** の大脳〜脳幹、交叉より下なら **左** の頸髄（上肢の反射も亢進しているので C5 より上）
- **体幹失調**：手足の協調運動は保たれているのに、座る・立つ・歩くと体幹がふらつく状態。典型は **小脳虫部** の障害

**見直し**
- 「失調」は「原因は小脳（または深部覚・前庭）」という **解釈を含む言葉**。今回の所見（座位で後方へ倒れる・姿勢反射障害・仮面様顔貌・手足の協調運動は正常）は、**錐体外路・前頭葉–皮質下の障害・筋力低下** でも同じように見える
  → 画像などで小脳性と分かっていなければ、「**体幹のバランス障害（座位で後方へ倒れる、立位で右に傾く、継ぎ足歩行不可）**」と見たまま書き、原因の考察は A へ
- まとめから漏れている異常：**認知機能低下（MMSE 20/30）**、**仮面様顔貌**、**姿勢反射障害**、**頸部・右上肢の軽い筋力低下**。異常は全部まとめに拾い、1 つの病巣で説明できるかを A で考える（8 章）

### 3-2. 高次脳機能

```
礼節整容保たれるがやや指示入りにくい
```

- **礼節**（あいさつ・礼儀）と **整容**（身だしなみ）＝ 人格・社会的行動の観察。前頭側頭型認知症では早くから崩れ、Alzheimer 型認知症では保たれやすい
- 「指示入りにくい」の原因はいくつもある：①意識・注意の低下（せん妄を含む）②失語（聞いて理解する力の障害）③難聴 ④認知機能低下 ⑤意欲低下
  → **どれなのかが分かるように** 書く（例：「2 段階の指示は可、3 段階で誤る」「聞き返しが多い。指こすり 両側低下」）
- 高次脳機能はほかにも多い → **4 章**

### 3-3. 脳 12 神経

| 記載 | 見ている神経 | 意味・コツ |
|---|---|---|
| 視野障害なし | II（視路） | 対座法。右大脳の病変では **左同名半盲** を探す。左右同時に指を動かすと片側だけ気づかない（**消去現象**）なら頭頂葉 |
| 瞳孔 3/3、対光反射 迅速/迅速 | II（入力）・III（出力） | 両側 3 mm で左右差なし。片側だけ散大＋対光反射消失 → 動眼神経麻痺（脳ヘルニア・動脈瘤） |
| 眼瞼下垂なし | III（上眼瞼挙筋）・交感神経 | 軽い下垂＋縮瞳 → Horner、強い下垂＋散瞳 → 動眼神経麻痺、夕方に悪化 → 重症筋無力症 |
| 眼位正中 | III・IV・VI と注視中枢 | 正面視での目の位置。両目が同じ方向に寄る（共同偏視）→ 大脳か脳幹 |
| EOM full & smooth | III・IV・VI・脳幹・小脳 | EOM＝外眼筋の運動。full＝全方向に十分動く、smooth＝追視がなめらか（カクカクする追視は小脳・脳幹。高齢者でもある） |
| 眼振なし／複視なし | 前庭・小脳・脳幹／III・IV・VI | 複視は本人に聞く |
| 輻湊可 | III（内直筋）・中脳 | 寄り目。Parkinson 病・中脳病変で低下。高齢者は正常でも弱い |
| 顔面の感覚低下なし左右差なし | V（感覚） | 額・頬・あご（V1・V2・V3）で左右を比べる |
| 睫毛徴候なし／眼輪筋低下なし | VII（眼輪筋） | 強く目を閉じてもらい、まつ毛が埋もれずに見えたら眼輪筋が弱い（＝睫毛徴候あり）。**2 つは同じことを見ている** |
| 頬膨らませ可／口輪筋低下なし | VII（口輪筋） | ふくらませた頬を押すと、弱い側から空気が漏れる。**これも 2 つで同じこと** |
| 鼻唇溝左右差なし | VII | 安静時の見た目。浅いほうが麻痺側 |
| 軟口蓋挙上良好、口蓋垂正中 | IX・X | 「アー」で軟口蓋が上がるか。片側の麻痺では麻痺側が上がらず、口蓋垂は **健側** に引かれる |
| 挺舌正中で歯列 2 横指を超える | XII | 舌は **弱い側** に偏る（核下性なら病変側、核上性なら片麻痺側）。2 横指を超える＝十分に出せる |
| 舌運動はスムーズ | XII・錐体路・小脳 | 左右に速く動かす。遅い → 偽性球麻痺など |
| 舌萎縮なし、舌線維束性収縮なし | XII（下位運動ニューロン） | 萎縮・線維束性収縮は **ALS など LMN 障害** のサイン。舌は **口の中で力を抜いた状態** で見る（出させると健常人でも細かく動く） |
| 構音障害は認めない | V・VII・IX・X・XII＋小脳・基底核・錐体路 | 会話と「パタカ」の繰り返し。**構音障害（発音の障害）と失語（言葉の障害）は別物** |

- **今回の意味**：左の手足に錐体路徴候があるのに、**顔・舌・構音に明らかな左右差がない**（顔面を含まない片麻痺）。局在の手がかりになる大事な陰性所見
- **書かれていない項目**：嗅覚（I）・視力・眼底・咬筋（V 運動）・角膜反射・聴力（VIII）・嚥下・胸鎖乳突筋と僧帽筋（XI）・衝動性眼球運動（特に垂直）。どれを足すかは 5 章

### 3-4. 認知機能（MMSE）

```
MMSE 20/30（場所−1、計算−4、遅延再生−1、口頭指示−1、書字指示−1、自発書字−1、図形模写−1）
```

| 項目 | 満点 | 今回 | 主に見ている機能 |
|---|---|---|---|
| 時の見当識 | 5 | 5 | 見当識・記憶 |
| 場所の見当識 | 5 | 4 | 見当識 |
| 3 単語の記銘 | 3 | 3 | 即時記憶・注意 |
| 注意と計算（100 から 7 を順に引く） | 5 | **1** | **注意**・作業記憶・計算 |
| 3 単語の遅延再生 | 3 | 2 | 近時記憶 |
| 物品呼称（時計・鉛筆） | 2 | 2 | 言語（呼称） |
| 文の復唱 | 1 | 1 | 言語（復唱） |
| 3 段階の口頭指示 | 3 | 2 | 聴理解・注意・行為 |
| 書かれた指示（「目を閉じてください」） | 1 | 0 | 読んで理解する力 |
| 文を書く（自発書字） | 1 | 0 | 書字・言語 |
| 図形模写（重なった五角形） | 1 | 0 | **構成**（視空間認知） |

- 23 点以下は認知症を疑う目安。ただし **意識・注意が落ちている（せん妄）と点数は下がる**。入院直後・急性期は特に注意
- **点数より失点のパターン** を見る。今回は **記憶（時の見当識 5/5・記銘 3/3・再生 2/3）は比較的保たれ、注意・計算・指示動作・書字・構成で失点**
  → 記憶から落ちる典型的な Alzheimer 型とは違うパターン。注意・遂行機能（前頭葉–皮質下）や構成・視空間（頭頂葉）を追加で見る（4 章）
- 書字・図形模写は **利き手の麻痺・視力・教育歴** の影響を受ける → 利き手と教育歴を書く
- MMSE は **前頭葉機能（遂行機能）に鈍感**。FAB・MoCA で補う

### 3-5. 運動（MMT）

```
頸部　前屈4　後屈4
肩関節　外転4+/4
肘関節　屈曲5−/4+　伸展5−/4+
手関節　屈曲5−/4+　伸展5−/4+
股関節　屈曲5/5−
膝関節　屈曲5/5−　伸展5/5−
足関節　屈曲5/5−　底屈5/5−
```

- 数字の意味（4+・5− など）は **6 章**
- 分布：**左は上肢 4〜4+、下肢 5−** → 左片側・上肢優位の軽い筋力低下（まとめの「左上下肢軽度筋力低下」）。ほかに **右の肩外転 4+・肘と手首 5−**、**頸部 4**

**見直し**
- 片側の錐体路障害では **右上肢と頸部の低下は説明しにくい**（頸部の屈曲・伸展は両側の大脳から支配されるので、片側の大脳病変だけではほとんど弱くならない）
  → 痛み（肩関節周囲炎など）・廃用・低栄養・協力不十分・別の病気（頸椎症・筋疾患など）を考える。指示が入りにくいときは「協力不十分で参考値」と書く
- **錐体路型の分布** かを見る：典型的には **上肢は伸筋（肩外転・肘伸展・手首と指の伸展）、下肢は屈筋（股屈曲・膝屈曲・足背屈）** が弱い。今回の左肘・手首は屈曲＝伸展（4+）
- 軽い錐体路障害は MMT より **上肢 Barré・Mingazzini** で出やすい → 追加する
- **手指（握力・指の伸展・骨間筋）が入っていない**。錐体路障害は手指の細かい動き（指タッピング・指折り）から出やすく、頸髄症・尺骨神経障害・ALS の区別にも要る → 追加する。握力は kg で書くと経過を比べやすい
- **「足関節 屈曲」は紛らわしい**：整形外科・リハビリの可動域表示では、足関節の屈曲＝**底屈**（伸展＝背屈）とされてきた。一方、神経（屈曲反射）では背屈を屈曲の側として扱う。今回は「屈曲」と「底屈」が並んでいるので屈曲＝背屈のつもりと思われる → **「背屈・底屈」** と書く
- 底屈・膝伸展は強い筋なので、手で押しても 5 に見えやすい → つま先立ち・片脚でのかかと上げ・しゃがみ立ちで見る（立位が不安定なら無理をしない）

| Jj | 下顎反射（jaw jerk） | V（橋） | −：出ない＝正常範囲。亢進なら **橋より上の両側** の錐体路（偽性球麻痺・ALS）。頸髄症では亢進しないので区別に使う |
| Bic | 上腕二頭筋反射 | C5–6 | 左 亢進 |
| Tri | 上腕三頭筋反射 | C7 | 左 亢進 |
| BR | 腕橈骨筋反射 | C5–6 | 左右とも正常 |

| Chaddock | 外くるぶしの下をこする | 錐体路 | ind/ind |

- 左の Bic・Tri・PTR 亢進は、筋力低下と同じ側なので **左の錐体路徴候として合う**
- 腱反射は **左右差** があると意味が大きい。左右同じように亢進しているだけなら、緊張した健常人でもある
- **ind（indifferent）**：母趾が上にも下にも動かない（無反応）。**陰性（正常＝母趾が下に曲がる）とは違い「判定できなかった」** の意味。足趾を動かす筋の筋力低下・感覚低下・こすり方が弱いと起こる
- 軽い錐体路障害では Babinski は出ないことも多い。亢進側では **クローヌス（足・膝蓋）** も見て書く
- 認知機能低下や前頭葉性の歩行障害を疑うときは **前頭葉解放徴候（把握反射・吸引反射・口とがらし反射・手掌頤反射）** も見る

**見直し**：スペル **Hofmann → Hoffmann、Tremnor → Trömner**

**腱反射の書き方は 2 種類ある**（混ぜない）

| 日本でよく使う記号 | 英語圏でよく使う尺度 |
|---|---|
| − 消失／± 低下／＋ 正常／＋＋ やや亢進／＋＋＋ 亢進／＋＋＋＋ 著明亢進（クローヌス） | 0 消失／1+ 低下／**2+ 正常**／3+ 活発／4+ 著明亢進（クローヌス） |

同じ「＋」でも意味が違う。科の書き方に合わせ、迷ったら今回のように `N`・`↑`・`↓` と書くと誤解されない。

### 3-7. 感覚

```
異常感覚：なし
Romberg：陰性
```

- **異常感覚** ＝本人の訴え（しびれ・ジンジン）。**感覚低下（診察で調べる客観的な所見）とは別**
- **Romberg 試験**：足をそろえて立つ。目を開けて安定 → 目を閉じると大きく揺れる・倒れる ＝ 陽性 ＝ **深部覚（後索・末梢神経）か前庭の障害**。小脳の障害では目を開けていても不安定なので「陽性」にはならない

**見直し**
- **目を開けていても足をそろえて安定して立てない人は、Romberg は判定できない**（今回は立位で右に傾く・Mann 不可）→ 開眼で閉脚立位が安定していたなら「陰性」、そうでなければ「開眼でも閉脚立位不安定のため判定不可」
- 感覚の診察そのものが書かれていない → **表在覚（触覚・痛覚・温度覚）**、**深部覚（振動覚・位置覚）** を左右で比べて書く。右頭頂葉の病変を疑うなら **複合感覚（立体覚・皮膚書字覚・2 点識別覚・触覚の消去現象）** も
- 左片麻痺で頸髄の病変を否定するにも、感覚（感覚レベル・左右で解離した感覚障害）が要る

### 3-8. 協調運動

```
回内回外：リズムや振幅に乱れは生じない
指鼻試験：測定障害、運動分解は見られない
膝踵試験：足が上がらないため測定不可
```

- **回内回外**（手の回内・回外の速い繰り返し）：リズム・振幅が乱れる＝反復拮抗運動不能＝ **小脳**。**遅いがリズムは正しい＝錐体路**、**だんだん小さく遅くなる＝錐体外路** と区別できる → 速さと減衰も書く
- **指鼻試験**：測定障害（行き過ぎる・届かない）、運動分解（まっすぐ行けずカクカク）、**企図振戦**（目標に近づくほど震える）を見る。いずれも **同じ側の小脳半球**
- **膝踵試験**：仰臥位で、かかとを反対の膝に乗せ、すねに沿って足首まで滑らせる

**見直し**
- **「足が上がらない」と MMT（股屈曲 5/5−）が合わない**。理由を具体的に書く（指示が理解できない・痛い・体幹が不安定 など）。指示理解の問題なら「指示理解不十分で施行困難」
- 代わりの方法：仰臥位で足の親指で検者の指を触る（足趾手指試験）、座位で足先で床をリズムよくたたく
- 筋力が 3 以下の手足では判定できない（弱さで不器用に見える）。今回の上肢は 4〜4+ なので指鼻は判定できる
- 今回は **四肢の協調運動は正常で、体幹だけが不安定**。小脳なら虫部の障害、小脳以外なら錐体外路・前頭葉–皮質下・前庭を考える（3-9・3-10）

### 3-9. 起立・歩行

```
座位：徐々に後方に倒れる
起立：支えれば可能
立位：自立でなんとか可能だが右に傾く
歩行：なんとか自立歩行可能。ふらつきあり。
つぎ足歩行：不可能　Man肢位：不可能
```

- **座位で後方へ倒れる**（後方への姿勢保持障害）：小脳虫部でも起こるが、**錐体外路（特に進行性核上性麻痺）・前頭葉–皮質下（正常圧水頭症・多発ラクナ梗塞など）・視床の病変** でもよく見る
- **傾く方向** も局在の手がかり：片麻痺なら麻痺側、片側の小脳・前庭の障害なら病変側に倒れやすい。今回は麻痺（左）と反対の右
- **継ぎ足歩行**（つま先とかかとをつけて一直線に歩く）：体幹のバランス障害に敏感。ただし高齢者は正常でもできないことがある
- **Mann 試験**：片足のつま先にもう片足のかかとをつけて、前後一直線に立つ（開眼 → 閉眼）

**見直し**
- スペル **Man → Mann**
- 「なんとか」「ふらつき」は人によって意味が違う → **歩き方の特徴** と **介助量** で書く：歩隔（開脚か）・歩幅（小刻みか）・すくみ・腕振りの左右差・方向転換（何歩かかるか、不安定か）・麻痺側の分回し・介助量（見守り／手引き／歩行器）

| 歩き方 | 特徴 | 考える部位 |
|---|---|---|
| 片麻痺歩行 | 麻痺側の足を外に回して出す（分回し）。腕は曲がったまま振れない | 片側の錐体路 |
| 痙性歩行 | 両足がつっぱる、はさみ脚 | 両側の錐体路（脊髄など） |
| 小脳性失調歩行 | 開脚、酔ったようによろめく、方向が定まらない | 小脳 |
| 感覚性失調歩行 | 足元を見て歩く、かかとを床に打ちつける、暗い所・閉眼で悪化 | 深部覚（後索・末梢神経） |
| Parkinson 歩行 | 前かがみ、小刻み、すくみ、腕振りが少ない、止まれない（突進） | 大脳基底核 |
| 前頭葉性歩行 | 開脚・小刻み・すり足、足が床に張りつく（磁性歩行）、方向転換が苦手、後ろに倒れやすい | 両側の前頭葉–皮質下（正常圧水頭症・多発ラクナ梗塞など） |
| 鶏歩 | 足先が垂れるので膝を高く上げる | 腓骨神経・L5（下垂足） |
| 動揺性歩行 | 腰を左右に振る | 近位筋（筋疾患） |

### 3-10. 錐体外路

```
仮面様顔貌あり
安静時振戦0/0
動作緩慢0/0
筋強剛　上肢0/0　下肢0/0
姿勢反射障害　2,3歩足は出るが倒れる
```

- **0/0**：MDS-UPDRS と同じ 0〜4 の点数（0＝なし〜4＝高度）を右/左で書いたもの
- **仮面様顔貌**：表情が乏しく、まばたきが少ない
- **安静時振戦**：力を抜いて膝に手を置いたときの震え。歩かせる・暗算させると出やすい
- **動作緩慢**：**指タッピング（親指と人差し指を 10 回打ち合わせる）**・手の開閉・つま先タッピングで、遅さと **だんだん小さく遅くなる（減衰）** を見る
- **筋強剛（固縮）**：力を抜いた手足を検者が動かしたときの抵抗。**反対の手を握ったり開いたりさせる（誘発法）** と出やすい。頸部（体幹）の固縮も見る
- **姿勢反射障害**：pull test（後ろから両肩を素早く引く）

| MDS-UPDRS 3.12（pull test） | 状態 |
|---|---|
| 0 | 1〜2 歩で立ち直る（正常） |
| 1 | 3〜5 歩出るが、自力で止まる |
| 2 | 6 歩以上出るが、自力で止まる |
| 3 | 安全に立てるが立ち直りの反応がなく、**検者が支えないと倒れる** |
| 4 | 非常に不安定。自然に、または軽く引くだけでバランスを崩す |

**見直し**
- 「2,3 歩足は出るが倒れる」は、検者が支えなければ倒れたなら **3 相当**。「後方へ 3 歩、自力で止まれず検者が支えた」のように **歩数と結果** で書く
- **パーキンソニズム（MDS 2015）＝ 動作緩慢 ＋（安静時振戦 または 筋強剛）**。動作緩慢は手足（指タッピングなど）で判定する。今回は動作緩慢 0 なので、この基準ではパーキンソニズムとは言えない
- 表情が乏しいのは、うつ・意欲低下・前頭葉の障害・両側の顔面筋の筋力低下でも起こる
- **後方へ倒れる＋姿勢反射障害＋表情が乏しい＋注意・遂行機能の低下** がそろうときは、**垂直方向の眼球運動（特に下方視と、上下の衝動性眼球運動の速さ）** を見る（進行性核上性麻痺の診断基準に入っている）。排尿障害（正常圧水頭症）も聞く

**前提は意識と注意**。意識や注意が落ちていると、ほかの検査は全部悪く出る → まず JCS/GCS と注意（数唱）を書く。

| 見当識 | 時・場所・人 | 今がいつか・ここがどこか分からない | 記憶と注意の合計 |

| 失認 | 見て分からない物が、触ると分かるか。家族の顔が分かるか | 視覚性失認・相貌失認 | 後頭葉〜側頭葉 |
| Gerstmann 症候群 | 指の名前、左右、書字、計算 | 手指失認・左右失認・失書・失算 | 優位半球の角回 |
| **遂行機能（前頭葉）** | **FAB**（類似・語の想起・系列動作・葛藤指示・Go/No-Go・把握行動。18 点満点）、「か」で始まる言葉を 1 分間 | 段取りが組めない・切り替えられない | 前頭前野・前頭葉–皮質下の回路 |
| 社会的行動・感情 | 礼節・脱抑制・無関心（アパシー）・怒りっぽさ・感情失禁 | 社会的行動障害 | 前頭葉の眼窩面・内側面 |

## 5. 脳神経を効率よくやるには

### 5-1. 考え方：削るより「同時に見る・順番を変える」

- 医学生の小さい RCT（Kamel 2011）：**病歴から仮説を立てて絞った診察** と **全項目のスクリーニング** を比べると、時間の差は中央値 **1 分**（7 分 vs 8 分、有意差なし）。異常を見つける感度は絞ったほうが高く（78% vs 56%）、特異度は低かった（71% vs 100%）
- つまり **全部やっても数分**。速くしたいなら手順を決めて同時に見る。精度を上げたいなら、病歴から「どこを重点的に見るか」を決める
- 神経内科医が「よくある場面でほぼ毎回（80% 以上）やる」とした必須項目は 22 個だった（Moore & Chalk 2009）

### 5-2. 2 分でできる順番（上から下へ、見る → 動かす）

1. **見るだけ**（会話しながら）：眼瞼下垂・瞳孔の左右差・眼位・顔の左右差（額のしわ・鼻唇溝）・表情・声（構音・嗄声）
2. **視野**：対座法で 4 方向 ＋ 左右同時に指を動かす（消去現象）
3. **瞳孔**：大きさ・対光反射（直接・間接）
4. **追視（H 字）**：眼位・眼球運動・眼振・複視・なめらかさを一度に見る。必要なら輻輳と、左右・上下の衝動性眼球運動（2 本の指を交互に見る）
5. **顔の感覚**：額・頬・あごを左右で比べる
6. **顔の筋**：額にしわ → 強く目を閉じる（睫毛徴候）→「イー」→ 頬をふくらませる
7. **聴力**：両耳のそばで指をこする
8. **口**：「アー」（軟口蓋・口蓋垂）→ 舌を出す（偏り）→ 口の中で舌を休ませる（萎縮・線維束性収縮）→ 左右に動かす →「パタカ」
9. **首・肩**：肩をすくめる・首を回して押し返す（XI）

|---|---|
| 嗅覚（I） | 普段は省略可（「未」）。Parkinson 病・頭部外傷・前頭蓋底の病変を疑うときだけ |
| 眼底 | 頭痛・視力低下・頭蓋内圧亢進を疑うときは必須。それ以外は省略可（「未」） |
| 視力 | 見え方の訴えがあるとき。眼鏡をかけて字が読めるか程度でよい |
| 角膜反射 | 意識障害・顔の感覚低下・小脳橋角部の病変を疑うときだけ |
| 咽頭反射 | 健常人でも出ないことが多く、不快。**軟口蓋の挙上と、水を飲んだときの嚥下** を見るほうが役に立つ |
| 輻輳 | Parkinson 病・進行性核上性麻痺・中脳病変を疑うときだけ |
| 咬筋（V 運動） | 口を開けるとあごがずれる・噛めないときだけ |
| 重複した記載 | 睫毛徴候＝眼輪筋、頬ふくらまし＝口輪筋 → 1 つにまとめる |
| **削らない** | **視野・瞳孔・眼球運動・顔面筋・軟口蓋・舌・構音**。局在（脳幹の高さ）に直結し、合わせて 1〜2 分で終わる |
| **足す（今回）** | 聴力・XI・**垂直方向の眼球運動**（後方に倒れる・姿勢反射障害があるため）・嚥下（誤嚥のリスク） |

**最初の診察と経過記録で分ける**：最初は全部見て書く（研修中は指導医も全部見たいことが多い）。2 回目以降は **前回から変わった所** と **病巣に関係する所** だけでよい（「脳神経 前回と著変なし」など。科のルールに合わせる）。

## 6. MMT の数字（4+・5−）の基準

### 6-1. MRC 尺度（0〜5）

| 段階 | 基準 |
|---|---|
| 0 | 筋の収縮がまったくない |
| 1 | 収縮が見える・触れるが、関節は動かない |
| 2 | 重力を除けば動かせる（ベッドの上で横に滑らせるなど） |
| 3 | 重力に逆らって全可動域を動かせるが、抵抗には負ける |
| 4 | 重力と抵抗に逆らって動かせるが、正常より弱い |
| 5 | 正常 |

- **3 が境目**：3 以上＝重力に勝てる（手を挙げていられる）、3 未満＝重力に勝てない
- **4 の幅がとても広い**（「抵抗に少し耐える」から「ほぼ正常」まで全部 4）。だから 4 を細かく分けたくなる

### 6-2. ＋・− のつけ方

- MRC の原典で決まっているのは **4−・4・4+ だけ**：それぞれ **弱い・中くらい・強い抵抗** に逆らって動かせる
- **5− は原典にない**。拡張版の MRC 尺度などで「**あるかないかの、ごく軽い筋力低下**（equivocal, barely detectable weakness）」として使われる

| 表記 | 目安 |
|---|---|
| 5 | 正常。同じ年齢・体格の人と同じで、検者が押しても負けない |
| 5− | ほぼ正常だが、わずかに弱い気がする。反対側と比べてわずかに差がある、最後に少し押し負ける程度 |
| 4+ | はっきり弱いが、強い抵抗にもかなり耐える |
| 4 | 中くらいの抵抗に耐える |
| 4− | 弱い抵抗にしか耐えない |
| 3 | 重力に逆らって全可動域を動かせるが、抵抗には耐えられない |

- 3+・3−・2+ なども使われるが、**定義は流派で違う**。リハビリ（PT）の MMT（Daniels）では 5〜0 を Normal・Good・Fair・Poor・Trace・Zero と呼び、＋・− の使い方も少し違う
- ＋・− は **検者によってぶれる**。4+ を加えた MRC 尺度で、かえって検者間の一致が下がったという報告がある（64% → 48%、O'Neill 2017）
  → **同じ人が同じやり方で比べる**、**反対側と比べる**、**握力（kg）など数字で残せるものは数字で**

### 6-3. 判定のコツ

- **関節の角度と固定を毎回同じに**：近位を固定し、遠位を押す
- **break test**：患者に最大の力で姿勢を保ってもらい、検者が押して負けるかを見る
- **左右を比べる**：片側が正常なら、それが一番の基準
- **強い筋（大腿四頭筋・下腿三頭筋・股関節伸筋）は手では 5 に見えやすい** → しゃがみ立ち・つま先立ち・片脚かかと上げ・かかと歩きで見る
- 痛み・協力不足・理解不足で力が出ていないときは **その旨を書く**（「疼痛のため評価困難」「協力不十分で参考値」）
- 力が急に抜ける（give-way）なら、痛み・協力不足・心因性なども考える

**今回の所見で考える例**（実際の A は病歴と画像で決める）
- 錐体路：左上下肢の軽い筋力低下＋左腱反射亢進 → **右** の大脳〜脳幹、または左の上位頸髄。顔・舌に明らかな左右差なし（顔面を含まない片麻痺）

- 頸部・右上肢の軽い低下 → 片側の病変では説明しにくい（全身状態・痛み・別の病気）
- → 「1 か所で全部説明できるか、多発・びまん性か」を、画像と発症の仕方で考える

## 12. 用語集

| 言葉 | 意味 |
|---|---|
| 局在診断 | どこが壊れているかを決めること（系統 × レベル × 左右） |
| 錐体路 | 大脳の運動野から脊髄の前角へ行く運動の伝導路。延髄の下端で左右が交叉する |
| 錐体外路 | 錐体路以外の運動の調節系。主に大脳基底核の回路 |
| UMN／LMN | 上位運動ニューロン（大脳〜脊髄の伝導路）／下位運動ニューロン（脊髄前角・脳神経核から筋まで） |
| 痙縮 | 速く動かすほど強くなり、途中で急に抜ける抵抗（折りたたみナイフ現象）。錐体路 |
| 固縮（筋強剛） | 速さに関係なく、動かす範囲全体で続く抵抗（鉛管様・歯車様）。錐体外路 |
| 線維束性収縮 | 筋の一部がピクピク動く。LMN 障害（特に前角） |
| 測定障害 | 目標を行き過ぎる・届かない。小脳 |
| 運動分解 | なめらかな動きがカクカクに分かれる。小脳 |
| 企図振戦 | 目標に近づくほど強くなる震え。小脳 |
| 反復拮抗運動不能 | 速い交互運動のリズム・振幅が乱れる。小脳 |
| 消去現象 | 片側ずつなら分かる刺激が、左右同時だと片側だけ分からない。頭頂葉 |
| 半側空間無視 | 片側（多くは左）の空間に注意が向かない。右頭頂葉 |
| 病態失認 | 自分の麻痺に気づかない・否定する。右半球 |
| 構音障害 | 発音の障害（言葉の中身は正しい） |
| 失語 | 言葉そのもの（理解・表出）の障害 |
| indifferent（ind） | 足底を刺激しても母趾がどちらにも動かない（判定不能） |
| pull test | 後ろから肩を引いて、立ち直れるかを見る検査 |
| 仮説駆動型の診察 | 病歴から病巣の仮説を立て、それを確かめる項目を重点的に見るやり方 |
