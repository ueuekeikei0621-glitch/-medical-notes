# BLS（一次救命処置）のきほん

> [!IMPORTANT]
> **BLS は「止まった心臓の代わりに、手で血を回すこと」。**
> やることは 3 つだけ：**① 気づいて呼ぶ ② 押す ③ AED**。

---

## 1. そもそも何？

### BLS とは
- **BLS**＝Basic Life Support＝**一次救命処置**
- **ほとんど道具なしで、その場にいる人が誰でもできる** 命をつなぐ方法
- 中身は **胸骨圧迫（心臓マッサージ）・人工呼吸・AED**

### ALS・ICLS との関係

| | 名前 | 誰が | 何を使う |
|---|---|---|---|
| **BLS** | 一次救命処置 | **誰でも**（市民・医療者） | 手・AED（あれば BVM） |
| **ALS** | 二次救命処置 | 医療者 | 除細動器・薬（アドレナリンなど）・挿管 |
| **ICLS** | コースの名前 | 医療者が練習する | **BLS ＋ ALS の最初の 10 分** |

> [!TIP]
> **BLS が土台**。ICLS はその上に「波形を見る・薬を使う・挿管する」を足したもの。
> BLS ができないと ICLS はできない。

---

## 2. なぜ必要？（心停止とは）

### たとえで言うと
- **心臓＝ポンプ**、**脳＝ポンプから届く酸素で動くパソコン**
- ポンプが止まると、
  - **数秒** で意識がなくなる
  - **数分** で脳が傷つき始める（パソコンが壊れ始める）

### 時間との勝負
- 何もしないと、**1 分ごとに助かる確率が約 7–10% ずつ下がる**（目安）
- 救急車が来るまで **平均で約 10 分** かかる
- **→ 待っていたら間に合わない。その場の人がやるしかない**

### BLS がやっていること

| やること | 何の代わり | たとえ |
|---|---|---|
| **胸骨圧迫** | 止まったポンプ（心臓） | 手でポンプを押して、脳に血を送る |
| **人工呼吸** | 止まった呼吸 | 肺に空気を入れて、血に酸素を足す |
| **AED** | 心臓のリズムを直す | 細かく震えて空回りしている心臓（VF）を、電気で **リセット** する |

### 救命の連鎖（4 つの輪）
1. **心停止の予防**
2. **早く気づいて、通報する**
3. **一次救命処置（CPR と AED）** ← **BLS はここ**
4. **二次救命処置と、心拍が戻った後の集中治療** ← ICLS・ICU はここ

**どこか 1 つでも切れると助からない**。3 番目（BLS）が一番切れやすい。

## 3. 手順（7 ステップ）

```
① 安全確認
② 反応を見る        「大丈夫ですか！」
③ 人を呼ぶ          「あなた 119 番！ あなた AED！」
④ 呼吸を見る        10 秒以内。普段どおりの呼吸がない → 心停止
⑤ 胸骨圧迫 30 回    強く・速く・絶え間なく
⑥ 人工呼吸 2 回     できれば。無理なら圧迫だけ
⑦ AED               来たらすぐ。声の指示どおり
   → ⑤〜⑦を、救急隊・医療チームが来るまで続ける
```

### ① 安全確認
- 周りが危なくないか（車・火・電気・ガス）
- **なぜ**：助ける人が倒れたら、誰も助けられない

### ② 反応を見る
- 肩を叩きながら、**大きな声で**「大丈夫ですか！」
- 反応がない、または **反応があるか迷う** → 次へ進む

### ③ 人を呼ぶ
- 「**誰か来てください！**」
- **指をさして、人を決めて頼む**：「**あなた、119 番お願いします！ あなた、AED を持ってきてください！**」
  - **なぜ**：「誰かがやるだろう」とみんなが思って、誰もやらないのを防ぐ
- 院内なら「**救急カートと除細動器！**」（コードブルーなど施設の方法で）

**「AED ってなに？」「どこ？」と言われないための頼み方**
- **見た目で人を指名**：「そこの **黒いジャケットの方**！」
- **何か・どこかまで言う**：「**電気ショックの機械** です。**ハートに稲妻のマークの箱** に入っています」
- **わからないときの次の手を渡す**：「わからなければ **駅員さん（店員さん）に『AED どこですか』と聞いて** ください」
- **箱のアラームで止まらないように**：「**箱を開けると音が鳴りますが、そのまま持ってきて大丈夫** です」
- **戻ってくるように言う**：「**見つからなかったら、戻って教えて** ください」
- 119 番も同じ：「**119 番して、スピーカーにして、ここに置いて** ください」（自分が圧迫しながら指令員と話せる）
- 人がいれば **交代要員も頼む**：「ほかに手伝える方いますか？ 交代で押してもらいます」

```
「誰か来てください！」
「（指さして）黒いジャケットの方！119 番に電話して、スピーカーにしてここに置いてください！」
「（指さして）帽子の方！AED を持ってきてください。電気ショックの機械で、ハートに稲妻のマークの箱です。
 わからなければ駅員さんに『AED どこですか』と聞いてください。箱を開けると音が鳴りますが大丈夫です！
 見つからなかったら戻って教えてください！」
```

### ④ 呼吸を見る（10 秒以内）
- **胸とお腹が動いているか** を見る
- **普段どおりの呼吸がない**、または **よくわからない** → **心停止とみなして** すぐ圧迫
- **しゃくりあげるような呼吸（死戦期呼吸）は「呼吸なし」**
  - 心臓が止まった直後によく見られる。「息をしている」と勘違いしやすい **一番の落とし穴**
- 医療者は **頸動脈の脈も同時に** 見る（でも 10 秒以上かけない）。市民は脈を見なくてよい

### ⑤ 胸骨圧迫（30 回）

**合言葉：強く・速く・絶え間なく・しっかり戻す**

| | やり方 | なぜ |
|---|---|---|
| **場所** | **胸の真ん中**（胸骨の下半分） | ここの下に心臓がある |
| **手** | 手の付け根を重ねる。**肘を伸ばして、真上から体重をかける** | 腕の力だとすぐ疲れて浅くなる |
| **強く** | **約 5 cm** 沈むまで（6 cm を超えない） | 浅いと血が脳まで届かない |
| **速く** | **1 分間に 100–120 回**（1 秒に 2 回弱） | 遅いと血の流れが足りない |
| **しっかり戻す** | 押したら **胸を完全に戻す**（もたれない） | ポンプは **戻るときに血が入る**。スポイトと同じ |
| **絶え間なく** | 止めるのは **10 秒以内** | 止めると脳への血流がすぐ 0 になる。また押し始めても、血圧が上がるまで時間がかかる |
| **交代** | 人がいれば **1–2 分ごと** | 疲れると気づかないうちに浅くなる |

### ⑥ 人工呼吸（2 回）
- **圧迫 30 回 → 人工呼吸 2 回** をくり返す（30:2）
- やり方：頭を後ろに倒して、あごを上げる（気道確保）→ **1 回 1 秒、胸が上がる程度**
- **入れすぎない**（胃に空気が入る・胸の中の圧が上がって血が戻りにくくなる）
- 市民で、できない・ためらうときは **胸骨圧迫だけでよい**
  - **なぜ**：止まった直後は、血の中にまだ酸素が残っている。まずは **回すこと** が大事
- 医療者は **BVM**（バッグバルブマスク）で行う

### ⑦ AED
1. **電源を入れる**（ふたを開けると入る機種もある）
2. **音声の指示どおり** にやる
3. **パッドを素肌に貼る**：**右胸の上（鎖骨の下）** と **左の脇の下**
4. 「解析中です。離れてください」→ **誰も触っていないことを確認**
5. 「ショックが必要です」→ 「**離れて！**」と言って確認してから **ボタンを押す**
6. **すぐ胸骨圧迫に戻る**（AED は 2 分ごとに自動でまた解析する）

**パッドを貼るときの注意**
- 胸が濡れていたら **拭く**
- 貼り薬（湿布など）は **はがす**
- ペースメーカーのふくらみの **上は避けて** 少し離す
- **未就学児** は小児用パッド・小児モード（なければ成人用でよい）

> [!TIP]
> **AED はショックが要るかどうかを自分で判断する**。要らないときは、ボタンを押しても電気は流れない。
> だから **迷わず使ってよい**。

### AED の場所の探し方

**その場で**
1. **大声で人を呼んで「AED を持ってきて！」と頼む**（その場所にいつもいる人＝駅員・店員・職員が場所を知っている）
2. **ハートに稲妻のマーク**（「AED」の表示）を探す
3. 置いてあることが多い場所：**駅・空港・学校・役所・スポーツ施設・商業施設・ホテル・コンビニの一部**・ビルのエレベーターホール
4. 地域によっては、**119 番の指令員が近くの AED を教えてくれる** こともある

**事前に調べる**
- **財団全国 AED マップ**（日本救急医療財団）：Web で検索できる。スマホアプリ「**QQ・MAP**」もある
- **AED N@VI**（日本 AED 財団）
- マップは設置者の登録なので、**建物が閉まっている時間は使えない** ことがある（利用できる時間も見ておく）

**1 人しかいないとき**
- まず **119 番**（スピーカーにして、指令員の指示を聞きながら）
- **AED が近くにあるとわかっていれば取りに行く**。わからなければ探しに行かず、**すぐ胸骨圧迫**

> [!TIP]
> **病院では**：当直の前に、**自分の病棟・外来の「救急カート」「除細動器」「AED」の場所** を見ておく。いざというとき探さなくて済む。

### いつまで続ける？
- **救急隊・医療チームに引き継ぐまで**
- または、**動き出した・普段どおりの呼吸が戻った** とき
  - それでも AED のパッドは **貼ったまま**、電源も **入れたまま**（また止まることがある）

## 4. よくある疑問

| 疑問 | 答え |
|---|---|
| 肋骨が折れたら？ | **気にせず続ける**。骨は治るが、脳は戻らない |
| 脈があったのに押してしまったら？ | 害は小さい。**押さない方がはるかに危ない** |
| 人工呼吸がこわい・できない | 市民は **胸骨圧迫だけでも効果がある** |
| AED で感電しない？ | 「**離れて**」を守れば大丈夫 |
| 女性の服は？ | パッドは **素肌に** 貼る。救命が最優先。布で覆うなど、できるだけ人目にさらさない配慮はする |
| 呼吸しているか迷う | **迷ったら心停止として始める** |

## 5. 落とし穴

| 落とし穴 | 正しくは |
|---|---|
| しゃくりあげる呼吸を「息をしている」と思う | **死戦期呼吸＝呼吸なし**。すぐ圧迫 |
| 脈を探して時間をかける | **10 秒以内**。わからなければ始める |
| 浅い・遅い圧迫 | **約 5 cm・100–120 回/分** |
| 胸を戻さない（もたれる） | 押したら **完全に戻す** |
| AED の準備や人工呼吸で圧迫が長く止まる | 止めるのは **10 秒以内** |
| 「誰か呼んで」と言うだけ | **指をさして、人を決めて** 頼む |
| ショック後に様子を見る | **すぐ圧迫に戻る** |

## 6. ICLS へのつながり

BLS に、医療者が次のものを足すと **ICLS** になる。

| BLS | ICLS で足すもの |
|---|---|
| AED（機械が判断する） | **除細動器で自分が波形を見て判断する**（VF・VT・心静止・PEA） |
| 胸骨圧迫・人工呼吸 | **挿管・カプノグラフィ** |
| — | **薬**（アドレナリン・アミオダロン） |
| — | **原因を探す**（5H5T） |
| — | **チームで動く**（リーダー・役割分担・2 分ごとのサイクル） |

→ 続きは「ICLS まとめ」へ。

## メモ

- BLS の数値（約 5 cm・100–120 回/分・30:2・10 秒以内）は JRC 2020 の内容で、2025 年版でも大きく変わっていない前提で書いている。最新の講習テキストで確認する
- 1 分ごとに 7–10% 下がる・救急車まで約 10 分、は目安の数字
