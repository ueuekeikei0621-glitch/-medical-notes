# JATEC まとめ（外傷初期診療）

> [!IMPORTANT]
> **生理学（ABCDE）で命を守るのが先、診断は後。**
> 異常を見つけたら **次に進まず、その場で治す**。悪くなったら **A に戻る**。**不安定なまま CT に行かない**。

---

## 0. 全体の流れ

```
準備（MIST・感染防御・物品・人）
  ↓
第一印象（15 秒）→ 酸素・モニター・静脈路 2 本・採血
  ↓
Primary Survey（PS）＋蘇生：A → B → C → D → E
  補助検査：胸部 X 線・骨盤 X 線・FAST・血ガス
  ↓  ★ 悪化したら A に戻る
（切迫する D があれば）頭部 CT を最初に
  ↓
Secondary Survey（SS）：AMPLE → 頭から足まで → 背面 → FIXES → 全身 CT（安定していれば）
  ↓
根本治療（手術・IVR）／転院
  ↓
三次評価（24 時間以内にもう一度全身）
```

**4 つのルール**
1. 生理学が先、解剖は後
2. 見つけたらその場で治す
3. 悪くなったら A から
4. 不安定なら CT に行かない（止血か転院が先）

## 1. 1 枚で（PS）

| | 合言葉 | 見ること | 異常なら |
|---|---|---|---|
| **A** | **喋れる？ 音は？** | 発語・変な音 | 吸引 → 下顎挙上 → 挿管 |
| **B** | **首 → 胸 → 聴診 → 触る → SpO₂** | 頸静脈・気管、左右差、呼吸音、皮下気腫、SpO₂ | 脱気・ドレーン・酸素・挿管 |
| **C** | **SHOCK で気づく → FIX-C で治す** | 皮膚・脈・外出血・CRT と意識・血圧 | FAST・静脈路・X 線・止血 |
| **D** | **まいど** | 麻痺・意識（GCS）・瞳孔 | 切迫する D → 挿管・脳外・頭部 CT |
| **E** | **脱がせて、測って、温める** | 全身・体温 | 保温 |

## 2. 準備（患者が来る前）

**MIST**（救急隊から聞く）

| | 内容 |
|---|---|
| **M** | Mechanism：受傷機転 |
| **I** | Injury：損傷部位 |
| **S** | Sign：バイタル |
| **T** | Treatment：救急隊の処置 |

- **高エネルギー事故**（車外放出・同乗者死亡・横転・歩行者 vs 車・高所墜落・挟まれ）は見た目が軽くても重症として準備
- 感染防御（手袋・ガウン・マスク・ゴーグル）を **到着前に**
- 物品：酸素・BVM・吸引・挿管セット・**39℃ 加温輸液**・O 型輸血の確認・ドレーン・エコー・ポータブル X 線・骨盤バインダー
- 役割：**リーダーは足側で全体を見る**（手技に入り込まない）。指示は名前を呼んで出し、復唱してもらう

## 3. 第一印象（最初の 15 秒）

肩に手を置いて「わかりますか？お名前は？」と声をかけながら、**橈骨動脈を触れ、皮膚を見て、胸の動きを見る**。

> 「気道開通、呼吸速い、橈骨速く弱い、冷汗あり。**ショックです！**」

→ すぐに **酸素 10L・モニター・静脈路 2 本（18G 以上）・採血・加温輸液**。
噴き出す外出血は ABC を待たずにその場で圧迫。

---

## 4. A：喋れる？ 音は？

**見るのは 2 つ**
1. **喋れるか** → 名前が言えれば **A は OK**
2. **変な音**

| 音 | 原因 | 処置 |
|---|---|---|
| ゴロゴロ | 口の中に血・吐物 | **吸引** |
| いびき | 舌が落ちている | **下顎挙上**（頭は後ろに倒さない） |
| ヒューヒュー（stridor） | のどが狭い | **挿管** を考える |

- 治らない・GCS ≤8 → **挿管**（頸椎は用手正中中間位固定＝MILS）
- 挿管も換気もできない → 輪状甲状靱帯切開（小児は穿刺）
- 頸椎は否定できるまで **ずっと保護**

> 「発語あり、異常音なし、**A 開通**。頸椎保護を続けます」

---

## 5. B：首 → 胸 → 聴診 → 触る → SpO₂

1. **首を見る**：頸静脈怒張・気管偏位
2. **胸を見る**：左右同じに動くか・呼吸数・奇異運動
3. **聴診**：左右の腋窩で呼吸音を比べる
4. **触る**：皮下気腫（雪を握るギュッギュッ）
5. **SpO₂**

→ ここで **胸部 X 線**。エコーがあれば E-FAST でも見られる。

| こう見えたら | 考える | すぐやる |
|---|---|---|
| 片側の呼吸音↓＋**頸静脈怒張**＋ショック | **緊張性気胸** | **X 線を待たずに脱気** → 胸腔ドレーン |
| 片側の呼吸音↓＋ショック＋頸静脈は **張らない** | **大量血胸** | 胸腔ドレーン＋輸血 |
| SpO₂↓ | 低酸素 | 酸素 → だめなら挿管 |

> [!TIP]
> 頸静脈で区別：**気胸は張る、出血は張らない**

**PS で治す胸部外傷：TAF3X**
- **T** 心タンポナーデ（FAST で心嚢液 → 心嚢穿刺・外科）
- **A** 気道閉塞
- **F** フレイルチェスト（奇異運動 → 酸素・鎮痛・陽圧換気）
- **X** 緊張性気胸（脱気：第 2 肋間鎖骨中線 or 第 4–5 肋間中腋窩線 → ドレーン）
- **X** 開放性気胸（**3 辺テープ** → 別の場所からドレーン）
- **X** 大量血胸（ドレーン。**初回 1,000 mL 以上**、**200 mL/時が 2–4 時間**、輸血しないと保てない → 開胸）

胸腔ドレーンの位置：**第 4–5 肋間（乳頭の高さ）、中腋窩線〜前腋窩線**

> 「頸静脈怒張なし、気管正中、左右差なし、呼吸音左右差なし、皮下気腫なし、SpO₂ 98%。**B 問題なし**」

## 6. C：SHOCK で気づく → FIX-C で治す

### SHOCK（1 つでもあればショック）

| | 英語 | 見ること |
|---|---|---|
| **S** | Skin | 皮膚が **冷たい・じっとり** |
| **H** | Heart rate | 脈が **速い・弱い** |
| **O** | Outer bleeding | **外出血** |
| **C** | CRT & Consciousness | **CRT > 2 秒**・**意識がおかしい（不穏も）** |
| **K** | Ketsuatsu | **血圧が低い** |

> [!WARNING]
> **血圧は最後に下がる**。血圧が下がったら出血はすでに 30% 以上（成人で 1.5 L 以上）。
> 高齢者・β 遮断薬・ペースメーカーは脈が速くならない。

**ショックインデックス（SI）＝ 心拍数 ÷ 収縮期血圧**：1.0 ≒ 1 L、1.5 ≒ 1.5 L、2.0 ≒ 2 L の出血

### FIX-C（C を治す）

| | 何をする | ポイント |
|---|---|---|
| **F** | **FAST** | 出血を探す（7 章） |
| **I** | **IV** | **静脈路 2 本**（18G 以上）＋採血。取れなければ骨髄路。**加温輸液 1L** |
| **X** | **X 線** | **胸部と骨盤** の 2 枚 |
| **C** | **Compression（止血）** | 外出血は圧迫・止血帯。骨盤骨折は **骨盤バインダー（大転子の高さ）**。手術・IVR |

**見えない出血は 胸・腹・骨盤**：胸部 X 線・FAST・骨盤 X 線で探す（＋大腿骨）

**出血以外のショックも忘れない**：緊張性気胸・心タンポナーデ（閉塞性）、頸髄損傷（神経原性：**徐脈・皮膚が温かい**。出血を否定してから考える）

### 輸液 1L のあとの反応：R／TR／NR

輸液の前後で **SHOCK の項目**（皮膚・脈・意識・CRT・血圧）を比べる。

| 略語 | 英語 | どうなったか | 意味 | 次 |
|---|---|---|---|---|
| **R** | Responder | 良くなって **そのまま安定** | 出血は止まっているかも | SS へ（見張りは続ける） |
| **TR** | Transient responder | いったん良くなるが **また悪くなる** | **出血が続いている** | **輸血**・外科／IVR を呼ぶ |
| **NR** | Non-responder | **良くならない** | **大出血**、または閉塞性ショック | **輸血＋すぐ止血**。気胸・タンポナーデを再確認 |

**例**（輸液前：脈 130・血圧 85/50・冷汗あり）
- R：1L で脈 95・血圧 120/70、15 分後もそのまま
- TR：1L で脈 100・血圧 110/65 → 10 分後に脈 125・血圧 88/50
- NR：1L 入れても脈 140・血圧 70/40

> [!IMPORTANT]
> **TR・NR に輸液を足し続けない。必要なのは「輸血」と「止血」。**
> 明らかな大出血なら 1L の反応を待たずに輸血。

### 輸血・薬

- 緊急時は **O 型 RBC**、FFP・血小板は **AB 型**。RBC と FFP は **1:1 に近く**（施設の大量輸血プロトコル）
- **トラネキサム酸**：受傷 **3 時間以内** に 1 g を 10 分 → 1 g を 8 時間
- 止血までは血圧を上げすぎない（収縮期 80–90 目安）。**頭部外傷があれば低血圧を避ける**
- **死の三徴**（低体温・アシドーシス・凝固障害）を防ぐ：加温、乳酸・BE を追う、早めに FFP

> 「皮膚冷感・湿潤、脈 120 で弱い、外出血なし、CRT 3 秒、不穏、血圧 90/60。**ショックです**。FAST します。静脈路 2 本、加温輸液 1L。胸部・骨盤 X 線お願いします」

## 7. FAST（＋肺）のやり方

**準備**
- プローブは **コンベックス**、プリセットは **腹部／FAST**
- 見るのは **黒い（無エコー）液体があるかだけ**
- 自施設メモ：電源ボタンは **本体の裏**

**順番：心臓 → 右（お腹 → 胸）→ 左（お腹 → 胸）→ 膀胱 →（E-FAST）前胸部**

| 順 | 場所 | 当て方 | 見るところ |
|---|---|---|---|
| ① | **心臓（心窩部）** | 剣状突起の下。プローブを **寝かせて左肩** へ向ける | 心臓のまわりの黒い帯（心嚢液） |
| ② | **右上腹部** | 右の **中腋窩線**、肋骨の間。マーカー頭側 | **肝臓と腎臓の間**（モリソン窩） |
| ②' | **右胸腔**（血胸） | ②から **肋間 1 つ上** | **横隔膜の上** に黒い液体 |
| ③ | **左上腹部** | 右より **上で後ろ**（手の甲がベッドにつくくらい） | **脾臓のまわり**（横隔膜との間） |
| ③' | **左胸腔**（血胸） | ③から **肋間 1 つ上** | 横隔膜の上に黒い液体 |
| ④ | **膀胱** | 恥骨の上。横と縦 | 膀胱の **後ろ** の黒い液体 |
| ⑤ | **前胸部**（気胸） | **鎖骨中線 第 2–3 肋間**、縦。左右両方 | **lung sliding** |

### 血胸：横隔膜の上を見る

| | 正常 | 血胸 |
|---|---|---|
| 横隔膜の上 | 肝臓（脾臓）の **鏡像** | **黒い液体** |
| 背骨 | 横隔膜で **消える** | 横隔膜より **上まで見える**（spine sign） |

### 気胸：lung sliding を見る

- 肋骨 2 本と、その間の **白い線（胸膜）**（コウモリが羽を広げた形）
- 白い線が呼吸で **キラキラ横に動く** → lung sliding あり → **そこに気胸はない**
- **動かない** → **気胸を疑う**
- M モード：砂浜（seashore sign）＝正常、**バーコード**（barcode sign）＝気胸

> [!TIP]
> 仰向けでは **空気は前（天井側）**、**血は背中側・横隔膜の上** に溜まる。
> だから気胸は前胸部、血胸は横隔膜の上を見る。

**注意**
- lung sliding がなくても、**片肺挿管**・息止め・癒着でも消える
- 皮下気腫が強いと見えない → 「描出不良」
- 左は見えにくい → **もっと上・もっと後ろ**
- 膀胱は **尿カテの前** に見る
- **1 回陰性でも、血圧が変わったらもう一度**（何回目か記録）
- 後腹膜（骨盤・腎）の出血は FAST では見えない

**カルテ**
```
【FAST】（　:　、　回目）
心嚢 −/＋　モリソン −/＋　脾周囲 −/＋　膀胱直腸窩 −/＋
胸腔 右 −/＋ 左 −/＋　lung sliding 右 有/無 左 有/無
→ 陰性 / 陽性（　）
```

## 8. D：まいど（麻痺・意識・瞳孔）

| | 見ること | やり方 |
|---|---|---|
| **ま** 麻痺 | 手足が左右同じように動くか | 「手を握って」「足を動かして」 |
| **い** 意識 | **GCS**（E・V・M を分けて） | 下の表 |
| **ど** 瞳孔 | 大きさ・左右差・対光反射 | ペンライトで片目ずつ |

**GCS 早見表**

| E（目） | V（言葉） | M（動き） |
|---|---|---|
| 4 自分で開けている | 5 日時・場所がわかる | 6 指示に従う |
| 3 呼ぶと開ける | 4 会話が混乱 | 5 痛い所に手を持ってくる |
| 2 痛みで開ける | 3 言葉だけ | 4 痛みから手を引っ込める |
| 1 開けない | 2 うめき声だけ | 3 異常屈曲 |
| | 1 声が出ない | 2 伸展 |
| | | 1 動かない |

**切迫する D（どれか 1 つ）**
- GCS **8 点以下**
- GCS が **2 点以上** 下がった
- **瞳孔の左右差**・**片麻痺**・Cushing 現象（高血圧＋徐脈）

→ **挿管・脳外科コール・ABC が落ち着いたら最初に頭部 CT**

- **血糖も測る**（低血糖でも意識が悪くなる）
- 意識障害を頭部外傷のせいと決めつけない（低酸素・ショック・アルコール・薬）

> 「麻痺なし、GCS E4 V5 M6 の 15 点、瞳孔 3 mm 左右差なし、対光反射あり。**切迫する D なし**」

---

## 9. E：脱がせて、測って、温める

1. **脱がせる**：はさみで切って全部。出血・傷・変形を見る
2. **測る**：体温
3. **温める**：すぐ毛布・加温ブランケット。濡れた服を取る。部屋を暖める

- 低体温は血を止まりにくくする → **最初から温める**
- 背中は SS の log roll で見る

> 「全身脱衣、外出血なし、変形なし。体温 36.2℃。保温します」

## 10. PS 全体の声出し（例）

```
第一印象「わかりますか？」→「ショックです！酸素、モニター、ルート 2 本お願いします」
A「発語あり、異常音なし、A 開通」
B「頸静脈怒張なし、気管正中、左右差なし、呼吸音左右差なし、皮下気腫なし、SpO₂ 98%。B 問題なし」
C「皮膚冷汗、脈速く弱い、外出血なし、CRT 3 秒、血圧 90/60。ショック。
   FAST：心嚢−、モリソン−、右胸腔−、脾周囲−、左胸腔−、膀胱−、sliding 両側あり。
   胸部・骨盤 X 線お願いします。加温輸液 1L」
D「麻痺なし、GCS 15、瞳孔 3 mm 左右差なし。切迫する D なし」
E「全身脱衣、外出血なし。体温 36.2℃、保温します」
「PS 終わります。C は輸液の反応を見ます」
```

PS が終わったら決める：**止血術が必要か → 自施設でできるか → できなければ転院**。

## 11. Secondary Survey（SS）

**入る条件**：PS の異常に対処して、悪化していない。**悪くなったら PS に戻る**。

### AMPLE（病歴）

| | 内容 | 特に |
|---|---|---|
| **A** | Allergy | 造影剤・薬 |
| **M** | Medication | **抗凝固薬・抗血小板薬**・β 遮断薬 |
| **P** | Past history & Pregnancy | 心疾患・肝疾患・透析・妊娠 |
| **L** | Last meal | 時刻 |
| **E** | Events & Environment | 事故の前に失神・けいれん・低血糖はなかったか |

### 頭から足まで（要点）

| 部位 | 探すもの |
|---|---|
| 頭部 | Battle 徴候・パンダの目・髄液漏 → **頭蓋底骨折**（経鼻胃管・経鼻エアウェイ禁止） |
| 顔面 | 眼外傷・顔面骨折（気道に影響しないか） |
| 頸部 | カラーの前を外して MILS：気管偏位・**大きくなる血腫**・皮下気腫・後頸部の圧痛 |
| 胸部 | **PATBED2X**（下） |
| 腹部 | 圧痛・腹膜刺激症状・**シートベルト痕**（腸管損傷・Chance 骨折） |
| 骨盤 | X 線で評価（不安定型なら動揺テストはしない） |
| 会陰・直腸 | 外尿道口出血・会陰血腫・直腸診（必要時） |
| 四肢 | 変形・開放骨折・末梢の脈・**コンパートメント症候群** |
| 背面 | **log roll**（4–5 人、頭側の合図で） |
| 神経 | GCS 再評価・脊髄損傷のレベル |

### PATBED2X（見逃すと後で死ぬ胸部外傷）

| | 損傷 | 手がかり |
|---|---|---|
| **P** | 肺挫傷 | 低酸素が悪化。X 線は遅れて出る |
| **A** | 大動脈損傷 | **縦隔拡大**・左血胸・第 1–2 肋骨骨折 → 造影 CT |
| **T** | 気管・気管支損傷 | ドレーンの空気漏れが止まらない |
| **B** | 鈍的心損傷 | 不整脈・心電図変化 → 12 誘導・トロポニン |
| **E** | 食道損傷 | 縦隔気腫 |
| **D** | 横隔膜損傷 | 胃管が胸の中（左に多い） |
| **X** | 気胸 | ドレーン |
| **X** | 血胸 | ドレーン |

### FIXES（SS の締め）

| | 内容 |
|---|---|
| **F** | Finger & Tube：直腸診・胃管（頭蓋底骨折疑いは経口）・尿道カテーテル |
| **I** | iv：鎮痛・**破傷風予防**・開放骨折の抗菌薬 |
| **X** | X-ray：追加の X 線・CT |
| **E** | ECG：12 誘導心電図 |
| **S** | Splint：副子固定（前後で末梢の脈・感覚を確認） |

> [!WARNING]
> **尿道カテーテル禁止のサイン**：外尿道口からの出血・会陰や陰嚢の血腫・前立腺が高い位置 → 泌尿器科に相談

### CT

- **循環が安定していれば** 全身 CT（頭部単純 → 頸椎 → 体幹造影）
- 不安定（TR・NR）なら **CT に行かず** 止血術・転院
- CT 室にも **医師が付いていく**

---

## 12. 再評価・三次評価・転院

- 状態が変わったら **A から**。FAST は繰り返す
- **三次評価**：24 時間以内に頭から足まで再診察。見逃しやすい：**手指・足・手首・足首・顔面・肋骨・脊椎・小腸**
- **転院**：自施設で根本治療ができなければ **PS の時点で決めてよい**。転院前に A・B を確保（挿管・ドレーン）、静脈路・保温、MIST と処置と画像を渡す

## 13. よくある落とし穴

| 落とし穴 | 正しくは |
|---|---|
| 血圧が保たれているから大丈夫 | 血圧は最後。**SHOCK の S・H・C** を見る |
| 緊張性気胸を X 線で確かめる | **X 線を待たずに** 脱気 |
| 反応しないのでさらに輸液 | TR・NR は **輸血と止血** |
| 不安定なまま CT | **止血術か転院が先** |
| FAST 陰性＝出血なし | 後腹膜は見えない・早期は陰性。**繰り返す** |
| 骨盤バインダーを腸骨稜に巻く | **大転子の高さ** |
| 意識障害は頭部外傷のせい | 低酸素・ショック・低血糖・アルコール・薬 |
| 頭部外傷で血圧を低めに | 頭部外傷では **低血圧を避ける** |
| リーダーが手技に入る | リーダーは全体を見る |
| SS で終わり | 翌日までに **三次評価** |
| 低体温を放置 | **最初から保温** |
