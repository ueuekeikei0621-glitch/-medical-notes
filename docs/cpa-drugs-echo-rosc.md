# 心停止の薬・エコー・ROSC 後の流れ

> [!IMPORTANT]
> **薬は「波形」で決まる**。VF・VT は **ショックが主役で薬は脇役**、心静止・PEA は **アドレナリンと原因の治療が主役**。
> **エコーはルーチンではない**。使うなら **2 分ごとの中断の中だけ**。
> **ROSC 後は決まった流れがある**：ABCDE で立て直す → 12 誘導 → 原因 → ICU（体温・予後は急がない）。

---

## 1. 波形ごとの薬

### 早見表

| | **VF・無脈性 VT**（ショックする） | **心静止・PEA**（ショックしない） |
|---|---|---|
| 主役 | **ショック** | **圧迫＋原因を探して治す** |
| アドレナリン 1 mg | **ショックが効かなければ** 入れる（コースでは「**2 回目のショックの後**」）→ 以後 **3–5 分ごと** | **できるだけ早く** → 以後 **3–5 分ごと** |
| 抗不整脈薬 | **3 回ショックしても VF・VT** → **アミオダロン 300 mg**、さらに続けば **150 mg** | **使わない** |
| 原因の薬 | 必要なら | **ここが本番**（下の「原因ごとの薬」） |

**なぜ違う？**
- VF・VT は **ショックが一番効く**。薬はショックを助ける脇役なので、まずショックを優先する
- 心静止・PEA は **ショックが使えない**。打てる手はアドレナリンと、**原因を治すこと** だけ

### 薬はいつ入れる？（圧迫は止めない）

- **薬は圧迫しながら入れる**。2 分ごとの中断は **波形を見る・ショックするためだけ**。薬のために圧迫を止めない
- **心静止・PEA の 1 回目**：**ルートが取れたら、その場ですぐ**（サイクルの途中でも、波形チェックを待たない）。救急隊がもう入れていれば、その時刻から 3–5 分後
- **2 回目以降・VF のとき**：波形チェック（とショック）のあと、**圧迫を再開したらすぐ** 入れる → 次の 2 分の圧迫で薬が回る
- **3–5 分ごと** ＝ 実際は **2 サイクルに 1 回**（「波形チェック → 再開 → アドレナリン」を 1 回おきに）
- **準備は前もって**：波形チェックの前に吸っておく。記録係が「次のアドレナリンは〇時〇分」と言う
- 入れたら **生食 20 mL で後押し・腕を上げる**

**時間はどう測る？（2 つの時計を 1 人で見る）**
- **① 2 分のタイマー**：ストップウォッチ、または除細動器の CPR タイマー。波形チェックのたびにリセット
- **② 時刻**（壁の時計・モニターの時計）：ショック・薬を入れた **時刻** をホワイトボードに書く。アドレナリンは **前回の時刻から 3–5 分** で決める
- 実際は ① に合わせて「**2 サイクルに 1 回**」入れると、② の 3–5 分にちょうど収まる
- 記録係が両方を見て声に出す：「1 分 50 秒です」「次のアドレナリンは 10:06 です」
- 除細動器によっては、2 分タイマーや **「薬を入れた」を記録するボタン**（イベント記録）がある
- 救急隊の時刻は救急隊の時計なので、**数分ずれることがある**（目安として使う）

```
（心静止の例）
ルート確保 → すぐアドレナリン①（10:02）
10:04 波形チェック → 再開
10:06 波形チェック → 再開 → アドレナリン②（10:06）
10:08 波形チェック → 再開
10:10 波形チェック → 再開 → アドレナリン③（10:10）
```

### 1 本ずつの中身

| 薬 | 量 | 準備・入れ方 | ひとこと |
|---|---|---|---|
| **アドレナリン** | **1 mg** | 1 mg／1 mL（プレフィルドシリンジなど）をそのまま静注 → **生食 20 mL で後押し・腕を上げる** | 血管を締めて、圧迫で送った血を **心臓と脳に集める** |
| **アミオダロン**（アンカロン） | **300 mg**（2 回目 **150 mg**） | 150 mg／3 mL のアンプル。**5% ブドウ糖液** で薄める（生食で薄めない） | ショックで止まりにくい VF を **止まりやすくする** |
| リドカイン（代わり） | 1–1.5 mg/kg（追加 0.5–0.75 mg/kg） | — | アミオダロンの代わり |
| ニフェカラント（代わり、日本） | 0.3 mg/kg | — | 日本で使われる代わりの薬 |
| マグネシウム | 2 g | — | **トルサード（QT 延長の多形性 VT）のときだけ**。ルーチンでは使わない |

- ルートは **静脈路が第一選択**、取れなければ骨髄路（JRC 2025）
- 薬の **量と製剤は自施設で確認**（アンプルの濃度が施設で違うことがある）

### 波形が途中で変わったら

| 変わり方 | どうする |
|---|---|
| **VF → 心静止・PEA** | ショックの流れをやめて、ショックしない流れへ。**アドレナリンは前回の時刻から数え続ける**（リセットしない）。アミオダロンは追加しない |
| **心静止・PEA → VF** | ショックの流れへ。アドレナリンは時刻どおり続ける。**ショックの合計回数** でアミオダロンを決める |
| **規則的な波形＋脈あり** | **ROSC**（3 章） |

### ルーチンでは使わない
- **重炭酸・カルシウム・マグネシウム・アトロピン・バソプレシン・ステロイド**
- 使うのは **原因に合うときだけ**（下の表）

### 原因ごとの薬（5H5T に当てはまるとき）

| 原因 | 手がかり | 薬・処置 |
|---|---|---|
| **高 K 血症** | 透析・腎不全、血ガスの K が高い、テント状 T | **カルシウム**（塩化 Ca・グルコン酸 Ca）＋ **インスリン＋ブドウ糖** ＋（重炭酸） |
| 三環系抗うつ薬などの中毒 | 内服歴、QRS 幅が広い | **重炭酸**（メイロン） |
| Ca 拮抗薬の中毒 | 内服歴 | **カルシウム** |
| **肺塞栓** | 術後・長期臥床・DVT、右室が大きい | **血栓溶解** を考える（入れたら **CPR を長めに続ける**）・ECPR |
| 心タンポナーデ | 心嚢液 | **心嚢穿刺**（薬ではない） |
| 緊張性気胸 | 片側の呼吸音↓・外傷 | **脱気**（薬ではない） |
| 循環血液量の不足 | 出血・脱水 | **輸液・輸血** |
| 低血糖 | 糖尿病の薬 | **ブドウ糖** |
| 局所麻酔薬中毒 | 処置中に起きた | **脂肪乳剤** |
| アナフィラキシー | 薬・食べ物のあと、皮疹 | アドレナリン（同じ）＋ **大量の輸液** |

- 量は **院内のプロトコル** で確認する（ここでは薬の名前と考え方だけ）

### 低体温のとき（ERC 2025 の考え方）
- **30℃ 未満**：アドレナリンは入れない（ショックは 3 回まで）
- **30–35℃**：アドレナリンの **間隔を倍に**（6–10 分ごと）
- 復温しながら続ける（ECPR を考える）

## 2. エコーはいつ始める？

### ガイドラインの位置づけ
- **JRC 2025**：原因を探すために、CPR 中に **ルーチンでは行わない** ことを提案（弱い推奨）。**慣れた人が、圧迫の中断を延ばさない** なら追加してよい
- **AHA・ERC 2025 も同じ方向**：**慣れた人**、**圧迫を止めない・ショックを遅らせない** が条件

### タイミング
1. **後回しでよい**：まず **圧迫・ショック・ルート・アドレナリン・気道** が回ってから（最初の数サイクルのうちに）
2. **2 分ごとの中断の中だけ** で見る（中断を延ばさない）
3. **特に役立つのは PEA**（原因を探すとき）

### やり方（中断を延ばさないコツ）
```
① 圧迫中に、プローブを心窩部に当てて準備しておく
② 中断と同時に 動画を録画（数秒）
③ 誰かが声に出して秒数を数える（「5、6、7……10、再開！」）
④ 圧迫を再開してから、録画を見て判断する
```
- **脈を触る人と、エコーを当てる人は別**。リーダーはエコーに入らない
- LUCAS が付いていると胸骨の横からは見にくい → **心窩部・心尖部**

### 何を見る（順番の例：CASA）
| 中断 | 見るもの | 見つかったら |
|---|---|---|
| 1 回目 | **心嚢液** | 心タンポナーデ → 心嚢穿刺 |
| 2 回目 | **右室が大きい** | 肺塞栓 → 血栓溶解・ECPR |
| 3 回目 | **心臓が動いているか** | 動いている（脈が触れないだけ）→ 圧迫を続け、昇圧を考える |

- 必要なら：lung sliding（気胸）、IVC・腹腔の液体（出血）
- **エコーだけで蘇生をやめると決めない**

## 3. ROSC 後の流れ（決まった流れがある）

### 最初の 10 分（ER）

```
① 確かめる   脈・血圧・モニター・EtCO₂。パッド（と病院の LUCAS）は付けたまま
② A          気道確保（意識がなければ挿管。声門上デバイスなら入れ替えを考える）
③ B          SpO₂ が測れるまで酸素 100% → 測れたら下げる（AHA 2025：SpO₂ 90–98%・PaO₂ 60–105）
             PaCO₂ 35–45 mmHg・1 回換気量 6–8 mL/kg（理想体重）
④ C          血圧を保つ（目安：収縮期 90 以上・平均血圧 65 以上）→ 輸液・昇圧薬
             12 誘導心電図
⑤ D          意識（GCS）・瞳孔・けいれん・血糖
⑥ E          体温を測る・熱を出させない
```

### 原因を決める
| 検査 | 何を見る | 次の一手 |
|---|---|---|
| **12 誘導** | **ST 上昇** | **緊急カテ**（循環器コール） |
| | ST 上昇なしでも心臓が原因らしい・ショックが続く | 循環器と相談 |
| 採血・血ガス | K・Hb・乳酸・トロポニン | 原因の治療 |
| エコー | 心機能・心嚢液・右室 | 原因の治療 |
| **CT** | 原因がわからない（頭蓋内出血・大動脈解離・肺塞栓など）。AHA 2025 では **頭部・胸部・腹部・骨盤** の CT を考える（原因と、蘇生でのけが） | 原因の治療 |

### ICU で（知っておくこと）

| 項目 | 考え方 |
|---|---|
| **体温** | JRC 2025：**37.5℃ 以下を目標に、熱を出させない**／AHA 2025：32–37.5℃、**36 時間以上**／ERC・ESICM 2025：37.5℃ 以下を **36–72 時間** |
| 血糖 | 低血糖も高血糖も避ける |
| けいれん | 脳波で見る。起きたら治療（予防投与はしない） |
| **予後の判断** | **急がない**（少なくとも **72 時間** 以上たってから、いくつもの検査を合わせて） |
| 家族 | 経過と見通しを説明する |

- ROSC 直後は **また止まりやすい** → パッドは貼ったまま、除細動器はすぐ使える状態で

### ROSC の声出し（例）
```
「脈あり、ROSC です。圧迫止めて。パッドはそのまま」
「血圧測って。SpO₂ 見えたら酸素下げます。PaCO₂ 35–45 で換気」
「12 誘導とって。血ガス・採血。体温も」
「ST 上がってたら循環器コール。原因不明なら CT を考えます」
```

## メモ（確認状況）

- JRC 2025 の内容（VF・VT のアドレナリン「電気ショックが不成功ならできるだけ早く」・静脈路が第一選択・CPR 中の POCUS はルーチンにしない・ROSC 後の酸素と PaCO₂・体温 37.5℃ 以下）は **解説記事** で確認（[医学のすすめ](https://igaku-no-susume.com/jrc-2025-als/)）。JRC の原文は未確認
- VF・VT でアドレナリンを何回目のショック後に入れるかは、ガイドライン・コースで書き方が違う（AHA は 2 回目、ERC は 3 回目の後）。**受講するコースのテキストに合わせる**
- 体温管理：[AHA 2025 Part 11](https://www.ahajournals.org/doi/10.1161/CIR.0000000000001375)、[ERC・ESICM 2025](https://www.resuscitationjournal.com/article/S0300-9572(25)00321-1/fulltext)
- 低体温での薬の間隔は ERC 2025 の内容として紹介されていたもの
- CASA（エコーの順番）は一例。施設のやり方に合わせる
- ROSC 後の「CT で原因を探す」「けいれんの予防投与はしない」「予後は 72 時間以降」は一般的な考え方。細かい基準は ICU・施設のプロトコルで確認
