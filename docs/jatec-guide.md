# JATEC 実践ガイド（外傷初期診療）

> **方針**：外傷はまず **生理学（ABCDE）で命を守る**。診断名をつけるのは後でよい。
> 異常を見つけたら **その場で治す**（評価と蘇生を同時に行う）。
> **悪くなったら A に戻る**。**不安定なまま CT に行かない**。

- 対象：ER の外傷初療（成人が中心）
- 根拠：外傷初期診療ガイドライン JATEC 改訂第6版（日本外傷学会・日本救急医学会 監修、へるす出版、2021）。細かい数値は **自施設のプロトコルを優先** する
- 関連：**[PS チートシート（これだけ見る版）](jatec-ps-cheatsheet.md)**・[FAST テンプレ](fast-karte-template.md)・[心エコー](tte-karte-template.md)

## 0. 全体の流れ（これだけ覚える）

```
準備（MIST・感染防御・物品・人）
  ↓
第一印象（15 秒：A・B・C・D をざっと見る → 重症感を共有）
  ↓  酸素・モニター・静脈路 2 本・採血
Primary Survey（PS）＋ 蘇生
  A 気道 → B 呼吸 → C 循環 → D 意識（切迫する D）→ E 脱衣・体温
  補助検査：胸部 X 線・骨盤 X 線・FAST・血ガス
  ↓  ★ 悪化したら A に戻る
（切迫する D があれば）頭部 CT を最初に
  ↓
Secondary Survey（SS）
  AMPLE → 頭から足まで → 背面（log roll）→ FIXES → 全身 CT（安定していれば）
  ↓
根本治療（手術・IVR・入院）/ 転院
  ↓
三次評価（翌日までにもう一度全身を診る）
```

**4 つのルール**

| ルール | 意味 |
|---|---|
| ① 生理学が先、解剖は後 | 「どこが壊れたか」より「何が足りないか（酸素・血液）」を先に直す |
| ② 見つけたらその場で治す | PS で緊張性気胸を見つけたら、C に進む前に脱気する |
| ③ 悪くなったら A から | 状態が変わったら、診断の途中でも PS をやり直す |
| ④ 不安定なら CT に行かない | CT 室で心停止させない。止血（手術・IVR）か転院を先に決める |

## 1. 準備（患者が来る前）

救急隊から連絡が来たら、到着までにこれを全部やる。

### 1-1. 情報を聞く：MIST

| | 内容 | 聞くこと |
|---|---|---|
| **M** | Mechanism（受傷機転） | 何が・どのくらいの速さで・どこに当たったか |
| **I** | Injury（損傷） | 見た目の損傷部位 |
| **S** | Sign（バイタル） | 意識・呼吸・脈・血圧・SpO₂ |
| **T** | Treatment（処置） | 固定・酸素・止血など、救急隊がしたこと |

＋ 年齢・性別・到着予定時刻・既往や内服（抗凝固薬）がわかれば聞く。

**高エネルギー事故**（車外放出、同乗者の死亡、車の横転・大きな変形、歩行者・自転車 vs 車、高所からの墜落、機械に挟まれた など）は、見た目が軽くても **重症として準備** する。

### 1-2. 感染防御

手袋・ガウン・マスク・ゴーグル（フェイスシールド）を **全員が到着前に** 着ける。

### 1-3. 物品

```
□ 酸素（リザーバー付きマスク）・BVM・吸引
□ 挿管セット・ビデオ喉頭鏡・輪状甲状靱帯切開セット
□ 39℃に加温した細胞外液（輸液加温器）
□ 輸血部に連絡（O 型 RBC・AB 型 FFP をすぐ出せるか）
□ 胸腔ドレーンセット・心嚢穿刺針
□ エコー（FAST）・ポータブル X 線（放射線科に連絡）
□ 骨盤バインダー（なければシーツ）・止血帯
□ 部屋を暖める・加温ブランケット
```

### 1-4. 人と役割

| 役割 | 位置 | 仕事 |
|---|---|---|
| **リーダー** | 足側（全体が見える所） | 指示を出す・PS を進める・決断する。**自分で手技に入り込まない** |
| A 担当 | 頭側 | 気道・頸椎保護（用手正中中間位固定）・挿管 |
| 処置担当 | 横 | 静脈路・採血・ドレーン・FAST |
| 看護師 | 横 | モニター・輸液・薬剤・時刻 |
| 記録 | 少し離れて | 時刻とバイタル・処置を記録 |

- 指示は **名前を呼んで** 出し、受けた人は **復唱** し、終わったら **報告** する（closed-loop）
  - 例：「〇〇さん、加温輸液 1L 全開でお願いします」→「加温輸液 1L 全開ですね」→（開始したら）「全開で始めました」
- 外科・脳外科・IVR が必要そうなら **到着前に一報** を入れておく

## 2. 第一印象（最初の 15 秒）

救急隊のストレッチャーの上で、**触りながら・話しかけながら** 同時に見る。

**やり方**：患者の肩に手を置いて「わかりますか？お名前言えますか？」と呼びかけながら、
もう片方の手で **橈骨動脈** を触れ、**皮膚** を見て触り、**胸の動き** を見る。

| 見るもの | 方法 | 異常のサイン |
|---|---|---|
| A 気道 | 声が出るか | 声が出ない・ゴロゴロ・いびき音 |
| B 呼吸 | 胸の動き・速さ・努力 | 速い・浅い・左右差・努力呼吸 |
| C 循環 | 橈骨動脈・皮膚 | 速く弱い・触れない・蒼白・冷汗 |
| D 意識 | 呼びかけへの反応 | 返事がおかしい・ぼんやり・反応しない |
| 外見 | 全体 | 大量の外出血・明らかな変形 |

**声に出して共有する（例）**

> 「声は出ます、気道は開通。呼吸は速いです。橈骨は速くて弱い、冷汗あり。意識はぼんやり。
> **ショックです！**」

**すぐやること（第一印象のあと、PS と並行）**

```
□ 酸素：リザーバー付きマスク 10L/分
□ モニター：心電図・SpO₂・血圧（自動で 2–5 分ごと）
□ 静脈路 2 本（18G 以上、肘の太い静脈）。取れなければ骨髄路
□ 採血：血算・生化学・凝固（フィブリノゲン）・血液型・交差・血ガス（乳酸・BE）・妊娠反応（女性）
□ 加温輸液を開始
□ ベッドに移す（頸椎を保護しながら、全員で一緒に）
```

- 噴き出す外出血は ABC を待たず、**その場で圧迫** する

## 3. Primary Survey（PS）と蘇生

**順番を守る**（A が悪いのに C の処置をしない）。それぞれ **見る・聞く・触る → 異常があればその場で処置** の順。

### A：気道（Airway）＋ 頸椎保護

**評価**
- 声が出て、普通に話せる → 気道は開通
- 閉塞のサイン：ゴロゴロ音・いびき音・stridor・**陥没呼吸**・**シーソー呼吸**・口の中の血液や吐物・顔面や頸部の大きな損傷・嗄声・気道熱傷（顔のやけど・すす・鼻毛が焦げている）

**処置（軽い順）**
1. **吸引**（血液・吐物）
2. **下顎挙上**（頭部後屈はしない＝頸椎を守る）
3. 経口・経鼻エアウェイ（頭蓋底骨折が疑わしければ経鼻はしない）
4. **確実な気道確保（気管挿管）**：頸椎カラーの前を外し、もう 1 人が頭を **用手正中中間位固定（MILS）** して挿管
5. 挿管できない・換気できない → **輪状甲状靱帯切開**（小児＝目安 12 歳未満は切開でなく穿刺）

**確実な気道確保（挿管）をする場面**

| どこの問題か | 具体例 |
|---|---|
| A | 気道閉塞、閉塞しそう（気道熱傷、頸部の血腫が大きくなる） |
| B | 酸素を投与しても低酸素、換気が足りない |
| C | 重症ショック（輸液・輸血に反応しない） |
| D | **切迫する D**（GCS ≤8 など。D の項を参照） |

**頸椎**：頸椎損傷が否定できるまで、カラーか用手で **ずっと保護** する。

**声に出す（例）**：「発語あり、A 開通。頸椎保護継続します」

---

### B：呼吸（Breathing）

**評価：頸部と胸を見る・聞く・触る・叩く**

| | 見ること |
|---|---|
| **見る** | 呼吸数・胸の動きの左右差・**奇異運動**（吸うと凹む部分）・開放創・**頸静脈怒張**・**気管の偏位** |
| **聞く** | 呼吸音の左右差（腋窩で聞くとわかりやすい） |
| **触る** | **皮下気腫**（雪を握るようなギュッギュッという感触）・圧痛・胸郭の動揺 |
| **叩く** | 鼓音（気胸）・濁音（血胸） |
| 補助 | SpO₂・**胸部 X 線（ポータブル AP）**・E-FAST（胸腔の液体・lung sliding） |

**PS で見つけてその場で治す胸部外傷：TAF3X**

| | 損傷 | 見つけ方 | その場の処置 |
|---|---|---|---|
| **T** | 心タンポナーデ | ショック＋頸静脈怒張＋心音が小さい。**FAST で心嚢液** | 心嚢穿刺・心膜開窓、外科にすぐ連絡（多くは C で見つかる） |
| **A** | 気道閉塞 | A の項 | A の項 |
| **F** | フレイルチェスト | **奇異運動**・多発肋骨骨折 | 酸素・十分な鎮痛。換気が足りなければ挿管して陽圧換気 |
| **X** | **緊張性気胸** | **ショック＋片側の呼吸音低下＋頸静脈怒張＋気管偏位＋皮下気腫** | **X 線を待たずに** 脱気 → 胸腔ドレーン |
| **X** | 開放性気胸 | 胸の傷から空気を吸い込む音（sucking wound） | **3 辺テープ**（1 辺を開けて弁にする）→ 傷とは別の場所に胸腔ドレーン |
| **X** | 大量血胸 | 片側の呼吸音低下＋濁音＋ショック。X 線で片側が白い。E-FAST で胸腔液 | **胸腔ドレーン**＋輸血。開胸の目安を超えたら外科 |

**緊張性気胸の脱気**
- 太い留置針を **第 2 肋間鎖骨中線**、または **第 4–5 肋間中腋窩線** に刺す（胸壁が厚い人は第 4–5 肋間の方が届きやすい）
- 脱気は一時しのぎ。**必ず胸腔ドレーン** を入れる

**胸腔ドレーン**
- 位置：**第 4–5 肋間（乳頭の高さ）、中腋窩線〜前腋窩線**（腋窩の安全な三角）
- 太さ：成人の血胸は太め（28Fr 前後が目安、施設の基準に従う）
- 入れたら **排液量と時刻** を記録

**大量血胸で開胸を考える目安**
- ドレーンを入れた時点で **1,000 mL 以上**
- **200 mL/時 以上が 2–4 時間** 続く
- 輸血を続けないと循環が保てない

**声に出す（例）**：「呼吸数 30、右呼吸音低下、右皮下気腫あり、気管偏位なし、頸静脈怒張なし。SpO₂ 90%。胸部 X 線お願いします」

### C：循環（Circulation）

C は 6 つのステップで考える。

#### Step 1：ショックに気づく

**血圧が下がるのは遅い。** 血圧が下がる前に、皮膚・脈・意識で気づく。

**合言葉 SHOCK**（1 つでもあればショック）：**S**kin 皮膚が冷たい・湿潤 ／ **H**eart rate 脈が速い・弱い ／ **O**uter bleeding 外出血 ／ **C**RT ＞2 秒・**C**onsciousness 意識の変化（不穏も）／ **K**etsuatsu 血圧低下

**気づいたら FIX-C**：**F**AST ／ **I**V（静脈路 2 本・加温輸液）／ **X** 線（胸部・骨盤）／ **C**ompression（圧迫止血・骨盤バインダー・手術・IVR）。Step 2〜6 はこの中身

| サイン | 見方 |
|---|---|
| 皮膚 | 蒼白・冷たい・**冷汗**・CRT（爪を押して戻る時間）> 2 秒 |
| 脈 | 速い・弱い（橈骨が触れない → 血圧はかなり低い） |
| 意識 | 不穏・ぼんやり |
| 血圧 | **下がったら出血はすでに 30% 以上（成人で 1.5 L 以上）** |

**出血の量の目安（出血性ショックの重症度）**

| クラス | 失血量（成人） | 脈拍 | 血圧 | 意識 |
|---|---|---|---|---|
| I | < 15%（< 750 mL） | 正常 | 正常 | 正常 |
| II | 15–30%（750–1,500 mL） | 速い | 正常（脈圧は狭くなる） | 少し不安 |
| III | 30–40%（1,500–2,000 mL） | とても速い | **低い** | 不穏・混乱 |
| IV | > 40%（> 2,000 mL） | とても速い | とても低い | ぼんやり・反応がない |

**ショックインデックス（SI）＝ 心拍数 ÷ 収縮期血圧**：1.0 ≒ 1 L、1.5 ≒ 1.5 L、2.0 ≒ 2 L の出血の目安。

**ショックに見えにくい人**
- 高齢者、**β 遮断薬**・ペースメーカー → 脈が速くならない
- 若い人・妊婦 → 血圧がぎりぎりまで保たれる
- もともと高血圧の人 → 「正常な血圧」でも低い

#### Step 2：外出血を止める

- まず **直接圧迫**（ガーゼの上から強く押す）
- 四肢で圧迫しても止まらなければ **止血帯**。巻いた **時刻を記録**
- 頭皮の挫創は出血が多い → 圧迫するか、ステープラーで仮に閉じる

#### Step 3：見えない出血を探す（胸・腹・骨盤）

外から見えない大量出血は、ほぼこの 3 か所（＋大腿骨）。

| 場所 | 調べ方 | 見つかったら |
|---|---|---|
| **胸腔** | 胸部 X 線・E-FAST | 胸腔ドレーン（B の項） |
| **腹腔** | **FAST** | 不安定なら開腹（外科）。安定していれば CT |
| **後腹膜（骨盤）** | **骨盤 X 線（AP）** | **骨盤バインダー** → TAE（IVR）・創外固定 |
| 長管骨 | 見て触る | 牽引・副子固定 |

**骨折の出血量の目安**：骨盤 2,000 mL 以上になることも ／ 大腿骨 1,000–2,000 mL ／ 下腿 500–1,000 mL ／ 上腕 300–500 mL

**FAST の順番**：心嚢 → モリソン窩（＋右胸腔）→ 脾周囲（＋左胸腔）→ 膀胱直腸窩。
**状態が変わったら繰り返す**。書き方は [FAST テンプレ](fast-karte-template.md) へ。

**骨盤バインダー**
- 不安定型の骨盤骨折（骨盤の輪が開いている・ずれている）＋ショックで装着
- 位置は **大転子の高さ**（腸骨稜ではない。高すぎると効かない）
- 骨盤の用手的な動揺テストは出血を増やす。X 線で不安定型とわかれば **しない**

#### Step 4：出血以外のショックを探す

外傷のショックは **まず出血** と考える。そのうえで、これを見逃さない。

| 種類 | 原因 | 手がかり |
|---|---|---|
| 閉塞性 | **緊張性気胸** | 頸静脈怒張・呼吸音低下・気管偏位（B の項） |
| 閉塞性 | **心タンポナーデ** | 頸静脈怒張・FAST で心嚢液 |
| 神経原性 | 頸髄・上位胸髄損傷 | **徐脈**・**皮膚が温かい**・四肢麻痺・腹式呼吸。**出血を否定してから** 考える |
| 心原性 | 鈍的心損傷 | 不整脈・心電図変化・心エコーで壁運動異常 |

#### Step 5：蘇生（輸液・輸血）

**初期輸液**
- 39℃ に加温した細胞外液を **成人 1 L（小児 20 mL/kg）を目安に急速投与** し、反応を見る
- 晶質液を入れすぎない（薄まって血が止まりにくくなる・体温が下がる）
- 明らかな大量出血なら、**輸液の反応を待たずに輸血** を始める

**反応で 3 つに分ける**

| 反応 | どうなったか | 意味 | 次の一手 |
|---|---|---|---|
| **Responder** | 改善して、そのまま安定 | 出血は止まっている可能性 | SS へ。ただし再評価を続ける |
| **Transient responder** | いったん良くなるが、また悪くなる | **出血が続いている** | **輸血開始**・止血術（手術・IVR）の準備・専門医コール |
| **Non-responder** | 良くならない | **大量出血が続いている** or 出血以外のショック | **すぐ止血術**＋大量輸血。閉塞性ショックを再確認 |

**輸血**
- 緊急時は交差を待たずに **O 型 RBC**、FFP と血小板は **AB 型**
- 大量出血では RBC と FFP を **1:1 に近い比率** で入れる（施設の大量輸血プロトコルに従う）
- **トラネキサム酸**：受傷 **3 時間以内** に 1 g を 10 分で静注 → その後 1 g を 8 時間で（3 時間を過ぎたら効果が乏しい）
- カルシウムも下がる → イオン化カルシウムを見て補う

**血圧の目標**
- 止血が終わるまでは **血圧を上げすぎない**（収縮期 80–90 mmHg 程度が目安。出血を増やさないため）
- **頭部外傷があるときは低血圧を避ける**（脳の血流を保つ）

**死の三徴（低体温・アシドーシス・凝固障害）を防ぐ**
- 低体温：輸液・輸血を加温、部屋を暖める、体を覆う
- アシドーシス：乳酸・BE を血ガスで追う（改善すれば蘇生がうまくいっている）
- 凝固障害：早めに FFP・フィブリノゲン（施設によりクリオ・濃縮製剤）

#### Step 6：止血を決める（ここが一番大事）

- Transient / Non-responder は **輸液を続けても治らない。止血するしかない**
- 出血源ごとに：胸 → 開胸、腹 → 開腹（ダメージコントロール手術）、骨盤 → バインダー＋TAE
- **早く外科・IVR に連絡**。自施設でできなければ **すぐ転院を決める**
- REBOA（大動脈遮断バルーン）は止血までの一時しのぎ

**声に出す（例）**：「HR 130、BP 82/50、冷汗あり、CRT 3 秒。ショックです。FAST、モリソン陽性。骨盤 X 線、不安定型。バインダー巻きます。輸血を O 型で 4 単位、FFP も 4 単位お願いします。トラネキサム酸 1 g。外科と IVR コールしてください」

---

### D：意識（Dysfunction of CNS）

**評価：まいど**（**ま**ひ・**い**しき・**ど**うこう）
- **麻痺**：片麻痺の有無（手足が左右同じように動くか）
- **意識**：**GCS**（E・V・M を分けて言う）
- **瞳孔**：大きさ・左右差・対光反射

**切迫する D（すぐ動く必要がある頭部外傷）**

```
□ GCS 合計 8 点以下
□ 経過中に GCS が 2 点以上下がった
□ 脳ヘルニアのサイン：瞳孔不同・片麻痺・Cushing 現象（高血圧＋徐脈）
```

**切迫する D があったら**
1. **確実な気道確保（挿管）**
2. **脳神経外科にすぐ連絡**
3. ABC が安定したら、**SS の最初に頭部 CT**

**二次性脳損傷を防ぐ**（脳を守る＝ABC を守ること）
- 低酸素を避ける（SpO₂ を保つ）
- 低血圧を避ける
- 換気は正常に（PaCO₂ 35–45 mmHg 程度）。過換気は脳ヘルニアのサインがあるときの一時的な手段だけ

**注意**：意識が悪いのを「頭を打ったから」と決めつけない。**低酸素・ショック・低血糖・アルコール・薬** でも意識は悪くなる。血糖を測る。

**声に出す（例）**：「GCS E3 V4 M6 の 13 点、瞳孔 3 mm 左右差なし、対光反射あり、麻痺なし。切迫する D なし」

---

### E：脱衣と体温（Exposure & Environment）

- 服は **はさみで切って全部脱がせる**（動かさない）
- 外表を見る：外出血・開放創・変形・刺創（刺し傷は小さくても深い）
- **体温を測る**
- **すぐ覆う**：毛布・加温ブランケット・部屋を暖める・濡れた服を除く
- 背面は SS の log roll で見る（X 線の板を入れるときに見てもよい）

**声に出す（例）**：「全身脱衣、明らかな外出血なし、右大腿に変形あり。体温 35.6℃、保温します」

---

### PS 中の補助検査（まとめ）

| 検査 | いつ | 何を見る |
|---|---|---|
| モニター | 最初から | 心電図・SpO₂・血圧（頻回に） |
| **胸部 X 線（AP）** | B・C | 気胸・血胸・多発肋骨骨折・縦隔拡大・チューブの位置 |
| **骨盤 X 線（AP）** | C | 不安定型骨盤骨折 |
| **FAST / E-FAST** | C（B でも） | 心嚢・腹腔・胸腔の液体、気胸 |
| 血ガス | 静脈路と同時 | 乳酸・BE・Hb・イオン化 Ca・血糖 |

**PS でやらないこと**：頸椎 X 線・四肢の X 線・CT（不安定なとき）・細かい縫合・長い病歴聴取。

### PS の終わりに宣言する

> 「PS 終了します。A 開通。B 右気胸と血胸にドレーン挿入、排液 400 mL。C 輸液 1 L で一時改善後に再低下、transient responder、輸血中。FAST 脾周囲と膀胱直腸窩で陽性、骨盤 X 線で不安定型、バインダー装着済み。D GCS 13、切迫する D なし。E 体温 35.6℃、保温中」

そして決める：**止血術が必要か → 自施設でできるか → できないなら転院**。

## 4. Secondary Survey（SS）

**SS に入る条件**：PS の異常に対処して、バイタルが少なくとも悪化していない。
**途中で悪くなったら、SS をやめて PS（A）に戻る**。

**切迫する D があれば、SS の最初に頭部 CT**。

### 4-1. 病歴：AMPLE

| | 内容 | 特に聞くこと |
|---|---|---|
| **A** | Allergy（アレルギー） | 造影剤・薬 |
| **M** | Medication（内服） | **抗凝固薬・抗血小板薬**・β 遮断薬・インスリン |
| **P** | Past history & Pregnancy（既往・妊娠） | 心疾患・肝疾患・透析・妊娠の可能性 |
| **L** | Last meal（最後の食事） | 時刻（挿管・手術の誤嚥リスク） |
| **E** | Events & Environment（受傷の状況） | 何が先か（失神・けいれん・低血糖で事故を起こした？）・寒冷・汚染 |

本人が話せなければ、救急隊・家族・目撃者から聞く。

### 4-2. 頭から足まで

| 部位 | 見る・触ること | 探す損傷 |
|---|---|---|
| **頭部** | 頭皮の挫創・陥没、Battle 徴候（耳の後ろの皮下出血）、パンダの目、耳・鼻からの髄液や血液 | 頭蓋骨骨折・**頭蓋底骨折**（→ 経鼻胃管・経鼻エアウェイは禁止） |
| **顔面** | 眼（視力・眼球運動・瞳孔）、顔の骨の動揺、かみ合わせ、口の中の出血 | 顔面骨折・眼外傷（気道に影響しないか） |
| **頸部** | カラーの前を外して MILS：気管偏位・頸静脈・皮下気腫・**大きくなる血腫**・後頸部の圧痛 | 血管損傷・気道損傷・頸椎損傷 |
| **胸部** | 視診・聴診・触診、胸部 X 線を読み直す | **PATBED2X**（下の表） |
| **腹部** | 圧痛・腹膜刺激症状・膨満・**シートベルト痕** | 実質臓器損傷・**腸管・腸間膜損傷**（シートベルト痕は Chance 骨折も） |
| **骨盤** | X 線で評価（不安定型なら動揺テストはしない） | 骨盤骨折 |
| **会陰・直腸** | 会陰・陰嚢の血腫、**外尿道口の出血**、必要なら直腸診（肛門括約筋の緊張・前立腺の位置・血液） | 尿道損傷・直腸損傷・脊髄損傷 |
| **四肢** | 変形・腫脹・圧痛・開放創・末梢の脈・感覚と運動 | 骨折・開放骨折・血管損傷・**コンパートメント症候群**（見た目より強い痛み・他動的に伸ばすと痛い） |
| **背面** | **log roll**（頭側の人の合図で 4–5 人で同時に回す）：背中の創・脊柱の圧痛・変形・段差 | 脊椎損傷・背部の刺創 |
| **神経** | GCS の再評価・瞳孔・四肢の運動と感覚（どの高さから感覚がないか） | 頭部外傷の悪化・**脊髄損傷のレベル** |

### 4-3. SS で探す胸部外傷：PATBED2X

PS の TAF3X（すぐ死ぬ）に対し、こちらは **見逃すと後で死ぬ** 損傷。

| | 損傷 | 手がかり | 次の一手 |
|---|---|---|---|
| **P** | 肺挫傷 | 低酸素が時間とともに悪化。X 線の陰影は **遅れて出る** | 酸素・必要なら陽圧換気。輸液を入れすぎない |
| **A** | 大動脈損傷 | **縦隔拡大**・大動脈弓の輪郭不明瞭・左血胸・第 1–2 肋骨骨折 | **造影 CT**。心拍数と血圧を下げて管理、心臓血管外科 |
| **T** | 気管・気管支損傷 | 皮下気腫が広がる・**ドレーンからの空気漏れが止まらない** | 気管支鏡・外科 |
| **B** | 鈍的心損傷 | 不整脈・心電図変化・胸骨骨折 | **12 誘導心電図**・トロポニン・心エコー・モニター継続 |
| **E** | 食道損傷 | 縦隔気腫（特に貫通性外傷） | CT・内視鏡／造影 |
| **D** | 横隔膜損傷 | X 線で胃管の先が胸の中・横隔膜の挙上（**左に多い**） | CT・外科 |
| **X** | 気胸（緊張性でない） | X 線・E-FAST | 胸腔ドレーン（陽圧換気・搬送の前は特に） |
| **X** | 血胸（大量でない） | X 線・E-FAST | 胸腔ドレーン |

### 4-4. SS の締め：FIXES

| | 内容 | ポイント |
|---|---|---|
| **F** | Finger & Tube（指と管） | 直腸診・**胃管**（頭蓋底骨折疑いは経口で）・**尿道カテーテル**（下の禁忌を確認） |
| **I** | iv（投薬） | 鎮痛・**破傷風の予防**・開放骨折には早く抗菌薬 |
| **X** | X-ray（追加の画像） | 四肢の X 線・CT |
| **E** | ECG | 12 誘導心電図（鈍的心損傷・受傷の原因が不整脈でないか） |
| **S** | Splint（副子固定） | 骨折の固定（痛みと出血を減らす）。固定前後で末梢の脈・感覚を確認 |

**尿道カテーテルを入れてはいけないサイン（尿道損傷を疑う）**
- 外尿道口からの出血
- 会陰・陰嚢の血腫
- 直腸診で前立腺が高い位置にある・触れない

→ 泌尿器科に相談、逆行性尿道造影。

### 4-5. CT

- **循環が安定していれば** 全身 CT（頭部単純 → 頸椎 → 体幹の造影）
- 不安定（transient / non-responder）なら **CT に行かず** 止血術・転院を優先
- CT 室にも **医師が付いていく**（モニター・輸液・輸血・気道物品を持って）

---

## 5. 再評価・三次評価

**再評価**
- バイタルは頻回に。**状態が変わったら A から** やり直す
- FAST は循環が変わったとき・時間をおいて **繰り返す**
- 処置のあと（挿管・ドレーン）は、効いているか・位置が正しいかを確認（X 線）

**三次評価（tertiary survey）**
- 入院後 **24 時間以内**（意識が戻ったときも）に、もう一度 **頭から足まで** 診察し、画像を見直す
- 見逃しやすい所：**手指・足・手首・足首**・顔面・肋骨・脊椎・小腸（腸管損傷は後から症状が出る）

---

## 6. 転院の判断

- 自施設で根本治療（手術・IVR・脳外科・ICU）ができなければ、**PS の時点で転院を決めてよい**。CT を撮ってから決めると遅れる
- 転院前にやること：
  - **A と B を確保**（必要なら挿管・胸腔ドレーン。搬送中は処置しにくい）
  - 静脈路 2 本・輸血をつなぐ・保温
  - 情報を渡す：MIST・PS の所見・処置・画像（CD）・時刻
- 転院先の医師と **医師同士で直接** 話す

## 7. 実践シナリオ（1 例を最後まで）

### 救急隊からの連絡

> 40 代男性。バイク運転中に乗用車と衝突、約 5 m 飛ばされた。
> M：バイク vs 乗用車、約 5 m 飛ばされた。I：右胸の痛み、右大腿の変形。
> S：JCS 1、呼吸 28、脈 120、血圧 100/70、SpO₂ 92%（酸素 10L）。T：全脊柱固定、酸素投与。到着 10 分後。

→ **高エネルギー事故**。外科・IVR に一報、O 型 RBC の準備、加温輸液、ドレーンセット、エコー、ポータブル X 線を呼ぶ。

### 時系列

```
0:00 到着・第一印象
  リーダー「わかりますか？お名前言えますか？」→ 返事はあるがぼんやり
  リーダー「A 開通。呼吸速い。橈骨速く弱い、冷汗あり。ショックです！」
  → 酸素 10L、モニター、静脈路 2 本・採血、加温輸液 全開。全員でベッドへ移動

0:02 A：発語あり、口腔内に血液なし → A 開通。頸椎保護継続
0:03 B：RR 30、右呼吸音低下、右胸に皮下気腫、気管偏位なし、頸静脈怒張なし、SpO₂ 90%
       → 胸部 X 線：右気胸＋血胸、右肋骨多発骨折
       → 右胸腔ドレーン挿入：排液 400 mL、空気漏れあり → SpO₂ 96% に改善
0:10 C：HR 130、BP 84/52、冷汗、CRT 3 秒 → ショック
       FAST：心嚢−、モリソン−、脾周囲＋、膀胱直腸窩＋
       骨盤 X 線：不安定型骨盤骨折 → 骨盤バインダー（大転子の高さ）
       輸液 1 L で BP 102/60 → 10 分後に 86/50（transient responder）
       → O 型 RBC・AB 型 FFP 開始、トラネキサム酸 1 g、外科・IVR にコール
0:18 D：GCS E3 V4 M6 = 13、瞳孔 3 mm 左右差なし、麻痺なし → 切迫する D なし。血糖 140
0:20 E：全身脱衣、右大腿の変形（開放創なし）、体温 35.6℃ → 加温ブランケット
0:22 「PS 終了」宣言
       輸血で BP 110/64、HR 105 で安定 → 外科・IVR と相談し、医師付き添いで造影 CT
0:35 CT：脾損傷（造影剤の血管外漏出あり）、骨盤骨折（漏出あり）、右大腿骨骨幹部骨折
       → IVR で脾動脈・内腸骨動脈の TAE。大腿骨は牽引 → 後日手術
     SS（IVR 前後）：AMPLE（内服なし・アレルギーなし・最後の食事 12 時）
       FIXES：直腸診（骨盤骨折があるので直腸損傷を確認：血液−・前立腺は正常の位置）、外尿道口出血なし → 尿道カテ、胃管、破傷風トキソイド、12 誘導（洞頻脈）、右下肢 副子
翌日 三次評価：左手の舟状骨骨折を新たに発見
```

**この例のポイント**
- B の問題（気胸・血胸）を先に治してから C に進んだ
- 輸液 1 L で一時改善 → 再低下 = **出血が続いている** → 輸液を足すのではなく **輸血＋止血の準備**
- CT は **輸血で安定してから**、医師が付いて行った
- 三次評価で手の骨折を拾った

## 9. よくある落とし穴

| 落とし穴 | 正しくは |
|---|---|
| 血圧が保たれているから大丈夫 | 血圧は最後に下がる。**皮膚・脈・意識・SI・乳酸** で判断 |
| 緊張性気胸を X 線で確かめてから脱気 | 臨床所見で疑ったら **X 線を待たずに** 脱気 |
| 輸液に反応しないのでさらに輸液 | Transient / Non-responder は **輸血と止血**。晶質液を入れ続けない |
| 不安定なまま CT へ | CT 室で心停止する。**止血術か転院が先** |
| FAST 陰性 = 出血なし | 後腹膜（骨盤・腎）は見えない。早い時期は陰性になる。**繰り返す** |
| 骨盤バインダーを腸骨稜に巻く | **大転子の高さ** に巻く |
| 意識障害は頭部外傷のせい | 低酸素・ショック・低血糖・アルコール・薬を除外する |
| 高齢者は脈が速くないから軽症 | β 遮断薬・ペースメーカーで頻脈にならない。抗凝固薬で出血しやすい |
| 頭部外傷で血圧を低めに保つ | 頭部外傷では **低血圧を避ける** |
| リーダーが手技に入り込む | リーダーは全体を見る。手技は他の人に任せる |
| 受傷の原因を考えない | 事故の前に **失神・けいれん・低血糖・不整脈** がなかったか（AMPLE の E） |
| SS で終わり | 翌日までに **三次評価**。手足の小さな骨折・腸管損傷を拾う |
| 低体温を放置 | 低体温は凝固障害を悪化させる。**最初から保温** |
