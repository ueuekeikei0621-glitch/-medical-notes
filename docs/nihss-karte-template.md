# NIHSS 実施ガイド＆カルテテンプレ（声かけ付き）

> **方針**：**1a → 11 の順番どおり**、**その場で採点**、**ヒントを出さない**。
> 点数は「患者が実際にやったこと」で付ける。「本当はできるはず」で付けない。
> **点数が低い＝軽症ではない**（右半球・後方循環は低く出る）。立てる人は歩行も見る。
> わからない言葉は **9 章の用語集** へ。

- 対象：急性期脳卒中疑い（tPA・TNK・血栓回収の判断、経時評価）
- 所要時間：慣れれば 5〜8 分
- 更新日：2026-11-08

---

## 1. テンプレ（コピペ用）

```
【NIHSS】（　:　）合計　　/42　前回　（　:　）
1a 意識 　 1b 月・年齢 　 1c 開閉眼・握る 　
2 注視 　 3 視野 　 4 顔面 　
5 上肢 右　 左　  6 下肢 右　 左　
7 失調 　 8 感覚 　 9 言語 　 10 構音 　 11 消去・無視 　
根拠：（2 点以上・UN・理由が紛らわしい項目だけ一言）
評価の制限：なし / 失語・挿管・鎮静・既存障害（　）
```

**点数の幅（迷ったらここ）**

```
1a 0-3 | 1b 0-2 | 1c 0-2 | 2 0-2 | 3 0-3 | 4 0-3
5・6 各 0-4/UN（左右別）| 7 0-2/UN | 8 0-2 | 9 0-3 | 10 0-2/UN | 11 0-2
```

**書き方のルール**
- 左右は **患者の** 左右
- 5・6 は **左右別に** 書く。合計には両方とも入れる（最大 42 点）
- **UN（評価不能）** にできるのは **5・6・7（切断・関節固定）と 10（挿管など）だけ**。合計に入れず、理由を書く（`合計 12（10 UN：挿管）`）
- 「失語のため 1b＝2」のように、**症状と点数の理由がずれる項目** は根拠に一言書く（後で見た人が誤解しない）
- 経時評価は **前回との差と、どの項目が変わったか** を書く

## 2. 記載例

**左 MCA 領域梗塞疑い（左半球：失語あり）**
```
O：NIHSS（10:15）合計 17
1a 0  1b 2  1c 1  2 1  3 2  4 2  5 右3 左0  6 右2 左0  7 0  8 1  9 2  10 1  11 0
根拠：1b 失語で質問を理解できず。1c 見本で開閉眼のみ可。2 左共同偏視、人形の目で右へ越える。
　　　3 右同名半盲。9 答えから絵の内容が推測できない。
A：左 MCA 領域の LVO 疑い（共同偏視＋失語＋右片麻痺）→ CT/CTA、血栓溶解の適応確認、血栓回収チームへ連絡
```

**右 MCA 領域梗塞疑い（右半球：無視が主体）**
```
O：NIHSS（14:40）合計 12
1a 0  1b 0  1c 0  2 1  3 2  4 2  5 右0 左2  6 右0 左1  7 0  8 1  9 0  10 1  11 2
根拠：2 右共同偏視、左から声をかけると越える。3 左同名半盲。11 左の触覚消去＋左手を自分の手と認めない。
A：右 MCA 領域梗塞疑い。言語の配点がないぶん左半球より点が低く出る → 点数でなく所見で LVO を疑う
```

**小脳梗塞疑い（後方循環：NIHSS が低く出る）**
```
O：NIHSS（3:20）合計 3
1a 0  1b 0  1c 0  2 0  3 0  4 0  5 右0 左0  6 右0 左0  7 2  8 0  9 0  10 1  11 0
根拠：7 右指鼻・右踵膝で失調（筋力低下なし）。10 一部不明瞭だが理解可。歩行 自力不可（NIHSS には入らない）。
A：右小脳梗塞疑い。NIHSS 3 でも歩けない → 軽症扱いしない。MRI、神経内科コール（めまいは vertigo-karte-template.md）
```

**血栓溶解後の経時評価（短く書く）**
```
NIHSS 11:00 合計 9（10:45 合計 9）変化なし
NIHSS 11:15 合計 14（↑5：1a 0→1、5 右 2→4、9 1→3）→（投与中なら中止）緊急 CT、上級医コール
```

## 3. 始める前に

### 3-1. 共通ルール（ここを外すと点数がブレる）

1. **1a → 11 の順番どおり** に行う
2. **その場で記録** し、あとから戻って点数を変えない
3. **患者がやったこと** を採点する。「本当はできるはず」は採点しない
4. **教えない・何度もやり直させない**。ヒントを出した後の答えは採点しない（例外：5・6 は声と身ぶりで励ましてよい）
5. 1b・1c は **最初の答え／最初の試み** だけ採点
6. UN にできるのは **5・6・7・10 だけ**。それ以外は、評価しにくくても必ず点数を選ぶ
7. **既存の障害も点数に入る**（感覚だけは脳卒中によるものだけ）。既存障害は「評価の制限」に書いて、変化で見る

### 3-2. 準備するもの

- **時計**（または声に出して数える）
- **感覚用のピン**：使い捨て（つまようじ・安全ピンを 1 人 1 本）。皮膚を刺さない
- **検査カード**：絵カード・呼称カード・読み上げ文・単語リスト（**施設の日本語版**。英語原文は 8 章）
- **患者の眼鏡**（9 の読み上げで必要）

### 3-3. 最初のひと言

```
「〇〇さん、これから脳の働きを確かめる検査をします。5 分くらいで終わります。
　簡単すぎる質問もありますが、皆さんに同じように聞いているので、そのまま答えてくださいね」
```

「簡単すぎる質問」と先に言っておくと、月や年齢を聞かれて気分を害する人が減る。

### 3-4. 流れの早見表（これだけで一通りできる）

| 項目 | 声かけ（ひと言） | 見るもの |
|---|---|---|
| 1a 意識 | 「〇〇さん、わかりますか？」 | 声だけで起きるか／刺激が要るか |
| 1b 質問 | 「今は何月ですか？」「今おいくつですか？」 | 最初の答えが正しいか |
| 1c 従命 | 「目を閉じて…開けて」「手をグーに…パーに」 | 2 段階ずつできるか |
| 2 注視 | 「顔は動かさず、目だけで指を追ってください」 | 左右へ動くか・偏視 |
| 3 視野 | 「私の鼻を見たまま、指が何本か教えてください」 | 4 象限＋両側同時刺激 |
| 4 顔面 | 「イーと歯を見せて」「眉を上げて」「目をぎゅっと」 | 左右差・上下どこまでか |
| 5 上肢 | 「腕を前に伸ばして、10 数えるまで下ろさないで」 | 10 秒保てるか |
| 6 下肢 | 「足を伸ばしたまま上げて、5 数えるまでそのまま」 | 5 秒保てるか |
| 7 失調 | 「鼻と私の指を交互に」「かかとですねをなぞって」 | 筋力で説明できない拙劣さ |
| 8 感覚 | 「目を閉じて。左右で同じくらいチクッとしますか？」 | 左右差 |
| 9 言語 | 「この絵で何が起きていますか？」「これは何？」「読んでください」 | 失語の程度 |
| 10 構音 | 「この言葉を読んでください」 | 発音の明瞭さ |
| 11 消去・無視 | 「目を閉じて。右・左・両方、どこを触った？」 | 同時刺激で片側が消えるか |

## 4. 項目ごとの声かけ・やり方・採点

### 4-1. 1a 意識水準

**声かけ**
```
（部屋に入りながら、まず様子を見る）
「〇〇さん、こんにちは。わかりますか？」          ← 普通の声
  反応なし → 「〇〇さん！」（大きな声＋肩を軽くたたく）
  反応なし → 痛み刺激（爪の付け根を押す・胸骨をこする）
```

| 点 | 状態 | 目安 |
|---|---|---|
| 0 | 清明。すぐ反応する | 部屋に入って声をかけたら普通に会話できる |
| 1 | 清明ではないが、**軽い刺激** で目覚めて答える・従う | ウトウトしているが、声かけ・軽く触れると起きて会話できる |
| 2 | **繰り返しの刺激、または強い刺激・痛み** でやっと反応する（パターン化していない動き） | 痛みを払いのける |
| 3 | **反射的な動き**（除皮質・除脳姿勢）か自律神経反応だけ、または全く反応がない（弛緩・反射消失） | 痛みで四肢が伸展するだけ |

**落とし穴**
- 挿管・言葉の壁・口の外傷があっても **1a は必ず点数を選ぶ**（UN はない）
- **3 は痛みに対して反射姿勢以外の動きが全くないときだけ**。払いのけ・逃避があれば 2
- 1a＝3（昏睡）なら、他の項目に決まった点が付く → 5 章
- 鎮静薬の影響があれば「評価の制限」に書く

### 4-2. 1b 意識：質問

**声かけ**
```
「今は何月ですか？」
「〇〇さんは今、おいくつですか？」
```

**やってはいけない聞き方**
```
×「今は 11 月ですよね？」     ← 答えを言っている
×「何月か分かりますか？」     ← 「はい」で終わってしまう
×「10 月？ 11 月？」          ← 選択肢を出している
×（考えている間にうなずく・首をかしげる）← 表情もヒントになる
```

| 点 | 状態 |
|---|---|
| 0 | 2 つとも正解 |
| 1 | 1 つだけ正解 |
| 2 | 2 つとも不正解 |

- 聞くのは **月と年齢だけ**（日付・曜日・場所は聞かない）
- **近くても部分点なし**（「70 くらい」→ 不正解）
- **最初の答えで採点**。言い直しても点は変えない
- 質問の意味が分からない（**失語・昏迷**）→ **2**
- 話せない（**挿管・口の外傷・重い構音障害・言葉の壁** など失語以外の理由）→ **1**

### 4-3. 1c 意識：従命

**声かけ**
```
「目を閉じてください」 →（閉じたら）「目を開けてください」
「（麻痺のない方の）手をグーにしてください」 → 「パーにしてください」
```

| 点 | 状態 |
|---|---|
| 0 | 2 つともできる |
| 1 | 1 つだけできる |
| 2 | 2 つともできない |

- それぞれ **「閉じる→開ける」「握る→開く」まで** できて 1 つ正解
- **検者の指を握らせない**：把握反射と区別できない。握らせたなら「離してください」で離せるかまで見る
- 声だけで反応がなければ **見本を見せて**（検者が目を閉じて見せる・手を握って見せる）、その結果で採点
- 麻痺で完全にできなくても、**はっきりやろうとしていれば正解**
- 手が使えない（切断・外傷）→ 別の 1 段階の指示（「舌を出してください」など）に替える
- **最初の試みで採点**

### 4-4. 2 最良の注視

**声かけ**
```
「顔は動かさないで、目だけで私の指を追ってください」
（指を左右にゆっくり動かし、左端・右端で少し止める）
```

**指示が通らないとき**
```
・目を合わせてから、検者がベッドの右側 → 左側へ歩いて移動する（目で追ってくるか）
・人形の目（頭位変換眼球反射）：頭を左右に回し、目が反対へ動くか
  ※ 頸椎損傷の疑いがあればしない
```

| 点 | 状態 |
|---|---|
| 0 | 正常 |
| 1 | **部分的注視麻痺**：片目または両目の注視が不十分。**共同偏視があっても、自分の意思か人形の目で反対側へ越えられる**。単独の動眼・滑車・外転神経麻痺もここ |
| 2 | **強制偏視**、または人形の目でも越えられない完全注視麻痺 |

- **水平方向だけ** 見る（上下は採点しない）
- **失語でも必ず評価できる**（人形の目を使う）。目の外傷・失明でも反射で評価して点数を選ぶ
- 温度刺激検査（カロリック）はしない
- **共同偏視は LVO を疑う大事なサイン**。大脳病変では **病巣側を向く**（左 MCA → 左を向く）。脳幹病変やけいれん中は反対を向くことがある

### 4-5. 3 視野

**声かけ**
```
「私の鼻を見ていてください。目は動かさないでくださいね」
「こちらの目を手で隠してください」（片目ずつ行う場合）
「指が何本見えるか教えてください」
（右上・右下・左上・左下に、1 本・2 本・5 本を出す）
```

| 点 | 状態 |
|---|---|
| 0 | 視野欠損なし |
| 1 | **部分半盲**（四分盲を含む。はっきりした左右差があるときだけ） |
| 2 | **完全半盲** |
| 3 | **両側半盲**（皮質盲を含む全盲） |

- **4 象限**（右上・右下・左上・左下）を対座法で見る
- 指は **1・2・5 本** を使う（3・4 本は周辺視では区別しにくい）
- 片目ずつがよいが、協力が得にくければ両目で行う
- 指示が通らない → **威嚇**（手を目の横から素早く近づけ、まばたきするか）
- 数は言えなくても、**指が動いた方へちゃんと目を向けたら正常** としてよい
- 片目が失明・義眼 → 残った目で採点。**原因を問わず全盲なら 3**

**両側同時刺激（ここで行い、項目 11 に使う）**
```
（両手を左右に広げ、両方同時に指を動かす）
「どっちの指が動きましたか？ 右？ 左？ 両方？」
```
- 片方ずつなら分かるのに、**両方同時だと片側しか言わない** → **視覚性消去** → **項目 11** で採点する
- 原文は「消去があれば 1 点、結果を項目 11 に使う」とだけ書かれていて紛らわしい。**項目 3 は視野欠損だけで採点し、消去は項目 11 に入れる** 運用が一般的。施設内で統一しておく
- 半盲があると視覚の同時刺激はできない → 触覚（4-13）で 11 を見る

### 4-6. 4 顔面麻痺

**声かけ**
```
「歯を見せて、『イー』としてください」
「眉毛を上げて、おでこにしわを寄せてください」
「目をぎゅっとつぶってください」
（伝わらなければ、検者が自分の顔でやって見せる）
```

| 点 | 状態 |
|---|---|
| 0 | 正常・左右対称 |
| 1 | **軽い麻痺**：鼻唇溝が浅い、笑うと非対称 |
| 2 | **部分麻痺**：顔の **下半分** が完全またはほぼ完全に動かない |
| 3 | **完全麻痺**：片側または両側で、**上も下も** 動かない |

- 反応が乏しい・理解できない人 → **痛み刺激でのしかめ顔の左右差** を見る
- テープ・挿管チューブ・包帯で顔が隠れていたら、できる範囲で外して見る
- 脳卒中（中枢性）は **下半分が主体**（おでこは動く）→ 1 か 2 が多い
- おでこまで動かない（3）→ 末梢性顔面神経麻痺（ベル麻痺）や脳幹病変も考える

### 4-7. 5 上肢の運動（左右別）

**声かけ**
```
（座位）「腕をまっすぐ前に伸ばして、手のひらを下に向けてください」
（仰臥位）「腕を斜め上に伸ばして、手のひらを下に向けてください」
「私が 10 数えるまで、そのまま下ろさないでください」
（検者が腕を位置に置いて手を離し、声に出して、指でも見せながら数える）
「1、2、3、…、10」
```

| 点 | 状態 |
|---|---|
| 0 | 90°（仰臥位なら 45°）を **10 秒間保持** |
| 1 | **drift**：10 秒以内に下がるが、**ベッドや支えに付かない** |
| 2 | **重力に抗う力はある** が、位置まで上がらない／保てずベッドまで落ちる |
| 3 | **重力に抗えない**：置いた瞬間に落ちる |
| 4 | **全く動かない** |
| UN | **肩の切断・関節固定のときだけ**（理由を書く） |

- **座位 90°・仰臥位 45°**、**手のひらは下**（Barré 徴候を見る手のひら上とは違う）
- 公式は **片方ずつ、麻痺のない側から**
- 「下ろさないで！ もう少し！」と **励ますのはこの項目では OK**
- 失語の人：**声の調子と身ぶり** で励ます。**痛み刺激は使わない**
- **1 と 2 の境目は「ベッド（支え）に付いたか」**
- 指・手首の動きや回内は採点しない（腕の高さだけ見る）
- 痛み・拘縮・既存の麻痺があっても **点数は付ける**（UN にしない）。「評価の制限」に書く

### 4-8. 6 下肢の運動（左右別）

**声かけ**
```
（必ず仰臥位）「片足を、膝を伸ばしたまま持ち上げてください」
（検者が 30° に持ち上げて手を離す）
「5 つ数える間、そのままにしてください。1、2、3、4、5」
```

| 点 | 状態 |
|---|---|
| 0 | 30° を **5 秒間保持** |
| 1 | **drift**：5 秒以内に下がるが、**ベッドに付かない** |
| 2 | **重力に抗う力はある** が、5 秒以内にベッドへ落ちる |
| 3 | **重力に抗えない**：すぐベッドへ落ちる |
| 4 | **全く動かない** |
| UN | **股関節の切断・関節固定のときだけ**（理由を書く） |

- **必ず仰臥位**、片方ずつ、麻痺のない側から
- 励まし方・痛み刺激を使わない点は 5 と同じ

### 4-9. 7 運動失調

**声かけ**
```
指鼻指試験：
「人差し指で、ご自分の鼻と私の指を、交互にさわってください。できるだけ正確に」
（検者の指は、患者が腕を伸ばしきる位置に置く。左右とも）

踵膝試験：
「右のかかとを左の膝に乗せて、すねに沿ってまっすぐ足首まで滑らせてください。
　何回か繰り返してください」（反対も）
```

| 点 | 状態 |
|---|---|
| 0 | なし |
| 1 | 1 肢にあり |
| 2 | 2 肢以上にあり |
| UN | 切断・関節固定のときだけ（理由を書く） |

- **目は開けたまま**。視野欠損があれば見える側で行う
- 失明している人 → 腕を伸ばした位置から自分の鼻をさわってもらう
- **筋力低下で説明できないほどの拙劣さだけ** を失調とする（片麻痺のぎこちなさは失調ではない）
- **麻痺で動かせない・指示を理解できない → 0**（失調なし）。UN ではない
- 片側小脳病変を拾う項目だが、**歩行・体幹失調は入っていない** → 立てる人は歩行も見る（点数外。vertigo-karte-template.md の 6 章）

### 4-10. 8 感覚

**声かけ**
```
「目を閉じてください。これから軽くチクッとさせます」
（顔・腕・太もも・体幹の、左右の同じ場所を順番に）
「こっちと…こっち。同じくらいチクッとしますか？ 違うなら、どっちが鈍いですか？」
（鈍い側で）「さわられているのは分かりますか？」     ← 1 と 2 を分ける質問
```

| 点 | 状態 |
|---|---|
| 0 | 正常 |
| 1 | **軽〜中等度**：患側でチクッとしにくい・鈍い。または痛みは分からないが、**触られていることは分かる** |
| 2 | **重度〜脱失**：顔・腕・脚で **触られていることすら分からない** |

- 見るのは **腕（手ではない）・脚・体幹・顔**。手先・足先は末梢神経障害を拾ってしまう
- **脳卒中による感覚障害だけ** を採点する（糖尿病性神経障害などは除く）
- 失語・意識が悪い人 → 痛みでの **しかめ顔・逃避の左右差**
- **2 ははっきり示せたときだけ**。失語・昏迷の人はたいてい 0 か 1
- 両側の感覚脱失（脳幹梗塞）→ 2、反応がなく四肢麻痺 → 2、**昏睡（1a＝3）→ 自動的に 2**

### 4-11. 9 最良の言語

**声かけ**
```
（絵カードを見せて）「この絵の中で何が起きているか、できるだけ詳しく教えてください」
（呼称カードを 1 つずつ指して）「これは何ですか？」
（読み上げ文を見せて）「上から順に、声に出して読んでください」
```

| 点 | 状態 |
|---|---|
| 0 | 失語なし |
| 1 | **軽〜中等度**：流暢さや理解に明らかな低下はあるが、言いたいことは伝わる。**患者の答えから、絵やカードの内容が検者に分かる** |
| 2 | **重度**：断片的な言葉だけで、聞き手が推測・質問・当て推量しないと分からない。**患者の答えから、絵やカードの内容が分からない** |
| 3 | **無言・全失語**：使える発話も、聞いて理解する力もない |

- **1 と 2 の境目＝「患者の説明だけで、どの絵・どのカードか検者が当てられるか」**
- 理解の程度は、**ここまでの全項目の指示への反応** も合わせて判断する
- **3 は無言で、かつ 1 段階の指示にも全く従えないときだけ**
- 目が見えず資材が使えない → **手に物を持たせて名前を言ってもらう・復唱・自発話** で判断
- **挿管中 → 書いてもらう**
- **昏睡（1a＝3）→ 自動的に 3**
- 失語と構音障害を混同しない：**言葉の選び方・理解** の問題が失語（9）、**発音** の問題が構音障害（10）

### 4-12. 10 構音障害

**声かけ**
```
「これから言葉をいくつか読んでもらいます」
（読めなければ）「私の後に続けて言ってください」
（単語リストを 1 つずつ読ませる／復唱させる）
```

| 点 | 状態 |
|---|---|
| 0 | 正常 |
| 1 | **軽〜中等度**：少なくとも一部の単語が不明瞭。最悪でも、何とか聞き取れる |
| 2 | **重度**：失語では説明できないほど不明瞭で聞き取れない、または無言・構音不能 |
| UN | **挿管・その他の物理的な障害** のときだけ（理由を書く） |

- **「ろれつを見ます」と目的を言わない**（意識して丁寧に話してしまう）
- 普通に話せているように見えても、**必ず単語リストで確認** する
- 重い失語がある → **自発話の発音の明瞭さ** で採点
- 方言・入れ歯・もともとの話し方は、家族に「普段と比べてどうか」を聞くと判断しやすい

### 4-13. 11 消去現象と無視

項目 3 で視覚の両側同時刺激は済んでいる。ここでは **触覚** と **自分の体・病気の認識** を見る。

**声かけ**
```
（触覚の両側同時刺激）
「目を閉じてください。これから手の甲をさわります。
　右か、左か、両方か、教えてください」
（右だけ → 左だけ → 両方同時、を順番を変えて数回）

（自分の体・病気の認識）
（麻痺側の手を持ち上げて見せて）「この手は誰の手ですか？」
「体で動かしにくいところはありますか？」
```

| 点 | 状態 |
|---|---|
| 0 | 異常なし |
| 1 | **1 つの感覚**（視覚・触覚・聴覚のどれか）で両側同時刺激の消去、または空間・身体への不注意 |
| 2 | **高度の半側無視**、または **2 つ以上の感覚** で消去。**自分の手を認識しない**、一側の空間にしか注意を向けない |

- 診察全体を通して **片側ばかり見ている・反対側から話しかけても気づかない**、も無視の根拠になる
- **病態失認**（麻痺を認めない）も異常の根拠になる
- 失語があっても、両側に注意を向けていれば 0
- 重い視力障害で視覚刺激ができず、触覚が正常 → 0
- **異常があるときだけ点が付く → UN にはならない**
- 右半球病変（左側の無視）で目立つ

## 5. 評価しにくい人

| 状況 | 扱い |
|---|---|
| **昏睡（1a＝3）** | 1b＝2、1c＝2、5・6 は動きがなければ各 4、7＝0、**8＝2（自動）**、**9＝3（自動）**、10＝2。2・3・4・11 は人形の目・威嚇・痛みでのしかめ顔などの観察から判断 |
| **失語** | 1b：質問を理解できなければ 2。1c：見本を見せて採点。5・6：声の調子と身ぶりで励ます（痛み刺激はしない）。8：痛みへの反応の左右差 |
| **挿管** | 1a は必ず選ぶ。1b＝1。4 はテープを外せる範囲で。9 は書字で。10＝UN |
| **言葉が通じない（外国語）** | 失語ではないので 1b＝1。通訳を使う。1c・4・5・6 は身ぶりで |
| **視力障害・失明** | 2 は人形の目、3 は全盲なら 3、7 は腕を伸ばした位置から鼻、9 は手に持たせた物の呼称・復唱、11 は触覚で |
| **既存の麻痺・認知症** | そのまま採点する（感覚以外）。既存障害を「評価の制限」に書き、変化で判断する |
| **切断・関節固定** | 5・6・7 を UN（理由を書く）。合計に入れない |
| **鎮静中・けいれん後** | そのまま採点し、記録に書く。けいれん後の麻痺（Todd 麻痺）は時間とともに改善する |

## 6. 点数の使い方と限界

### 6-1. 重症度の目安

| 合計 | 目安 |
|---|---|
| 0 | 症状なし |
| 1–4 | 軽症 |
| 5–15 | 中等症 |
| 16–20 | 中等症〜重症 |
| 21–42 | 重症 |

あくまで目安。**点数だけで治療を決めない**。

### 6-2. 使いどころ

- **血栓溶解（tPA・TNK）**：点数が低くても、**生活に支障が出る症状**（失語・半盲・利き手の麻痺など）なら適応になりうる
- **血栓回収**：前方循環 LVO では「NIHSS 6 以上」が代表的な目安。**最新のガイドライン・施設基準を確認** する
- **LVO を疑うサイン**：**共同偏視**、**失語（左半球）または無視（右半球）**、**片麻痺** の組み合わせ（皮質徴候）
- **経時評価**：血栓溶解後は、投与中〜2 時間は 15 分ごと、6 時間まで 30 分ごと、24 時間まで 1 時間ごとが一般的（施設のプロトコルを優先）
- **悪化したら出血を疑って緊急 CT**。臨床試験では「合計 4 点以上の増加」が症候性頭蓋内出血の定義によく使われる。投与中なら中止して上級医へ

### 6-3. 限界（ここを知らないと見逃す）

- **左半球が高く、右半球が低く出る**：言語（1b・1c・9）の配点が大きいため、同じ大きさの梗塞でも右半球は点が低い
- **後方循環（小脳・脳幹）が低く出る**：**歩行・体幹失調・めまい・嚥下障害** は採点されない → **NIHSS 0〜3 でも歩けなければ重症**
- **点数が低い＝軽症ではない**：低 NIHSS の LVO もある
- **既存障害も点に入る**ので、絶対値より **前回との差** が大事

## 7. よくある間違い（まとめ）

| 間違い | 正しくは |
|---|---|
| 「今は 11 月ですよね？」と聞く | 「今は何月ですか？」。ヒント・選択肢を出さない |
| 言い直した答えで 1b を採点 | **最初の答え** で採点 |
| 検者の指を握らせて 1c 正解 | 把握反射の可能性。「グー・パー」で見る |
| 失語で 1b を 1 にする | 理解できない失語は **2**。1 は挿管・言葉の壁など失語以外 |
| 視覚性消去を 3 に入れる | **11** で採点する（3 は視野欠損だけ） |
| 上肢で手のひらを上にする | NIHSS は **手のひら下** |
| ベッドに付いたのに 1 点 | 付いたら **2 以上** |
| 片麻痺のぎこちなさを失調に | 筋力で説明できるなら **失調ではない**。麻痺で動かなければ 0 |
| 手先・足先で感覚を見る | **腕・太もも・体幹・顔** で見る |
| 「ろれつを見ますね」と言う | **目的を言わない** |
| 拘縮・痛みを UN にする | UN は **切断・関節固定・挿管だけ**。他は点数を付ける |
| NIHSS 2 点なので軽症として帰宅 | 後方循環・右半球は低く出る。**歩行** と生活への影響を見る |

## 9. 用語集

| 用語 | 意味 |
|---|---|
| **UN**（untestable） | 評価不能。5・6・7（切断・関節固定）と 10（挿管など）だけに使える。合計に入れない |
| **drift** | 挙上した腕・脚が、保持時間内にだんだん下がること |
| **共同偏視** | 両目が同じ方向に寄ったままになること。大脳病変では病巣側を向く |
| **人形の目**（頭位変換眼球反射） | 頭を左右に回すと、目が反対方向へ動く反射。指示に従えない人の注視評価に使う |
| **対座法** | 検者と向き合い、検者の指で患者の視野を調べる方法 |
| **威嚇瞬目** | 目の横から手を素早く近づけたときのまばたき。指示に従えない人の視野評価に使う |
| **同名半盲・四分盲** | 両目の同じ側（右または左）の視野が欠けるのが同名半盲。その上下どちらか 1/4 だけ欠けるのが四分盲 |
| **消去現象**（extinction） | 片側ずつの刺激は分かるのに、両側同時に刺激すると片側しか感じない現象 |
| **半側空間無視**（neglect） | 片側（多くは左）の空間や自分の体に注意が向かない状態。右半球病変で多い |
| **病態失認** | 麻痺などの自分の障害を認識しない状態 |
| **把握反射** | 手のひらに触れたものを反射的に握ってしまう反射。前頭葉病変で出る。1c の正解と区別する |
| **失語** | 言葉の理解・選択・組み立ての障害（9 で採点） |
| **構音障害** | 発音の障害。言葉の中身は正しいが、ろれつが回らない（10 で採点） |
| **LVO** | 主幹動脈閉塞（内頸動脈・中大脳動脈 M1 など）。血栓回収の対象 |
| **TNK** | テネクテプラーゼ。単回静注の血栓溶解薬 |
