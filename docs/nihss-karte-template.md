# NIHSS 実施ガイド＆カルテテンプレ（ER 用・声かけ付き）

> **1 章を覚えれば、見ないで 3〜5 分で終わる**（声かけ → 見る → 点）。文字のカードは使わない。
> ルールは 3 つ：**ヒントを出さない**・**その場で採点**・**患者がやったことで採点**。
> **点数が低い＝軽症ではない**（右半球・後方循環は低く出る）。立てる人は歩行も見る。
> 項目ごとの「速いやり方・何を見ているか」は **4 章**、評価しにくい人は **5 章**、わからない言葉は **7 章** へ。

- 対象：ER の脳卒中疑い（血栓溶解・血栓回収の判断、治療後の経時評価）
- 更新日：2026-11-09

## 1. ベッドサイド台本（見ないでできる・3〜5 分）

**覚え方**：**頭から下へ**（意識 → 目 → 顔 → 腕 → 脚）→ **手足の細かいところ**（失調 → 感覚）→ **最後に言葉の 3 つ**（言語 → 構音 → 無視）

**速くやるコツ（「早くしろ」と言われないために）**
- 看護師が点滴・採血・心電図をしている **横で同時に** 取る。CT 室への移動中や CT 台の上でもいい
- 点数は **声に出して** 記録係に書いてもらう（「1a ゼロ、1b 2…」）。足し算は最後
- **文字のカードは使わない**：10 は単語を言って **復唱** させる（公式に OK）。見せるのは 9 の **絵と呼称の 1 枚だけ**（スマホの写真でいい）
- 視野は指を動かして指さしてもらう → 3 と 11（視覚）が同時に終わる。8 のついでに 11（触覚）も済ませる
- 5・6 で全く動かなかった手足は 7 を飛ばす（0 点）

**準備**：血糖を先に（低血糖は脳卒中そっくり）。つまようじ（使い捨て）。絵・呼称カード 1 枚（スマホ）。

**最初のひと言**：「脳の働きを見る検査をします。簡単な質問もありますが、皆さんに聞いているので答えてくださいね」

**1a 意識**（0 秒：近づきながら見る）

- 「〇〇さん、わかりますか？」→ 反応がなければ大声＋肩たたき → 痛み刺激
- **0** すぐ反応 ／ **1** 軽い刺激で起きる ／ **2** 繰り返し・痛み刺激でやっと動く ／ **3** 反射のみ・無反応

**1b 質問**（5 秒）

- 「今は何月ですか？」「今おいくつですか？」
- 正解の数で **0**（2 問）／ **1**（1 問）／ **2**（0 問）
- ※ ヒント・選択肢・うなずきは禁止。最初の答えで採点。理解できない失語 → 2、挿管・言葉の壁 → 1

**1c 従命**（5 秒）

- 「目を閉じてください…開けてください」「手をグーにしてください…パーにしてください」
- できた数で **0**（2 つ）／ **1**（1 つ）／ **2**（0）
- ※ 検者の指は握らせない（把握反射と区別できない）。声で反応がなければ見本を見せる

**2 注視**（10 秒）

- 「顔は動かさないで、目だけで私の指を追ってください」（左右に 1 往復）
- **0** 正常 ／ **1** 片側へ動きが悪い・偏視があるが越えられる・眼筋麻痺 ／ **2** 越えられない強制偏視・完全注視麻痺
- ※ 従えなければ人形の目。共同偏視は LVO のサイン

**3 視野**（15 秒）

- 「私の鼻を見ていてください。指が動いたら、そっちを指さしてください」
- 両手を左右に広げ、**上で** 右だけ → 左だけ → 両方、**下でも** 同じように指を動かす
- **0** 正常 ／ **1** 部分半盲・四分盲 ／ **2** 完全半盲 ／ **3** 両側半盲・全盲
- 片方ずつは分かるのに、両方のとき片側しか指さない → **11 用にメモ**
- ※ 指示が通らなければ威嚇でまばたきを見る

**4 顔面**（5 秒）

- 「イーと歯を見せて。眉を上げて。目をぎゅっと閉じて」
- **0** 対称 ／ **1** 鼻唇溝が浅い・笑うと非対称 ／ **2** 顔の下半分がほぼ動かない ／ **3** 上も下も動かない

**5 上肢**（左右 10 秒ずつ・麻痺のない側から）

- 「腕を伸ばして、手のひらは下。10 数えるまで下ろさないでください」
- 臥位 45°（座位 90°）に置いて手を離し、声に出して 10 数える
- **0** 10 秒保つ ／ **1** 下がるがベッドに付かない ／ **2** ベッドに落ちるが重力に抗う ／ **3** すぐ落ちる ／ **4** 動かない
- ※ ベッドに付いたら 2 以上。「下ろさないで！」と励ましてよい

**6 下肢**（左右 5 秒ずつ・必ず臥位）

- 「膝を伸ばしたまま足を上げて、5 数える間そのままにしてください」
- 30° に置いて手を離し、声に出して 5 数える
- 上肢と同じ **0〜4**（時間は 5 秒）

**7 失調**（20 秒）

- 「人差し指で、ご自分の鼻と私の指を交互にさわってください」「かかとを反対の膝に乗せて、すねをなぞってください」
- **0** なし ／ **1** 1 肢 ／ **2** 2 肢以上
- ※ 麻痺で説明できる・動かない・理解できない → 0

**8 感覚**（15 秒）

- 「目を閉じてください。左右で同じくらいチクッとしますか？」（顔・腕・太もも。手先・足先は使わない）
- **0** 正常 ／ **1** 鈍いが触られているのは分かる ／ **2** 触られても分からない
- 目を閉じたまま両手の甲を同時に触る：「右・左・両方、どこを触りましたか？」→ 片側しか言わなければ **11 用にメモ**

**9 言語**（20〜40 秒）

- 絵を見せて「この絵で何が起きているか教えてください」→ 呼称の絵を指して「これは何ですか？」
- **0** 正常 ／ **1** 答えから絵・カードが当てられる ／ **2** 当てられない ／ **3** 無言・全く理解できない
- ※ 読み上げ文（文字）は急ぐなら省いて「読字未施行」と書く。カードがなければ身の回りの物で呼称（→ 4-1）。挿管なら筆談

**10 構音**（10 秒）

- 「私の後に続けて言ってください」→ 施設の日本語版の単語を 1 つずつ言う（カードは見せない）
- **0** 正常 ／ **1** 不明瞭だが聞き取れる ／ **2** 聞き取れない・無言 ／ **UN** 挿管など
- ※「ろれつを見ます」とは言わない。「パタカ」は補助（→ 4-1）

**11 消去・無視**（5 秒）

- 3・8 のメモ＋麻痺側の手を持ち上げて「この手は誰の手ですか？」
- **0** なし ／ **1** 1 つの感覚で消去・不注意 ／ **2** 2 つ以上の感覚で消去・自分の手と認めない
- ※ くわしくは **4-2**

**合計 /42**（UN は合計に入れない。UN にできるのは 5・6・7・10 だけ）

## 2. カルテテンプレ・記載例

### 2-1. テンプレ（コピペ用）

```
【NIHSS】（　:　）合計　　/42　前回　（　:　）
1a 意識 　 1b 月・年齢 　 1c 開閉眼・握る 　
2 注視 　 3 視野 　 4 顔面 　
5 上肢 右　 左　  6 下肢 右　 左　
7 失調 　 8 感覚 　 9 言語 　 10 構音 　 11 消去・無視 　
根拠：（2 点以上・UN・理由が紛らわしい項目だけ一言）
評価の制限：なし / 失語・挿管・鎮静・既存障害・資材なし・読字未施行（　）
```

```
点数の幅：1a 0-3 | 1b 0-2 | 1c 0-2 | 2 0-2 | 3 0-3 | 4 0-3
　　　　　5・6 各 0-4/UN（左右別）| 7 0-2/UN | 8 0-2 | 9 0-3 | 10 0-2/UN | 11 0-2
```

**書き方のルール**
- 左右は **患者の** 左右。5・6 は左右別に書き、**合計には両方入れる**（最大 42 点）
- UN は合計に入れず、理由を書く（`合計 12（10 UN：挿管）`）
- 「失語のため 1b＝2」のように、**症状と点数の理由がずれる項目** は根拠に一言
- 公式のやり方から省いたもの（読み上げ文・カード）は「評価の制限」に書く
- 経時評価は **前回との差と、変わった項目** を書く

### 2-2. 記載例

**左 MCA 領域梗塞疑い（左半球：失語あり）**
```
O：NIHSS（10:15）合計 17
1a 0  1b 2  1c 1  2 1  3 2  4 2  5 右3 左0  6 右2 左0  7 0  8 1  9 2  10 1  11 0
根拠：1b 失語で質問を理解できず。1c 見本で開閉眼のみ可。2 左共同偏視、人形の目で右へ越える。
　　　3 右同名半盲。9 答えから絵の内容が推測できない。
A：左 MCA 領域の LVO 疑い（共同偏視＋失語＋右片麻痺）→ CT/CTA、血栓溶解の適応確認、血栓回収チームへ連絡
```

**右 MCA 領域梗塞疑い（右半球：無視が主体）**
```
O：NIHSS（14:40）合計 12
1a 0  1b 0  1c 0  2 1  3 2  4 2  5 右0 左2  6 右0 左1  7 0  8 1  9 0  10 1  11 2
根拠：2 右共同偏視、左から声をかけると越える。3 左同名半盲。11 左の触覚消去＋左手を自分の手と認めない。
A：右 MCA 領域梗塞疑い。言語の配点がないぶん左半球より点が低く出る → 点数でなく所見で LVO を疑う
```

**小脳梗塞疑い（後方循環：NIHSS が低く出る）**
```
O：NIHSS（3:20）合計 3
1a 0  1b 0  1c 0  2 0  3 0  4 0  5 右0 左0  6 右0 左0  7 2  8 0  9 0  10 1  11 0
根拠：7 右指鼻・右踵膝で失調（筋力低下なし）。10 一部不明瞭だが理解可。歩行 自力不可（NIHSS には入らない）。
A：右小脳梗塞疑い。NIHSS 3 でも歩けない → 軽症扱いしない。MRI、神経内科コール（めまいは vertigo-karte-template.md）
```

**血栓溶解後の経時評価（短く書く）**
```
NIHSS 11:00 合計 9（10:45 合計 9）変化なし
NIHSS 11:15 合計 14（↑5：1a 0→1、5 右 2→4、9 1→3）→（投与中なら中止）緊急 CT、上級医コール
```

## 3. ER での使い方

### 3-1. いつ取るか

- **来院したらすぐ**（3〜5 分）。ただし **画像検査を遅らせない**：CT の準備中や CT 室で取ってよい
- **治療後の経時評価**：施設のプロトコルに従う（例：投与中〜2 時間は 15 分ごと → 6 時間まで 30 分ごと → 24 時間まで 1 時間ごと）
- **症状が変わったら** いつでも取り直す。悪化したら出血を疑って **緊急 CT・上級医**（投与中なら中止）。臨床試験では「合計 4 点以上の増加」が症候性頭蓋内出血の定義によく使われる

### 3-2. NIHSS とセットで聞く（抜けると治療を決められない）

- **最終健常確認時刻**（発見時刻ではない。寝ている間に起きたなら就寝前）
- **血糖**（低血糖は脳卒中そっくり。NIHSS の前に）
- **抗血栓薬**（抗凝固薬の種類と最終内服時刻）
- **発症前の ADL**（既存の麻痺も NIHSS に入るので、普段の状態を家族に聞く）

### 3-3. 所見・点数から考えること

| 所見・点数 | 考えること |
|---|---|
| 共同偏視＋失語（左）または無視（右）＋片麻痺 | **LVO 疑い** → CTA、血栓回収チームへ連絡 |
| 前方循環 LVO で 6 点以上 | 血栓回収の代表的な目安（最新のガイドライン・施設基準を確認） |
| 点数は低いが、失語・半盲・利き手の麻痺・歩けない | 生活に支障が出る症状 → **点数が低くても** 血栓溶解の適応を考える |
| 0〜3 点でも歩けない・めまい・飲み込めない | **後方循環** を疑う（NIHSS に入っていない）→ 歩行を見る |

重症度の目安：1–4 軽症、5–15 中等症、16–20 中等症〜重症、21 以上 重症（点数だけで治療を決めない）

### 3-4. 低く出るとき（ここで見逃す）

- **右半球**：言語（1b・1c・9）の配点がないぶん、同じ大きさの梗塞でも左半球より低い
- **後方循環**：歩行・体幹失調・めまい・嚥下障害は採点されない
- **既存障害も点に入る**ので、絶対値より **前回との差** を見る

## 4. 項目ごとのくわしい説明

### 4-1. 速いやり方と、何を見ているか

各項目を **速いやり方**（ER 用）・**何を見ているか**（なぜその検査をするのか）・**判定のコツ**・**公式との違い** の順にまとめた。

**1a 意識**
- **速いやり方**：問診しながら見ている時点でほぼ決まる。普通に会話できていれば 0（追加の手間なし）
- **何を見ているか**：目が覚めている程度（覚醒）。意識が落ちる＝大きな梗塞・脳幹梗塞・出血、または低血糖・けいれん後など脳卒中以外も考える
- **判定のコツ**：痛みを払いのければ 2。**3 は反射姿勢しか出ないときだけ**。挿管・言葉の壁があっても必ず点を選ぶ（UN はない）。1a＝3（昏睡）なら他の項目に決まった点が付く → 5 章

**1b 質問**
- **速いやり方**：問診の最初に「今は何月？」「おいくつ？」と聞いてしまう（5 秒）。**周りが日付や年齢を口にする前に** 聞く
- **何を見ているか**：質問を理解して、正しく答えられるか（意識・言葉・見当識）。誰でも答えが決まっている簡単な質問にしてある
- **判定のコツ**：聞くのは **月と年齢だけ**。近くても部分点なし（「70 くらい」は不正解）。言い直しても点は変えない。理解できない失語 → 2、話せない（挿管・口の外傷・重い構音障害・言葉の壁）→ 1
- **やってはいけない**：「11 月ですよね？」（答えを言っている）、「分かりますか？」（「はい」で終わる）、「10 月？ 11 月？」（選択肢）、考えている間のうなずき

**1c 従命**
- **速いやり方**：「目を閉じて…開けて」「グー…パー」で 5 秒
- **何を見ているか**：**言葉の指示を理解できるか**。目の開け閉めは麻痺の影響を受けにくく、手は麻痺のない側を使う → 麻痺ではなく「理解」だけを見るための組み合わせ
- **判定のコツ**：「閉じる→開ける」「握る→開く」まで できて 1 つ正解。**検者の指は握らせない**（把握反射と区別できない）。麻痺でできなくても、はっきりやろうとしたら正解。声で反応がなければ見本を見せ、その結果で採点。手が使えなければ「舌を出してください」など別の 1 段階の指示に替える

**2 注視**
- **速いやり方**：顔の前で指を左右に 1 往復（10 秒）。従えなければ、目を合わせてから検者がベッドの右 → 左へ移動する。それでも分からなければ人形の目
- **何を見ているか**：**目を左右に向ける中枢**（大脳の前頭眼野と脳幹）。大脳の大きな病変では目が **病巣側に寄る**（共同偏視）→ LVO を疑う一番分かりやすいサイン。脳幹病変やけいれん中は反対を向くことがある
- **判定のコツ**：**水平だけ** 見る（上下は採点しない）。偏視があっても越えられれば 1、越えられなければ 2。単独の眼筋麻痺（動眼・滑車・外転神経）は 1。失語でも人形の目で必ず評価できる。頸椎損傷の疑いがあれば人形の目はしない

**3 視野**
- **速いやり方**：両手を左右に広げ、指を動かして「動いた方を指さして」。上・下 × 右だけ・左だけ・両方（15 秒）→ **3 と 11（視覚）が同時に終わる**
- **何を見ているか**：**目から後頭葉までの視覚の通り道**。片側の視野が両目とも欠ける（同名半盲）＝ MCA の大きな梗塞や PCA 梗塞
- **判定のコツ**：はっきりした左右差があるときだけ 1 以上。指示が通らなければ威嚇でまばたきを見る。片目が失明・義眼なら残った目で採点。原因を問わず全盲なら 3。**消去は 3 ではなく 11 で採点**（原文が紛らわしいので施設で統一）。半盲があると視覚の同時刺激はできない → 触覚で 11 を見る
- **公式との違い**：公式は指の数を数えるか威嚇。ただし「動いた指の方を正しく見れば正常としてよい」とあるので、指を動かして指さしてもらう方法で判定してよい。余裕があれば片目ずつ

**4 顔面**
- **速いやり方**：「イーして、眉を上げて、目をぎゅっ」と続けて言う（5 秒）。問診中の表情やしゃべる口元でも、だいたい分かる
- **何を見ているか**：**脳から顔の筋肉への運動の通り道**。脳卒中（中枢性）は顔の **下半分だけ** 麻痺する。おでこは左右両方の脳から命令を受けているので動く
- **判定のコツ**：おでこまで動かない（3）→ ベル麻痺や脳幹病変も考える。テープ・挿管チューブで顔が隠れていたら、できる範囲で外して見る。反応が乏しければ痛み刺激でのしかめ顔の左右差

**5 上肢**
- **速いやり方**：検者が腕を位置（臥位 45°・座位 90°、手のひら下）に置いて手を離し、声に出して 10 数える（片方 10 秒）
- **何を見ているか**：**運動の通り道（錐体路）**。軽い麻痺は「持ち上げられるが保てない（drift）」で分かる
- **判定のコツ**：まず **ベッド（支え）に付いたか** だけ見る。付かなければ 0〜1（10 秒保てば 0、下がれば 1）、付いたら 2〜4（重力に逆らう力があれば 2、置いた瞬間に落ちれば 3、全く動かなければ 4）。指・手首の動きは採点しない。失語の人は声と身ぶりで励まし、**痛み刺激は使わない**。拘縮・痛み・既存の麻痺があっても点を付ける（UN は切断・関節固定だけ）
- **公式との違い**：公式は片方ずつ（麻痺のない側から）。両腕同時に上げると速く、左右差も見やすいが、点は 1 本ずつ判定する。手のひらは下で統一（手のひら上の Barré 徴候の方が軽い麻痺に敏感だが、NIHSS は下）

**6 下肢**
- **速いやり方**：仰臥位のまま、検者が片足を 30° に持ち上げて手を離し、声に出して 5 数える（片方 5 秒）
- **何を見ているか**：上肢と同じ運動の通り道。前大脳動脈（ACA）の梗塞では **脚が腕より強く** 麻痺する
- **判定のコツ**：境目は上肢と同じ（ベッドに付いたか）。**必ず仰臥位**、時間は 5 秒

**7 失調**
- **速いやり方**：指鼻指を左右 2〜3 往復、踵膝を左右 1 回ずつ（20 秒）。**5・6 で全く動かなかった手足は飛ばして 0**
- **何を見ているか**：**小脳**（と脳幹にある小脳への通り道）。力はあるのに、狙いがずれる・揺れる
- **判定のコツ**：**筋力低下で説明できるぎこちなさは失調にしない**。理解できない人も 0。3 肢以上でも 2。目は開けたまま、視野欠損があれば見える側で行う。失明なら腕を伸ばした位置から鼻をさわってもらう
- **NIHSS の弱点**：歩行・体幹の失調は入っていない → 立てる人は歩かせる（点数外。vertigo-karte-template.md の 6 章）

**8 感覚**
- **速いやり方**：目を閉じてもらい、つまようじで **顔・腕・太もも** を左右 1 回ずつ（15 秒）。そのまま両手の甲を同時に触って、11（触覚）も済ませる
- **何を見ているか**：**感覚の通り道**（脳幹・視床・頭頂葉）。痛覚（チクッ）の左右差を見る
- **判定のコツ**：**手先・足先は使わない**（糖尿病などの神経障害を拾ってしまう）。脳卒中による感覚障害だけ採点する。鈍い側で「さわられているのは分かりますか？」と聞き、分かれば 1、分からなければ 2。**2 ははっきりしたときだけ**。失語・昏迷の人はしかめ顔・手足を引っ込めるかの左右差で見る（たいてい 0 か 1）。両側の感覚脱失（脳幹梗塞）・反応のない四肢麻痺・昏睡は 2

**9 言語**
- **速いやり方**：絵を見せて「何が起きていますか？」→ 同じ紙の呼称の絵を指して「これは何ですか？」（20〜40 秒）。絵だけなので文字はいらない
- **何を見ているか**：**言語の中枢（多くは左半球）**
  - 絵の説明 → 自分から話す力（なめらかさ）と、話の中身
  - 呼称 → 言葉を思い出す力。サボテン・ハンモック・羽根のような **普段あまり使わない言葉** を混ぜて、軽い「言葉が出てこない」を拾う
  - 読み上げ → 字を読む力と、長い文をなめらかに言えるか
  - 理解 → ここまでの指示（1c・目・手足）に従えたかで、ほぼ分かっている
- **判定のコツ**：**1 と 2 の境目＝患者の説明だけで、どの絵・どのカードか当てられるか**。3 は無言で、1 段階の指示にも全く従えないときだけ。挿管中は筆談。目が見えなければ手に物を持たせて名前を言ってもらう・復唱・自発話で判断。言葉の選び方・理解の問題は 9、発音の問題は 10
- **公式との違い**：公式は絵・呼称・読み上げの 3 つ。急ぐときは読み上げ（文字）を省き、「読字未施行」と書く
- **カードがないとき**：身の回りの物で呼称する。ペン・時計のようなよく使う物は簡単すぎるので **部品** まで聞く（時計 → バンド → 針、ペン → キャップ → クリップ）。「資材なし」と書く

**10 構音**
- **速いやり方**：「私の後に続けて言ってください」と単語を言って復唱させる（10 秒）。**復唱は公式に OK なので、カードを見せなくていい**。施設の日本語版の単語を覚えておく
- **何を見ているか**：**口を動かす力**（唇・舌・軟口蓋）。英語原文の単語リストも、唇の音（MAMA）・舌先の音（TIP-TOP）・長い単語（HUCKLEBERRY・BASEBALL PLAYER）が入っている
- **判定のコツ**：「ろれつを見ます」と目的を言わない（意識して丁寧に話してしまう）。普通に話せているように見えても必ず確認する。重い失語がある → 自発話の発音の明瞭さで採点。方言・入れ歯・もともとの話し方は、家族に「普段と比べてどうか」を聞く
- **「パ・タ・カ」との関係**：NIHSS の公式のやり方ではなく、日本でよく使う構音のスクリーニング（オーラルディアドコキネシス）
  - パ＝唇、タ＝舌先、カ＝舌の奥。「パパパ…」「タタタ…」「カカカ…」「パタカパタカ…」をできるだけ速く繰り返してもらい、遅さ・リズムの乱れ・不明瞭さを見る
  - パが言いにくい → 唇（顔面神経）、タが言いにくい → 舌（舌下神経）、カが言いにくい → 舌の奥・軟口蓋、リズムが不規則 → 小脳
  - NIHSS の点は **単語が聞き取れるか** で付ける。パタカだけだと単語の不明瞭さが分かりにくく、高齢者のゆっくりした話し方を悪く取りやすい → **点は単語で付け、パタカは補助** に使う
  - 単語を覚えていないときは、会話・パタカで判断し、「単語リストなし」と書く

**11 消去・無視**
- **速いやり方**：視覚は 3、触覚は 8 のついでに済んでいる。最後に麻痺側の手を見せて「この手は誰の手ですか？」（5 秒）
- **何を見ているか**：片側への **注意**（多くは右の頭頂葉）。くわしくは **4-2**

### 4-2. 11 消去・無視をくわしく

**何を見る項目か**

正式名は「消去現象と無視（Extinction and Inattention、旧称 Neglect）」。
**見えている・感じているのに、片側に注意が向かない** 状態を拾う。視野欠損（3）や感覚障害（8）とは別物。

| 用語 | どういう状態か | 患者の様子 |
|---|---|---|
| **半側空間無視** | 片側（多くは左）の空間に注意が向かない | ずっと右を向いている。左から話しかけても気づかない |
| **消去現象** | 片側ずつなら分かるのに、両側同時だと片側を見落とす（軽い無視） | 両手を同時に触ると「右」とだけ言う |
| **身体の無視** | 自分の体の片側を自分のものと思わない | 左手を見せて「誰の手？」→「先生の手」 |
| **病態失認** | 自分の麻痺に気づかない・認めない | 左手が全く動かないのに「どこも悪くない」 |

**ER で大事な理由**
- **右半球（右 MCA 領域、特に頭頂葉）の皮質徴候**。左半球でいう失語にあたる。右共同偏視＋左片麻痺＋左無視 → **右 MCA の LVO を疑う**
- 右半球は言語の点がないので、**11 は右半球の皮質徴候に点が付く数少ない項目**。見落とすと点数がさらに低く出る
- 病態失認があると **本人は「大丈夫」と言う** → 症状や最終健常確認時刻は家族・目撃者から聞く
- 最大 2 点でも、生活への影響（転倒・介護量）は大きい → 血栓溶解の判断で「軽い」と思わない

**なぜ「両側同時」に刺激するのか**

片側だけの刺激なら、軽い無視の人でも気づける。両側から同時に刺激が来ると、注意が健側（右）に取られて、患側（左）の刺激が「消える」。

| | 片側ずつ | 両側同時 | どこで採点 |
|---|---|---|---|
| 正常 | 分かる | 「両方」と言える | — |
| 視野欠損・感覚障害 | 患側は **分からない** | 患側は分からない | 3・8 |
| **消去現象** | **分かる** | **健側だけ** 言う | **11** |

→ **片側ずつで分かることを確かめてから** 両側同時をする。片側でも分からなければ、消去ではなく視野欠損・感覚障害。

**やり方と声かけ**

① 観察（1a から最後までずっと）
- 頭と目がいつも右を向いている、左側に立つと気づかない、左側の物（点滴・家族）を無視する → 空間の無視

② 視覚（項目 3 のついで）
```
（患者の正面で両手を左右に広げる）
「私の鼻を見たままでいてください。指が動いたら、そっちを指さしてください」
（右だけ → 左だけ → 両方同時、を順番を変えて数回）
```

③ 触覚（項目 8 のついで）
```
「目を閉じてください。これから手の甲をさわります。
　右か、左か、両方か、教えてください」
（右だけ → 左だけ → 両方同時、を順番を変えて数回。同じ強さで、同時に）
```

④ 自分の体・病気の認識
```
（麻痺側の手を持ち上げ、患者に見えるところで）「これは誰の手ですか？」
「体で動かしにくいところはありますか？」「左手は動きますか？」
```

**採点**

| 点 | 状態 | 例 |
|---|---|---|
| 0 | 異常なし | 両側同時でも「両方」と答える |
| 1 | **1 つの感覚**（視覚・触覚・聴覚のどれか）で消去、または空間・身体への不注意 | 触覚だけ消去。視覚だけ消去。病態失認だけ（目安） |
| 2 | **2 つ以上の感覚** で消去、または高度の半側無視 | 視覚も触覚も消去。**自分の手を認めない**。片側の空間にしか注意を向けない |

**判定のコツ**
- **半盲がある** → 視覚の同時刺激はできない。触覚で判定する。触覚が正常で、ほかの異常もなければ 0
- **重い感覚障害がある** → 触覚の同時刺激はできない。視覚と観察で判定する
- **失語** →「右・左・両方」と言えなければ、「触った方の手を上げてください」と身ぶりで伝える。両側に注意を向けていれば 0
- **半盲と無視の見分け**：半盲の人は見えない部分があることに気づいて、目を動かして補うことが多い。無視の人は気づかず、補わない
- 異常があるときだけ点が付く → **UN にはならない**
- 左半球の病変でも右側の無視は起こるが、右半球（左側の無視）より少なく、軽い

**カルテの書き方**：感覚の種類と左右を書く
```
11 1（左触覚消去）
11 2（左の視覚・触覚消去、左手を自分の手と認めない）
```

| 状況 | 扱い |
|---|---|
| **昏睡（1a＝3）** | 1b＝2、1c＝2、5・6 は動きがなければ各 4、7＝0、**8＝2（自動）**、**9＝3（自動）**、10＝2。2・3・4・11 は人形の目・威嚇・痛みでのしかめ顔などの観察から判断 |
| **失語** | 1b：質問を理解できなければ 2。1c：見本を見せて採点。2：人形の目。3：威嚇。5・6：声と身ぶりで励ます（痛み刺激はしない）。8：痛みへの反応の左右差 |
| **挿管** | 1a は必ず選ぶ。1b＝1。4 はテープを外せる範囲で。9 は筆談。10＝UN |

| **鎮静中・けいれん後** | そのまま採点し、記録に書く。けいれん後の麻痺（Todd 麻痺）は時間とともに改善する |

## 6. 検査用資材（英語原文）

日本人の患者には **施設の日本語版** を使う（英語の単語をそのまま言わせない）。
9 の絵・呼称カードはスマホに写真で入れておく。10 の単語は覚えて、言って復唱させる。
内容の考え方を知るために英語原文を載せる。

**読み上げ文（項目 9）**：短い文から長い文へ
```
You know how.
Down to earth.
I got home from work.
Near the table in the dining room.
They heard him speak on the radio last night.
```

**呼称カード（項目 9）**：鍵・手袋・椅子・サボテン・羽根・ハンモック（key, glove, chair, cactus, feather, hammock）

**絵カード（項目 9）**：状況が描かれた絵 1 枚。何が起きているかを説明してもらう

**単語リスト（項目 10）**：唇・舌先・舌の奥を使う音と、長い単語が入っている
```
MAMA
TIP – TOP
FIFTY – FIFTY
THANKS
HUCKLEBERRY
BASEBALL PLAYER
```

## 7. 用語集

| 用語 | 意味 |
|---|---|
| **UN**（untestable） | 評価不能。5・6・7（切断・関節固定）と 10（挿管など）だけに使える。合計に入れない |
| **drift** | 挙上した腕・脚が、保持時間内にだんだん下がること |
| **錐体路** | 大脳から脊髄へ、手足を動かす命令を伝える通り道。障害されると反対側の麻痺が出る |
| **共同偏視** | 両目が同じ方向に寄ったままになること。大脳病変では病巣側を向く |
| **人形の目**（頭位変換眼球反射） | 頭を左右に回すと、目が反対方向へ動く反射。指示に従えない人の注視評価に使う |
| **対座法** | 検者と向き合い、検者の指で患者の視野を調べる方法 |
| **威嚇瞬目** | 目の横から手を素早く近づけたときのまばたき。指示に従えない人の視野評価に使う |
| **同名半盲・四分盲** | 両目の同じ側（右または左）の視野が欠けるのが同名半盲。その上下どちらか 1/4 だけ欠けるのが四分盲 |
| **消去現象**（extinction） | 片側ずつの刺激は分かるのに、両側同時に刺激すると片側しか感じない現象 |
| **半側空間無視**（neglect） | 片側（多くは左）の空間や自分の体に注意が向かない状態。右半球病変で多い |
| **病態失認** | 麻痺などの自分の障害を認識しない状態 |
| **把握反射** | 手のひらに触れたものを反射的に握ってしまう反射。前頭葉病変で出る。1c の正解と区別する |
| **失語** | 言葉の理解・選択・組み立ての障害（9 で採点） |
| **構音障害** | 発音の障害。言葉の中身は正しいが、ろれつが回らない（10 で採点） |
| **オーラルディアドコキネシス** | 「パ」「タ」「カ」などをできるだけ速く繰り返してもらい、口の動きの速さ・リズムを見る検査 |
| **最終健常確認時刻** | 最後に普段どおりだったと確認された時刻。発見時刻とは違う。血栓溶解・血栓回収の時間の起点 |
| **LVO** | 主幹動脈閉塞（内頸動脈・中大脳動脈 M1 など）。血栓回収の対象 |
| **TNK** | テネクテプラーゼ。単回静注の血栓溶解薬 |
