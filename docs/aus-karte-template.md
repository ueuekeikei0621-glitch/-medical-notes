# AUS カルテテンプレ（腹部エコー）

> **方針**：ER は **コンパクト優先**。所見（O）だけを書き、解釈は **アセスメント（A）** へ。
> 全部埋めなくてよい。**症状に合わせて見た所だけ書く**（どこを見るかは 4 章）。

- 対象：ER の腹部エコー（POCUS 含む）
- 更新日：2026-10-25

---

## 1. テンプレ（コピペ用）

```
【AUS】
胆嚢：結石 −/＋　壁肥厚 −/＋（　mm）　腫大 −/＋　sono-Murphy −/＋
胆管：CBD　mm　肝内胆管拡張 −/＋
腎：水腎 右 −/＋ 左 −/＋（軽/中/高度）　結石 −/＋
Ao：最大径　mm　フラップ −/＋
腹水 −/＋（　）　膀胱 尿　mL
腸管：拡張 −/＋（　mm）　蠕動 正常/亢進/低下/消失
その他：（虫垂・肝/脾/膵・子宮付属器・胸水 など）
```

見えなかった臓器は「−」ではなく **「描出不良」** と書く。

---

## 2. 記載例

**正常**
```
O：AUS 胆嚢 結石−壁肥厚−腫大−Murphy−、CBD 4mm、肝内胆管拡張−、水腎 両側−、Ao 18mm、腹水−、腸管拡張−。膵は描出不良。
```

**胆嚢炎**
```
O：AUS 胆嚢 結石＋（頸部嵌頓）壁肥厚 6mm 腫大＋ sono-Murphy＋、胆嚢周囲液体＋。CBD 5mm、肝内胆管拡張−。
A：急性胆嚢炎 → 採血で重症度判定（TG18）・外科コール。
```

**水腎**
```
O：AUS 水腎 右＋（中等度）左−、腎結石−。Ao 20mm、腹水−。
A：右尿管結石疑い（AAA は否定的）。発熱あれば閉塞性腎盂腎炎 → 泌尿器科に緊急ドレナージ相談。
```

---

## 3. 異常の目安

| 項目 | 異常 | メモ |
|---|---|---|
| 胆嚢壁 | >4 mm | 肝硬変・心不全・低 Alb・食後でも厚くなる |
| 胆嚢腫大 | 長径 >8 cm / 短径 >4 cm | |
| CBD | >7 mm | 胆摘後・高齢者は太め（〜10 mm） |
| 肝内胆管 | 門脈と並走して見える | parallel channel sign |
| 腹部大動脈 | **≥30 mm で AAA** | 短軸で外膜〜外膜。≥55 mm は破裂リスク高 |
| 水腎 | 軽度：腎盂のみ／中等度：腎杯まで／高度：実質が薄い | |
| 小腸 | 径 >25 mm | keyboard sign、to-and-fro |
| 虫垂 | 外径 ≥6 mm、圧迫で潰れない | 糞石、周囲脂肪の高エコー |
| 膀胱容量 | 長径×短径×高さ×0.52 mL | 排尿後 >100 mL で残尿あり |

---

## 4. 症状別：どこを見るか

| 症状 | 見る所 | 見逃し注意 |
|---|---|---|
| 右季肋部痛・発熱 | 胆嚢・CBD・肝内胆管 | CBD 拡張＋発熱・黄疸 → **胆管炎**（ドレナージ） |
| 側腹部痛・背部痛 | 腎・Ao | 高齢の「尿管結石」は **AAA 破裂** を否定。水腎＋発熱 → **閉塞性腎盂腎炎** |
| 心窩部痛 | 胆嚢・Ao・膵 | ACS を ECG で否定 |
| 右下腹部痛 | 虫垂・回盲部・右付属器 | 虫垂が見えない ≠ 否定 |
| 下腹部痛（妊娠可能女性） | 子宮・付属器・ダグラス窩 | hCG＋で子宮内胎嚢なし＋液体 → **異所性妊娠** |
| 嘔吐・腹部膨満 | 腸管・腹水 | 蠕動消失・壁肥厚・腹水増加 → **絞扼** → 造影 CT |
| 尿が出ない | 膀胱・両腎 | 尿閉なら導尿。両側水腎なら腎後性 AKI |
| 小児の間欠的腹痛 | 右側腹部〜上腹部 | target sign → **腸重積** |

- AAA 破裂の後腹膜血腫はエコーで見えにくい → 疑えば CT
- 尿管結石そのものは見えないことが多い → 水腎で間接的に評価
