# LUCAS 装着で CPA が来たときの流れ（ICLS）

> [!IMPORTANT]
> **救急隊の LUCAS は、ベッドに移すまで使う → 引き継いだら外して返す → 手の圧迫（か病院の LUCAS）→ あとは ICLS。**
> **救急隊のショックとアドレナリンは数え直さない**（合計で数える）。

- 横浜市の救急隊は **全隊が LUCAS 3**（2023 年 4 月〜）
- ボタン：**1 調整 → 2 中断（‖）→ 3 開始（▶ 連続／▶ 30:2）**

---

## 0. 全体の流れ

```
到着前     情報を聞く → 役割を決める → 物品・病院の LUCAS を準備
到着       LUCAS は動いたまま。圧迫を止めずに引き継ぎ（ショック回数・アドレナリン時刻）
移す       「2 中断」→ 全員でベッドへ → すぐ「▶」→ 位置を確認
つなぐ     病院のモニター・除細動器
替える     救急隊の LUCAS を外して返す → 手の圧迫 →（病院の LUCAS があれば付ける）
ICLS      2 分ごとに波形 → ショック or 圧迫 → 薬 → 気道 → 原因（5H5T）
決める     ROSC ／ 続ける（ECPR・カテ）／ 中止
ROSC 後    圧迫を止める → 12 誘導 → 酸素・CO₂・血圧・体温
```

---

## 1. 到着前（ホットライン〜到着）

### 聞くこと
- 年齢・性別・**目撃**・**バイスタンダー CPR**・倒れた時刻
- **初期波形**・**ショック回数**・**アドレナリンの回数と最終時刻**
- 気道（BVM／声門上デバイス／挿管）・ルート
- **LUCAS 装着中か**・到着予定時刻
- 既往・内服・DNAR の情報

### 役割を決める

| 役割 | 仕事 |
|---|---|
| **リーダー** | 全体を見る・指示・時間管理・波形の判断・原因を考える。**手を出さない** |
| 圧迫 | 2–3 人（交代要員も）。LUCAS 係を兼ねる |
| 気道 | 頭側。カプノ・BVM・挿管 |
| 除細動器 | パッド・充電・ショック |
| 薬・ルート | 静脈路・薬 |
| 記録 | **時刻**・**2 分タイマー**・**救急隊の分も含めたショック回数とアドレナリン時刻** |

### 物品
```
□ 除細動器・パッド          □ 挿管セット・ビデオ喉頭鏡・カプノ・吸引
□ 静脈路（取れなければ骨髄路）□ アドレナリン・アミオダロン（5% ブドウ糖）
□ 血ガス                     □ エコー
□ 病院の LUCAS があれば：電源 ON（調整モード）・**背中の板をベッドにセット**（患者の脇の下が来る高さに）
```

---

## 2. 到着〜引き継ぎ（0–1 分）

- 救急隊のストレッチャーの上でも **LUCAS は動いたまま**
- **圧迫を止めずに** 引き継ぎを聞く
- 記録係は、救急隊の **ショック回数** と **アドレナリンの最終時刻** を **ホワイトボードに書く**

| 救急隊の分 | どう使う |
|---|---|
| ショック回数 | **合計** に入れる → 合計 3 回でも VF ならアミオダロン |
| アドレナリンの最終時刻 | 次は **そこから 3–5 分後** |

---

## 3. ベッドに移す

1. 「**2（‖ 中断）**」を押す
2. 全員で移す（LUCAS の脚の下の爪ロックの下に手を入れ、もう片方の手で腰・太ももを持つ）
3. すぐ「**▶**」で再開
4. **位置を確認**（移すとずれやすい）。ずれていたら **1 調整** → 直す → 2 → ▶

---

## 4. つなぐ

> [!NOTE]
> **自分の病院：波形チェックは普通のモニター（ベッドサイドモニター）で見る。**
> - 心電図の電極を **ベッドサイドモニター** につなぐ（早めに貼る）。パッドは **除細動器**（ショック用）
> - 到着前に、モニターに **2 つの誘導（例：II と I／III）を並べて表示** しておくと、平らなときに切り替えなくて済む
> - **感度の上げ方・誘導の変え方** をモニターで一度確認しておく
> - VF に見えたら、**除細動器の画面（パッド誘導）でも確認** してショック


- 病院の **モニター・除細動器** へ（パッドを貼り替える。**吸着カップの下にパッドやケーブルを入れない**）
- ルートの確認（漏れていないか、太さ）

---

## 5. 救急隊の LUCAS を外して返す

- 医師に引き継いだら、救急隊の資器材は外す。**外すときは救急救命士が立ち会う**（高知県の基準の例）
- **体に入っている使い捨てのもの**（声門上デバイス・ルートの針）はそのまま使う
- 外すタイミング・誰が外すかは **院内と消防の取り決め** に従う

### 手順（波形チェックに合わせると止める回数が増えない）

```
① 外す人と、すぐ手で押す人を決める
② 救急隊の LUCAS：電源 OFF → ネックストラップのバックル → リリースリングで本体を外す
③ すぐ手の圧迫
④ 救急隊の背中の板を抜く
   ・病院の板を先にベッドにセットしてあれば：患者は「病院の板の上に救急隊の板」の状態 → 救急隊の板を抜くだけで、病院の板の上に乗る
   ・セットしていなければ：同じ持ち上げで病院の板を入れる
⑤ 救急隊は LUCAS を持ち帰る
```

### 病院の LUCAS を付ける（あれば）

> [!TIP]
> **病院の板を先にベッドにセットしておく** と早い。
> - ベッドに移したら、患者は **病院の板の上に、救急隊の板と LUCAS が乗った状態**（救急隊の LUCAS はそのまま動かせる）
> - 救急隊の LUCAS を外して **救急隊の板を抜けば、病院の板の上に乗る** → 病院の本体をはめるだけ
> - 救急隊の板を抜いたあと、**病院の板が脇のすぐ下に来ているか** を確認（ずれていたら板をずらす）
> - LUCAS を使わず手で押すことになっても、板が **硬い台** になって圧迫が効きやすい

1. 手の圧迫を続けながら、自分側の脚をはめる → 圧迫を止めて反対側 → カチッ → 引いて確認
2. 吸着カップの下の縁を **胸骨の下端のすぐ上** に
3. カップを手で下げて **胸に触れるまで** → **2 で固定**
4. **▶（連続）**（声門上デバイス・挿管が入っていれば）／**▶ 30:2**（マスクなら）
5. 動き出してからネックストラップ

---

## 6. ICLS のサイクル（2 分ごと）

### 波形チェック
```
「2 分です」
→ 手なら圧迫を止める／LUCAS なら「2（‖ 中断）」
→ 波形を見る
   ├ VF・VT     → 圧迫を再開（LUCAS は ▶）→ 充電 → ショック（LUCAS は動かしたままでよい）
   ├ 心静止      → すぐ再開（平らなら リード・感度・誘導を確認）
   └ 規則的な波形 → 脈を見る → 脈なし（PEA）→ すぐ再開 ／ 脈あり → ROSC（9 章）
→ 手の圧迫なら交代
```
- 中断は **できるだけ短く**（目安 10 秒以内）
- ショックの後は **脈も波形も見ずにすぐ圧迫**

### 薬
| 薬 | いつ |
|---|---|
| **アドレナリン 1 mg** | 心静止・PEA：**できるだけ早く**。VF・VT：ショックが効かなければ早めに（コースでは「2 回目のショック後」）。以後 **3–5 分ごと**（救急隊の最終時刻から数える） |
| **アミオダロン 300 mg**（2 回目 150 mg） | ショック **合計 3 回** でも VF・VT が続く（救急隊の分も入れる） |

- ルートは **静脈路が第一選択**、取れなければ骨髄路（JRC 2025）
- カルシウム・重炭酸は **ルーチンでは使わない**（高 K などのときだけ）

### VF が止まらないとき（JRC 2025 で新しく入った）
- **3 回以上ショックしても VF・VT** → **DSED（2 台の除細動器で続けてショック）** か **ベクトル変更（パッドを前胸部と背中に貼り直す）** を **考慮**（弱い推奨）
- 自分で決めず、**リーダー・上級医の判断**

---

## 7. 気道

| 来たときの状態 | すること |
|---|---|
| **声門上デバイス**（ラリンゲアルチューブなど） | **カプノの波形**・胸の上がりを確認 → 換気できていれば **そのまま使う**（圧迫は連続、換気は 6 秒に 1 回） |
| 挿管済み | 同じく確認（深さ・波形） |
| BVM | 30:2。準備が整ったら挿管を考える |

**挿管するなら**
- 準備を全部そろえてから。**LUCAS は動かしたまま**、止めるならチューブを通す一瞬だけ「2」
- つなぎ方：**チューブ ─（フィルター）─ カプノ ─ バッグ**
- 入ったら **▶（連続）**＋ **6 秒に 1 回、そっと**（入れすぎない）
- カプノの波形が急に消えたら → **チューブが抜けていないか**

---

## 8. 原因を探す（5H5T）

| グループ | 中身 | 見つけ方 |
|---|---|---|
| ① 中身が足りない | 出血・脱水、低酸素 | 病歴・Hb |
| ② 血液の成分がおかしい | 高 K・低 K、アシドーシス、低体温、中毒 | **血ガス**（K・pH・Hb）・体温・病歴 |
| ③ 何かに邪魔されている | 緊張性気胸、心タンポナーデ、肺塞栓、心筋梗塞 | 病歴・心電図・身体所見・（エコー） |

- **救急隊の情報が大事**：倒れる前の様子（胸痛・呼吸苦）、既往（透析・心疾患）、薬
- **エコー**：JRC 2025 では、原因を探すために CPR 中に **ルーチンでは行わない** ことを提案。**慣れた人が、圧迫の中断を延ばさない** なら追加してよい
  - LUCAS 中は胸骨の横から見にくい → 心窩部・心尖部から、波形チェックの中で

---

## 9. 決める

| 状況 | どうする |
|---|---|
| **ROSC** | 10 章へ |
| **続ける** | 原因を治す。**ECPR**（条件に合えば）・カテ室 → 病院の LUCAS を付けたまま運ぶ |
| **中止** | リーダー（上級医）が、経過・原因・本人の意思・家族の意向をふまえて決める |

- EtCO₂ だけで中止を決めない

---

## 10. ROSC のあと

### 圧迫を止める
- 波形チェックで **規則的な波形＋脈あり**
- 病院の LUCAS なら **▶ を押さず中断のまま**（また止まったら ▶。**30 分で電源が切れる**ので時間を記録）

### ABCDE

| | すること |
|---|---|
| A | 気道（声門上デバイスなら、挿管に入れ替えるか考える） |
| B | **SpO₂ が測れるまでは酸素 100%** → 測れたら下げる（**SpO₂ 90% 未満は避ける・上げすぎない**。目安 92–98%）・**PaCO₂ 35–45** |
| C | **血圧を保つ**（目安：平均血圧 65 以上）・**12 誘導**（ST 上昇 → 緊急カテ） |
| D | 意識・けいれん・血糖 |
| E | **体温 37.5℃ 以下**（発熱を防ぐ）・原因検索（CT・エコー・採血） |

- 病院の LUCAS：外すかどうかは **リーダーが決める**。12 誘導の電極が貼れなければ相談して外す

## 11. 声出しシナリオ

> 救急隊：70 代男性、自宅で目撃あり、家族が圧迫。初期波形 VF。AED 2 回（最終 10:21）、アドレナリン 1 回（10:22）。ラリンゲアルチューブ、左前腕ルート。LUCAS 装着中。10:25 到着。

```
10:25 到着（LUCAS 動いたまま）
  リーダー「引き継ぎお願いします」→ 記録「ショック 2 回、アドレナリン 10:22、ボードに書きます」
  リーダー「中断して移します。1、2、3！」→「▶ 再開」→「位置よし」
  リーダー「モニター・除細動器つないで。カプノ波形ありますか？」→ 気道「波形あり、胸上がってます」
10:26 波形チェック（2 中断）
  リーダー「VF。再開して充電……ショック（合計 3 回目）」
  リーダー「アドレナリン、前回 10:22 から 4 分。入れて。アミオダロン 300 も入れて（3 回ショックで VF）」
  リーダー「救急隊の LUCAS 外します。〇〇さん、手で押して。救命士さん立ち会いお願いします」
  → 外す → 手の圧迫 →（病院の LUCAS を付ける → ▶ 連続）
  リーダー「血ガス出して。既往は？透析？胸痛あった？」
10:28 波形チェック「VF。ショック（4 回目）。次のアドレナリンは 10:30 以降」
10:30 波形チェック「VF。ショック（5 回目）。アドレナリン 2 回目、アミオダロン 150」
  リーダー「3 回以上ショックして VF。ベクトル変更か DSED を考えます」（上級医と相談）
10:32 波形チェック「洞調律。脈……あり！ ROSC です」
  リーダー「LUCAS は中断のまま。12 誘導。酸素はまず 100%、SpO₂ 見て下げます。血圧測って。循環器コール」
```

## 12. 落とし穴

| 落とし穴 | 正しくは |
|---|---|
| 救急隊の LUCAS を蘇生が終わるまで借りておく | **引き継いだら外して返す**（院内の取り決めに従う） |
| 病院で「ショック 1 回目」と数え直す | **救急隊の分も合計** |
| アドレナリンを到着直後にすぐ入れる | **救急隊の最終時刻から 3–5 分** |
| ベッドに移した後に位置を見ない | 移すと **ずれやすい** → 確認 |
| LUCAS を「1 調整」や電源で止める | 止めるのは **「2 中断」** |
| 声門上デバイスをすぐ入れ替えようとして圧迫が止まる | 換気できていれば **そのまま** |
| エコーで中断が長くなる | **中断を延ばさない**。ルーチンではない |
| ROSC 後に酸素 100% のまま | **SpO₂ が測れたら下げる** |

## メモ（確認状況）

- **JRC 蘇生ガイドライン 2025** の変更点（静脈路が第一選択・DSED／ベクトル変更・CPR 中の POCUS はルーチンにしない・ROSC 後の酸素・PaCO₂ 35–45・体温 37.5℃ 以下・カルシウムはルーチンにしない）は、**解説記事** で確認したもの（[医学のすすめ](https://igaku-no-susume.com/jrc-2025-als/)・[日本医事新報 識者の眼](https://www.jmedj.co.jp/blogs/product/product_27543)・[ER-Nurse HOT LINE](https://er-nurse-study-room.info/jrc-guideline2025-public/)）。JRC の原文は未確認
- **VF でのアドレナリンのタイミング**（何回目のショック後か）は、解説記事でも書き方がそろっていない。受講するコースのテキストに合わせる
- **ROSC 後の血圧の目標** と **体温管理の期間** は、確認した記事には載っていなかった（平均血圧 65 以上は従来の目安）
- 救急隊の資器材を外すときに救急救命士が立ち会う：[高知県 救急救命処置実施基準](https://www.pref.kochi.lg.jp/doc/kyuukyuuiryoukyougikai/file_contents/file_20231227311432_1.pdf)。横浜市の運用は公開されておらず **院内で確認**
- 横浜市の救急隊の機種：[横浜市の公式ページ](https://www.city.yokohama.lg.jp/bousai-kyukyu-bohan/kyukyu/kyukyusha/20230309092803878.html) の写真に「LUCAS 3」
