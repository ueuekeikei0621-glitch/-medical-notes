# めまい精査カルテテンプレ（HINTS Plus ＋ Dix-Hallpike）

> **方針**：ER は **コンパクト優先**。まず **めまいの型** を決め、型に合った検査だけをする。
> **持続性＋自発眼振あり → HINTS Plus**、**頭位で数十秒＋自発眼振なし → Dix-Hallpike**。
> HINTS は神経所見の代わりにならない。**歩けるか** を必ず見る。

- 対象：成人の急性めまい
- 更新日：2026-10-25

---

## 1. テンプレ（コピペ用）

```
【めまい】（　:　〜）持続性 / 頭位で数十秒 / 発作性　自発眼振 有・無
HINTS+：HIT catch-up 右 −/＋ 左 −/＋
　　　　眼振 一方向（　向き）/ 注視で方向交代 / 垂直・純回旋
　　　　skew −/＋　新規難聴 −/＋（右・左）
Dix-Hallpike：右 −/＋ 左 −/＋（　）
神経：複視・構音・麻痺・しびれ・指鼻 −/＋　歩行 自力可/不可
→ 末梢 / 中枢疑い / BPPV（右・左）/ HINTS 適応外（眼振なし）
```

**使い分け（これだけ覚える）**

```
持続性＋自発眼振あり   → HINTS+ をやる（Dix はやらない）
頭位で数十秒＋眼振なし → Dix-Hallpike をやる（HINTS はやらない）
1 つでも中枢 / 歩けない → 中枢として MRI・神経内科
眼振なし               → 型ごとに 9 章（歩行・神経所見・ECG が中心）
```

## 2. 記載例

**前庭神経炎（末梢パターン）**
```
O：めまい（6:00〜持続）、自発眼振あり。HINTS+：HIT catch-up 右＋ 左−、眼振 左向き水平・一方向（左注視で増強）、skew−、新規難聴−。Dix 未施行。神経所見なし、歩行 ふらつくが自力可。→ 末梢
A：右前庭神経炎疑い → 制吐薬、飲水・歩行を確認して帰宅。耳鼻科外来。
```

**小脳梗塞疑い（中枢パターン）**
```
O：めまい（3 時間前〜持続）、自発眼振あり。HINTS+：HIT catch-up 右− 左−、眼振 注視方向へ方向交代、skew＋、新規難聴−。神経：指鼻 右拙劣、他−。歩行 自力不可。→ 中枢疑い
A：小脳梗塞疑い → MRI（DWI）、神経内科コール。CT 陰性でも否定しない。
```

**BPPV**
```
O：寝返り・起き上がりで 20 秒程度のめまい、自発眼振なし（HINTS 適応外）。Dix-Hallpike 右＋（潜時 3 秒、上向き＋回旋、20 秒で消失、座位で逆転）左−。神経所見なし、歩行可。→ BPPV（右）
A：右後半規管 BPPV → Epley 法 1 回で眼振・症状消失。帰宅。
```

## 3. 最初に型を分ける（TiTrATE）

HINTS も Dix-Hallpike も **使える型が決まっている**。型を間違えると結果に意味がない。

| 型 | 経過 | 主な疾患 | やる検査 |
|---|---|---|---|
| **持続性**（急性前庭症候群：AVS） | 数時間〜数日続く。眼振・嘔吐・歩行不安定 | 前庭神経炎・迷路炎 **vs** 小脳・脳幹梗塞 | **HINTS Plus** |
| **頭位で誘発**（t-EVS） | 寝返り・起き上がり・上を向くと起こり、1 回は **1 分以内** | BPPV **vs** 中枢性頭位めまい・起立性低血圧 | **Dix-Hallpike**（＋ supine roll test） |
| **自然発作性**（s-EVS） | 誘因なく起こり、数分〜数時間で治まる。反復 | 椎骨脳底動脈系 TIA・前庭性片頭痛・メニエール病・不整脈 | 神経所見・ECG・血管リスク評価 |

**問診で聞くこと**
- 「じっとしていても続いていますか？」→ 続く＝持続性
- 「1 回のめまいは何秒・何分ですか？」→ 数十秒＝BPPV、数分〜数時間＝TIA・片頭痛・メニエール
- 「何をすると起こりますか？」→ 頭位変換で起こる＝頭位誘発、立ち上がりで起こる＝起立性

**注意**：持続性めまいの人も **頭を動かすと悪化** する。これは「悪化」であって「誘発」ではない。
頭を動かして悪くなるから BPPV、と決めつけない。

## 4. HINTS Plus

### 4-1. 適応（ここを外すと意味がない）

- **持続性（AVS）** であること。来院時にまだ症状が続いていれば AVS として扱う
- 診察時に **自発眼振または注視眼振が見えている** こと

**なぜ眼振が必要か**：HINTS は「今見えている眼振の原因が内耳か脳か」を見分ける検査。

| 状態 | HIT | 解釈 |
|---|---|---|
| 眼振あり | 片側で catch-up あり | 前庭神経が壊れていて眼振を説明できる → **末梢** |
| 眼振あり | 両側とも正常 | 内耳は正常なのに眼振がある → 原因は脳 → **中枢** |
| **眼振なし** | 両側とも正常（当然） | ルール上「中枢」になってしまう → 不要な MRI が増える。判定に使えない |

- 眼振のない人に HINTS をして **「HINTS 陰性＝安心」と書くのはよくある誤り** → **「HINTS 適応外」** と書く
- 眼振のない持続性めまい → **歩行の重症度** で判断する（6 章・9 章）
- 根拠は 10 章の文献を参照

### 4-2. やり方と判定

| 項目 | やり方 | 末梢（安心） | 中枢（危険） |
|---|---|---|---|
| **HI**：Head Impulse | 検者の鼻を見続けてもらい、頭を左右どちらかへ **10–20°、素早く** 回して急に止める。方向は予測されないようにランダムに。**ゆっくり回すと異常が隠れる** | **片側で catch-up saccade あり**（目が頭と一緒に流れ、止まった直後に鼻へ戻る） | **両側とも catch-up なし（正常）** |
| **N**：Nystagmus | 正面視 → 左右 **30° 程度** の注視で数秒ずつ観察。端まで見させない（生理的眼振が出る） | **一方向性**の水平（＋軽い回旋）眼振。速い相の向きを見ると強く、反対を見ると弱まるが向きは変わらない | **注視方向で向きが変わる**（右を見ると右向き、左を見ると左向き）／**垂直性・純回旋性** |
| **TS**：Test of Skew | 交互遮閉：鼻を見てもらい片目を隠し、1–2 秒後に素早くもう片目へ手を移す。左右交互に数回 | 出てきた目に上下の動きなし（**水平の動きは健常人にもあり、skew ではない**） | 出てきた目が **上下（または斜め）に動いて** 戻る（斜偏倚） |
| **Plus**：聴力 | 耳垢がないことを確認し、両耳のすぐ近くで指をこすって左右差を見る | 新規難聴なし | **明らかな左右差があり、本人が新しいと確認した** 片側難聴 |

**catch-up saccade とは**：saccade は目が一瞬で「ピッ」と跳ぶ速い動き。「遅い動き」ではない。

```
正常：頭を右へ → 目は同じ瞬間に左へ回る → 鼻から外れない → 何も見えない
異常：頭を右へ → 目が頭と一緒に右へ流される → 頭が止まった直後に左へピッと戻る
                                                  ↑ これが catch-up saccade
```

**判定**
- 4 つ **全部が末梢** → 末梢パターン（前庭神経炎など）
- **1 つでも中枢** → 中枢として扱う
- 覚え方：**INFARCT** = **I**mpulse **N**ormal / **F**ast-phase **A**lternating / **R**efixation on **C**over **T**est

**根拠**：熟練者（神経眼科医など）が行った研究では、HINTS の脳卒中に対する感度はほぼ 100% で、
発症早期の MRI（DWI）より高かった。ただし ER 医が行うと精度は下がるという報告がある。
**自信がなければ「判定不確実」と書いて MRI・コンサルトへ**。

### 4-3. 落とし穴

- **HIT が正常なのが危険**（直感と逆）。catch-up saccade が出る＝末梢＝安心
- **catch-up が出る側が患側**、眼振の速い相は **患側と反対** を向く（右前庭神経炎なら HIT 右異常＋左向き眼振）。
  向きが合わないときは中枢を疑う
- **AICA 梗塞** は内耳も虚血になるため **HIT が異常（＝末梢に見える）** になる。
  HINTS で末梢と判定された脳卒中は、ほぼすべて AICA 領域（内耳動脈の梗塞、または前庭神経が入る外側橋の梗塞）。
  これを拾うのが **Plus（聴力）**。新規難聴＋めまいは迷路炎もあり得るが、ER では区別できないので中枢として扱う
- 中枢でも **一方向性の水平眼振**（前庭神経炎そっくり）になることがある → 眼振だけで末梢と言わない。**4 項目すべて** 末梢でそろって初めて末梢
- **片側の注視でだけ** 出る眼振（正面・反対側では出ない）は末梢・中枢どちらもあり得る → 決め手にしない
- 端まで見させたときだけ出る・小さい・数拍で消える眼振は **生理的（終末位眼振）**。めまいの人で続く注視眼振は病的として扱う
- skew は感度が低い（Kattah 2009 で 17%）が、あれば脳幹病変を強く示唆。HIT が末梢に見える外側橋梗塞を skew で拾えることがある
- HIT は頭が止まった **直後** の目に注目。頭を回している最中に出る小さな saccade は肉眼では見えない
- 末梢性眼振は **固視で弱まる**。Frenzel 眼鏡があれば眼振の観察に使う
- 鎮静薬・制吐薬の後は眼振が弱まることがある → できれば **投与前に診察**
- 頸椎疾患・頸部外傷では HIT を無理にしない

## 5. Dix-Hallpike

### 5-1. 適応

- **頭位で誘発・1 回 1 分以内** のめまい
- 診察時に **自発眼振がない**（自発眼振がある持続性めまいは HINTS へ）

### 5-2. やり方

1. 長座位で、頭を検査側へ **45° 回す**
2. その向きのまま素早く仰臥位にし、頭をベッドの端から **20° 程度下げる**
3. 目を開けたまま **30–60 秒** 眼振を観察
4. 座位に戻し、**逆向きの眼振** が出るかを見る
5. 反対側も同じように行う

### 5-3. 陽性（後半規管 BPPV）の判定

| ポイント | BPPV の特徴 |
|---|---|
| 潜時 | **数秒** 遅れて出る（多くは 1–5 秒、長くても 20 秒程度） |
| 向き | **上向き（額の方向）＋回旋性**（目の上の極が **下にした耳** へ向かう） |
| 持続 | 多くは **30 秒以内**、長くても **1 分以内** に消える（いったん強まってから弱まる） |
| 座位に戻す | 向きが **逆転** する（下向き＋回旋） |
| 繰り返す | だんだん弱まる（疲労現象） |
| 症状 | めまい感と眼振が **一緒に** 出る |

**コツ**：素早く倒す（ゆっくりだと出にくい）。目を閉じさせない。嘔吐に備える。Frenzel 眼鏡があれば使う。

**下にした側が患側**（右下で陽性なら右後半規管 BPPV）。

### 5-4. 陽性なら Epley 法（右患側の例）

1. 右 Dix-Hallpike の姿勢（頭右 45°・懸垂位）で眼振が止まるまで待つ（30 秒以上）
2. 頭を懸垂位のまま **左へ 90°**（左 45°）回して 30 秒
3. 体ごと左側臥位にし、顔を **床向き** まで回して 30 秒
4. 頭の向きを保ったまま座位に戻し、あごを引く

左患側は左右を逆にする。1 回で残れば繰り返してよい。

### 5-5. Dix 陰性で頭位めまいがある → supine roll test（外側半規管）

- 仰臥位・頭を 30° 挙上した姿勢で、頭を左右へ **90°** 素早く回す
- **水平性** の眼振が出れば外側半規管 BPPV
  - **向地性**（下の耳へ向かう）：眼振が **強い側** が患側。90 秒以内に消える
  - **背地性**（上の耳へ向かう）：眼振が **弱い側** が患側。**長く続くほど中枢を疑う**（中枢性頭位眼振でも出る）
- 治療は Lempert 法（barbecue roll）・Gufoni 法など。結果はテンプレの Dix 欄の（　）に書く

### 5-6. BPPV に見えて中枢を疑うサイン（中枢性頭位眼振）

```
□ 潜時がない / 1 分以上続く / 繰り返しても弱まらない
□ 回旋成分のない純粋な下向き眼振
□ どの半規管でも説明できない向きの眼振
□ 眼振は弱いのに嘔吐が強い
□ 頭痛・神経症状がある
□ 頭位治療を繰り返しても改善しない
→ 1 つでもあれば MRI
```

## 6. HINTS 以外に必ず見る神経所見

### 6-1. 立位・歩行（最重要）

- 支えなしで **座れない・立てない・歩けない** → HINTS が末梢でも中枢を疑う。
  前庭神経炎は片側へ傾いても、たいてい自力で立てる。**眼振がないときはこれが主な判断材料**

| Grade | 状態 | 脳卒中だった割合 |
|---|---|---|
| 0 | 正常 | 0%（0/5） |
| 1 | ふらつくが自力で歩ける | 7%（3/42） |
| 2 | 立位で強くふらつく／支えなしでは歩けない | 28%（11/39） |
| 3 | 支えなしで立てない・倒れる | **100%（28/28）** |

（GRACE-3 Table 3。元は Carmona 2016 の AVS 114 例の 1 研究）

### 6-2. Deadly Ds（6D）＋ Horner・麻痺

めまいの中枢（前庭神経核・小脳）は、ほかの脳神経核や伝導路と **すぐ隣** にある。
そのため後方循環の梗塞では、隣の症状が一緒に出ることがある。**1 つでもあれば中枢**。

| 項目 | 見方 | 異常なら考える部位 |
|---|---|---|
| **複視** Diplopia | 「二重に見えるか」を聞く。指を H 字に追視。片目を隠すと消えるか（消える＝眼球運動の異常） | 脳幹（橋・中脳）。縦にずれるなら skew |
| **構音障害** Dysarthria | 会話を聞く。「パタカ」を繰り返させる | 小脳（とぎれとぎれ・不明瞭）、延髄 |
| **嚥下障害** Dysphagia | 少量の水でむせるか。唾液を飲めず吐き出していないか。軟口蓋の挙上に左右差がないか | 延髄外側（Wallenberg） |
| **嗄声** Dysphonia | 声がかすれていないか | 延髄外側（声帯麻痺） |
| **測定障害** Dysmetria | 指鼻試験・踵膝試験・手の回内回外。左右差を見る | 同側の小脳半球 |
| **感覚障害** Dysesthesia | 顔の両頬と手足を、ピンや冷たい物で左右比較（**温痛覚**）。本人は気づいていないことが多い | 延髄外側：同側の顔＋反対側の体幹・手足（交叉性） |
| **Horner** | 片側の縮瞳・軽い眼瞼下垂。暗くすると瞳孔の左右差が目立つ | 延髄外側（交感神経の通り道） |
| **麻痺** | Barré・Mingazzini。顔面麻痺 | 脳幹。顔面麻痺＋難聴は AICA 領域 |

**よく出る組み合わせ**
- **Wallenberg 症候群**（延髄外側、PICA・椎骨動脈）：めまい・眼振＋同側 Horner＋同側の顔の温痛覚低下＋反対側の体の温痛覚低下＋嚥下障害・嗄声＋同側の失調。**手足の麻痺は出ない**
- **AICA 症候群**（橋外側下部）：めまい＋同側の難聴・顔面麻痺・顔の感覚低下・失調。HIT が末梢に見えるので注意（4-3）

### 6-3. 正常でも脳卒中は否定できない

- 神経所見は **特異度が高いが感度が低い**。あれば中枢、なくても否定できない
  - 四肢の失調（指鼻など）：感度 25%・特異度 98%（GRACE-3 のメタ解析）
  - ER 医の一般的な神経診察：感度 40–73%
- **NIHSS 0 点の後方循環梗塞** はある。NIHSS には歩行・嚥下・Horner・めまいの項目がない
- 小脳虫部（真ん中）の梗塞は **手足の失調が出ず、体幹失調だけ** → だから歩行が最重要
- 結局、**眼の所見（HINTS）＋歩行＋神経所見** を組み合わせて判断する。
  HINTS が末梢でも **立てなければ MRI**（GRACE-3）

### 6-4. そのほか

- **頭痛・後頸部痛** → 椎骨動脈解離を考えて CTA / MRA
- 高齢・高血圧・糖尿病・AF・脳卒中既往は脳卒中の可能性を上げる。ただし若年でも解離はある

## 7. 画像と方針

**画像**
- **CT**：小脳・脳幹の早期梗塞はほとんど写らない。**出血（小脳出血）の除外** にだけ使う
- **MRI（DWI）**：発症 48 時間以内は後方循環梗塞の **1 割以上を見逃す**（小さい梗塞ではさらに多い）。
  HINTS で中枢パターンなら、MRI 陰性でも梗塞として扱い、入院・再検を考える

**方針**

| 結果 | 方針 |
|---|---|
| 末梢パターン＋神経所見なし＋自力歩行可 | 制吐薬など対症療法。飲水・歩行を確認して帰宅、耳鼻科外来。悪化・新しい症状で再診を指示 |
| BPPV（Dix 陽性） | Epley 法 → 帰宅 |
| 中枢パターン・神経所見あり・歩行不可 | MRI（DWI）、神経内科・脳外科へ。MRI 陰性でも入院・再検を考える |
| 発症早期で脳梗塞が強く疑われる | 血栓溶解・血栓回収の適応を考えて脳卒中チームへ（**脳底動脈閉塞** は見逃すと致死的） |
| HINTS に自信がない・適応外だがリスクが高い | MRI またはコンサルト |

**薬**：抗ヒスタミン薬・ベンゾジアゼピンなどの前庭抑制薬は **急性期の数日だけ**。長く使うと前庭代償が遅れる。

## 8. めまい以外の見逃し

「めまい」と言って来る人には、回転性でない **ふらつき・前失神** も混じる。

```
□ 全例：ECG・血糖・起立時のバイタル
□ 不整脈・ACS・大動脈弁狭窄
□ 出血（消化管出血）・貧血・脱水
□ 低血糖・電解質異常
□ CO 中毒（同居家族も同じ症状、冬季・暖房）
□ 薬剤（降圧薬・抗てんかん薬・睡眠薬）
```

## 9. 眼振がないとき

まず **本当に眼振がないか** を確認する。正面だけでなく左右 30° の注視も見る。
末梢性眼振は固視で消えやすいので、Frenzel 眼鏡があれば固視を外して見る。
それでもなければ **型で分ける**。

### 9-1. 持続性なのに眼振なし

```
□ 歩行 Grade（6 章）：Grade 3 → 中枢として扱う / Grade 2 → MRI・コンサルト
□ 神経所見：6D・Horner・麻痺（6 章）
□ 回転性でない（ふらつき・前失神）→ 8 章（ECG・血糖・起立時バイタル・Hb）
□ CT では脳卒中を否定できない
```

Grade 0–1 で神経所見がなく、ほかの原因もなければ低リスク。
ただし Grade 1 でも脳卒中は 0 ではない（7%）→ 血管リスクが多い・症状が強いなら MRI を考える。

### 9-2. 頭位で誘発されるのに眼振なし

- Dix-Hallpike 陰性 → **supine roll test**（5-5）
- それでも眼振なし、でも **片側の頭位でだけ典型的な症状** が出る（subjective BPPV）
  → 症状が出た側に **Epley 法をしてよい**（固視で眼振が見えていないだけのことがある）
- **立ち上がったときだけ** 起こる → 起立性低血圧を考えて起立時バイタル。BPPV は寝返り・臥位でも起こる
- 神経所見あり・頭位治療が効かない → MRI

### 9-3. 発作性で、今は症状がない

診察時に症状がないので、HINTS も Dix も意味がない。**病歴で TIA を探す**。

| | 椎骨脳底動脈系 TIA | 前庭性片頭痛 |
|---|---|---|
| 年齢 | 高齢 | 若い |
| 1 回の長さ | 短い（多くは 1 時間未満） | 長い（多くは 1 時間以上） |
| 始まり方 | 突然 | 突然のことも、徐々のことも |
| 片頭痛の既往 | 少ない | とても多い |
| 発作の回数 | 短い期間に起こる | 長い期間に何度も |
| 血管リスク | 多い | 少ない |
| 頭痛 | 少ない（頸部痛なら椎骨動脈解離） | とても多い |

```
□ 神経所見：視野・眼球運動・指鼻・歩行
□ ECG・モニター（不整脈）
□ TIA が心配 → CT ではなく 頭頸部 CTA / MRA
□ 難聴・耳鳴・耳閉感を伴う発作の反復 → メニエール病 → 耳鼻科
□ 来院時にまだ症状がある → 持続性（AVS）として扱う
```

**注意**
- 後方循環梗塞の約 1 割は、48 時間以内に **めまいだけの発作** が先行している。初回のめまい発作を軽く見ない
- ABCD2 スコアは後方循環 TIA を拾いにくい（C は片麻痺・言語障害の項目）。単独で使わない
- 椎骨動脈解離は若年・血管リスクなしでも起こる
