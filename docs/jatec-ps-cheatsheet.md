# PS（ABCDE）チートシート ── これだけ見る

> **方針**：各項目で見るのは **3〜5 個だけ**。異常があったら **次に進まず、その場で治す**。
> 悪くなったら **A に戻る**。詳しい説明は [JATEC 実践ガイド](jatec-guide.md) へ。

- 対象：ER の外傷初療（Primary Survey）
- 更新日：2026-11-13

---

## 1 枚で

| | 合言葉 | 見ること | 異常なら |
|---|---|---|---|
| **A** | **喋れる？ 音は？** | 発語・変な音 | 吸引 → 下顎挙上 → 挿管 |
| **B** | **首 → 胸 → 聴診 → 触る → SpO₂** | 頸静脈・気管、左右差、呼吸音、皮下気腫、SpO₂ | 脱気・ドレーン・酸素・挿管 |
| **C** | **SHOCK で気づく → FIX-C で治す** | 皮膚・脈・外出血・CRT と意識・血圧 | FAST・静脈路・X 線・止血 |
| **D** | **まいど** | 麻痺・意識（GCS）・瞳孔 | 切迫する D → 挿管・脳外・頭部 CT |
| **E** | **脱がせて、測って、温める** | 全身・体温 | 保温 |

## A：喋れる？ 音は？

**見るのは 2 つだけ**
1. **喋れるか**：名前を言える → **A は OK**
2. **変な音がしないか**
   - ゴロゴロ → 口の中に血や吐物
   - いびき → 舌が落ちている
   - ヒューヒュー（息を吸うときの高い音＝stridor）→ のどが狭くなっている

**異常なら**
- ゴロゴロ → **吸引**
- いびき → **下顎挙上**（頭は後ろに倒さない）
- 治らない・意識が悪い（GCS ≤8）→ **挿管**

**言うこと**：「発語あり、異常音なし、**A 開通**。頸椎保護を続けます」

---

## B：首 → 胸 → 聴診 → 触る → SpO₂

**上から順に 5 つ**
1. **首を見る**：頸静脈が張っていないか（怒張）・気管が真ん中にあるか
2. **胸を見る**：左右同じように動くか・呼吸が速くないか
3. **聴診**：左右の腋窩で呼吸音を比べる（左右差を探す）
4. **触る**：皮下気腫（押すとギュッギュッと雪を握る感じ）
5. **SpO₂**

**異常なら（この 3 つだけ覚える）**

| こう見えたら | 考える | すぐやる |
|---|---|---|
| 片側の呼吸音↓ ＋ **頸静脈怒張** ＋ ショック（気管偏位・皮下気腫があればさらに疑う） | **緊張性気胸** | **X 線を待たずに脱気** → 胸腔ドレーン |
| 片側の呼吸音↓ ＋ ショック ＋ 頸静脈は **張っていない** | **大量血胸** | 胸腔ドレーン ＋ 輸血 |
| SpO₂↓ | 低酸素 | 酸素 10L → 改善しなければ挿管 |

- 頸静脈で区別する：**気胸は張る、血胸（出血）は張らない**
- ここで **胸部 X 線**（ポータブル）を撮る。エコーがすぐ使えれば **E-FAST**（lung sliding・横隔膜の上）でも気胸・血胸を見られる（FAST のやり方 ②' ③' ⑤）

**言うこと**：「頸静脈怒張なし、気管偏位なし、胸郭の動きは左右差なし、呼吸音左右差なし、皮下気腫なし、SpO₂ 98%。**B 問題なし**。胸部 X 線お願いします」

## C：SHOCK で気づく → FIX-C で治す

### SHOCK（ショックに気づく）

| | 英語 | 見ること |
|---|---|---|
| **S** | Skin | 皮膚が **冷たい・じっとり** |
| **H** | Heart rate | 脈が **速い・弱い** |
| **O** | Outer bleeding | **外出血** がある |
| **C** | CRT & Consciousness | 爪を押して戻るまで **2 秒より長い**・**意識がおかしい（不穏も）** |
| **K** | Ketsuatsu（血圧） | **血圧が低い** |

- **1 つでもあればショック** と考えて動く
- **血圧（K）は最後に下がる**。血圧が普通でも、S・H・C があればショック

### FIX-C（C を FIX ＝ 治す）

| | 何をする | ポイント |
|---|---|---|
| **F** | **FAST** | 出血を探す（下の「FAST のやり方」） |
| **I** | **IV**（静脈路） | **2 本**（18G 以上）＋採血。取れなければ骨髄路。**加温輸液 1L** |
| **X** | **X 線** | **胸部と骨盤** の 2 枚 |
| **C** | **Compression**（止血） | 外出血は **圧迫**。骨盤骨折は **骨盤バインダー**（大転子の高さ）。必要なら手術・IVR |

### 輸液 1L のあとの反応で分ける

| 反応 | 意味 | 次 |
|---|---|---|
| 良くなって、そのまま安定（R） | 出血は止まっているかも | 先に進む（見張りは続ける） |
| 良くなるが、また悪くなる（TR） | **出血が続いている** | **輸血**・外科／IVR を呼ぶ |
| 良くならない（NR） | **大出血が続いている** | **輸血＋すぐ止血**（手術・IVR） |

- TR・NR に **輸液を足し続けない**。**輸血と止血**
- 明らかな大出血なら 1L の反応を待たずに輸血

**言うこと**：「皮膚冷感・湿潤あり、脈 120 で弱い、外出血なし、CRT 3 秒、不穏あり、血圧 90/60。**ショックです**。FAST します。静脈路 2 本、加温輸液 1L。胸部・骨盤 X 線お願いします」

## FAST のやり方

**準備**
- プローブは **コンベックス**（腹部用）、プリセットは **腹部／FAST**
- 見るのは **黒い（無エコー）液体があるかどうかだけ**。臓器の損傷は見なくてよい

**順番：心臓 → 右（お腹 → 胸）→ 左（お腹 → 胸）→ 膀胱 →（E-FAST）前胸部**

| 順 | 場所 | プローブの当て方 | 見るところ |
|---|---|---|---|
| ① | **心臓（心窩部）** | 剣状突起のすぐ下。プローブを **寝かせて**、患者の **左肩** に向ける | 心臓のまわりの黒い帯（心嚢液） |
| ② | **右上腹部** | 右の **中腋窩線**、肋骨の間。マーカーは頭側 | **肝臓と腎臓の間**（モリソン窩）の黒い線 |
| ②' | **右胸腔**（血胸） | ②の位置から **肋間 1 つ上** にずらす（または頭側に振る） | **横隔膜**（白く光るカーブ）の **上** に黒い液体がないか |
| ③ | **左上腹部** | 左は右より **上で後ろ**（手の甲がベッドにつくくらい） | **脾臓のまわり**（特に横隔膜との間） |
| ③' | **左胸腔**（血胸） | ③の位置から **肋間 1 つ上** | 横隔膜の上に黒い液体がないか |
| ④ | **膀胱** | 恥骨のすぐ上。横と縦の 2 方向 | 膀胱の **後ろ** の黒い液体 |
| ⑤ | **前胸部**（気胸、E-FAST） | **鎖骨中線の第 2–3 肋間**、プローブは縦（マーカー頭側）。左右両方 | **lung sliding**（下の説明） |

### 肺（胸腔）の見方

**血胸（②' ③'）：横隔膜の上を見る**

| | 正常 | 血胸 |
|---|---|---|
| 横隔膜の上 | 肝臓（脾臓）の **鏡像**（空気で反射して、同じ模様が上にも映る） | **黒い液体** |
| 背骨 | 横隔膜のところで **見えなくなる** | 横隔膜より **上まで背骨が見える**（spine sign） |

**気胸（⑤）：lung sliding を見る**
- 画面に **肋骨 2 本**（影を引く丸い山）と、その間を横に走る **白い線（胸膜）** が見える（コウモリが羽を広げた形）
- 呼吸に合わせて白い線が **キラキラ横に動く** ＝ **lung sliding あり** → その場所に気胸はない
- **動かない** ＝ lung sliding なし → **気胸を疑う**
- できれば M モード：砂浜のように見える（seashore sign）なら正常、**縦じまのバーコード**（barcode sign）なら気胸
- プローブはコンベックスのままでよい（リニアの方がきれいに見える）

**なぜこの場所か**：仰向けでは **空気は前（天井側）**、**血は後ろ・下（背中と横隔膜の上）** に溜まる。だから気胸は前胸部、血胸は横隔膜の上を見る。

**注意**
- lung sliding がなくても気胸とは限らない：**片肺挿管**・息を止めている・胸膜の癒着でも消える
- 皮下気腫が強いと、空気で何も見えない → 「描出不良」と書く

**コツ**
- 左は右より見えにくい → **もっと上・もっと後ろ**
- 膀胱は尿が溜まっている方が見やすい → **尿カテを入れる前に** 見る
- **1 回陰性でも、血圧が変わったらもう一度**（何回目かを記録）
- 書き方は [FAST テンプレ](fast-karte-template.md)

## D：まいど（麻痺・意識・瞳孔）

| | 見ること | やり方 |
|---|---|---|
| **ま** 麻痺 | 手足が左右同じように動くか | 「手を握って」「足を動かして」 |
| **い** 意識 | **GCS**（E・V・M を分けて） | 下の表 |
| **ど** 瞳孔 | 大きさ・左右差・光への反応 | ペンライトで片目ずつ |

**GCS 早見表**

| E（目） | V（言葉） | M（動き） |
|---|---|---|
| 4 自分で開けている | 5 日時・場所がわかる | 6 指示に従う |
| 3 呼ぶと開ける | 4 会話が混乱している | 5 痛い所に手を持ってくる |
| 2 痛みで開ける | 3 言葉だけ（会話にならない） | 4 痛みから手を引っ込める |
| 1 開けない | 2 うめき声だけ | 3 腕を曲げる（異常屈曲） |
| | 1 声が出ない | 2 腕を伸ばす（伸展） |
| | | 1 動かない |

**切迫する D（どれか 1 つで動く）**
- GCS **8 点以下**
- GCS が **2 点以上** 下がった
- **瞳孔の左右差**・**片麻痺**

→ **挿管**・**脳外科コール**・ABC が落ち着いたら **最初に頭部 CT**

- **血糖も測る**（低血糖でも意識が悪くなる）

**言うこと**：「麻痺なし、GCS E4 V5 M6 の 15 点、瞳孔 3 mm 左右差なし、対光反射あり。**切迫する D なし**」

## E：脱がせて、測って、温める

1. **脱がせる**：はさみで切って全部（患者は動かさない）。出血・傷・変形を見る
2. **測る**：体温
3. **温める**：すぐ毛布・加温ブランケットで覆う。濡れた服は取る。部屋を暖める

- 低体温は血を止まりにくくする → **最初から温める**
- 背中は後で log roll で見る

**言うこと**：「全身脱衣、明らかな外出血なし、変形なし。体温 36.2℃。保温します」

## 迷ったら

- **喋れる → A は OK**
- **異常を見つけたら、次の文字に進まず治す**
- **悪くなったら A からやり直す**
- **血圧が普通でもショックはある**（S・H・C を見る）
- **FAST は 1 回で終わりにしない**
