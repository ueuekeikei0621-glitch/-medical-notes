# ECG カルテテンプレ（簡易版）

> **方針**：ER は **コンパクト優先**。所見（O）だけを短く書き、解釈は **アセスメント（A）** へ。
> 一番大事なのは **前回 ECG との比較**。正常値は 3 章、A を書くときの参考は 4〜5 章。

- 対象：成人の 12 誘導 ECG
- 更新日：2026-10-25

---

## 1. テンプレ（コピペ用）

```
【ECG】（症状 有/無）
調律：洞調律 / AF / ペーシング / 不明（　）　HR：　（整/不整）
PR/QRS/QTc：　/　/　ms
ST：変化なし / ↑（　）/ ↓（　）　T：変化なし / 陰転（　）/ 尖鋭化
その他：（Q波・δ波・期外収縮・軸偏位 など）
前回比：著変なし / 変化あり（　）/ 前回なし
```

---

## 2. 記載例

**正常**
```
O：ECG 洞調律 HR 72 整、PR/QRS/QTc 160/90/420ms、ST-T 変化なし。前回と著変なし。
```

**ST 上昇**
```
O：ECG 洞調律 HR 98 整、PR/QRS/QTc 150/96/440ms、ST↑ II・III・aVF（2mm）、ST↓ I・aVL。前回なし。
A：下壁 STEMI 疑い → V4R・循環器コール。
```

**徐脈**
```
O：ECG 調律不明（P–QRS 無関係）HR 38 整、PR/QRS/QTc −/140/480ms。前回は洞調律 HR 70。
A：3 度 AVB → パッド貼付・ペーシング準備。
```

## 3. 正常値（成人）

| 項目 | 正常 | メモ |
|---|---|---|
| HR | 50–100 bpm | <50 徐脈、>100 頻脈 |
| 軸 | −30°〜+90° | I と aVF が両方（＋）なら正常。I（＋）aVF（−）は II（＋）なら正常、II（−）なら左軸偏位 |
| PR | 120–200 ms | >200 で 1 度 AVB、<120 は WPW を疑う |
| QRS | <120 ms | ≥120 で脚ブロック・心室調律・高 K を考える |
| QTc | 男 <450 / 女 <460 ms | **>500 は TdP 高リスク** |
| ST 上昇（STEMI） | 隣接 2 誘導で ≥1 mm | V2–V3 は男 ≥2 mm（<40 歳 ≥2.5 mm）、女 ≥1.5 mm |
| ST 低下 | ≥0.5 mm で有意 | |
| 異常 Q 波 | — | 幅 ≥40 ms または深さ ≥R 波の 1/4 |
| LVH | SV1 + RV5(6) ≥35 mm | Sokolow-Lyon |
| 低電位 | 四肢 <5 mm / 胸部 <10 mm | 心嚢液・肥満・COPD・アミロイドーシス |

## 4. 見逃し注意（ここだけは毎回確認）

```
□ 後壁梗塞：V1–V3 の ST 低下＋高い R → V7–V9 を追加
□ 右室梗塞：下壁 STEMI なら V4R を追加
□ aVR ST 上昇＋広範な ST 低下：LMT／3 枝病変、びまん性虚血
□ de Winter T 波：V1–V6 で上向き ST 低下＋高い T → LAD 閉塞
□ Wellens：V2–V3 の二相性／深い陰性 T → LAD 近位部狭窄
□ 新規 LBBB・ペースメーカ調律：Sgarbossa 基準で評価
□ 高 K：テント状 T → PR 延長・P 消失 → QRS 開大
□ QT 延長：薬剤・低 K・低 Mg を確認
□ WPW：短い PR＋δ 波
□ Brugada 型：V1–V2 で coved 型 ST 上昇
□ 肺塞栓：洞頻脈、右側胸部誘導の T 陰転、S1Q3T3、新規 RBBB
□ 心タンポナーデ：低電位＋電気的交互脈
```

## 5. 調律の見分け方

### 5-1. ER ではまずこれだけ（名前は後でよい）

| 分類 | 主な候補 | 初期対応 |
|---|---|---|
| 脈なし | VF・無脈性 VT／PEA・心静止 | 心停止アルゴリズム |
| 徐脈（HR <50） | 洞徐脈・接合部調律・AVB | 不安定ならアトロピン → ペーシング。薬剤・高 K・下壁梗塞を確認 |
| narrow・整の頻拍 | 洞頻脈・PSVT・AFL（2:1） | 洞頻脈なら原因検索。PSVT なら迷走神経刺激 → ATP |
| narrow・不整の頻拍 | AF・MAT・AFL（変動伝導） | レートコントロール |
| wide・整の頻拍 | **VT として扱う** | 不安定なら同期カルディオバージョン |
| wide・不整の頻拍 | AF＋WPW・多形性 VT（TdP） | AF＋WPW に房室結節抑制薬は禁忌。TdP なら Mg、不安定なら除細動 |

どの分類でも **不安定（低血圧・意識障害・ショック・胸痛・心不全）なら電気的治療を優先**。

### 5-2. 調律の早見表（あとで名前を付けるとき）

| 分類 | 調律 | 見分けるポイント |
|---|---|---|
| 洞性 | 洞調律 | QRS の前に毎回 P、II で陽性 P、HR 50–100 |
| | 洞頻脈 / 洞徐脈 | 洞調律で HR >100 / <50 |
| | 洞不整脈 | 呼吸で RR が変わる（若年者は正常） |
| | 洞停止・洞房ブロック | P が突然抜ける（洞不全症候群） |
| 上室性 | AF | P なし、f 波、RR 完全不整 |
| | AFL | 鋸歯状 F 波（II・III・aVF）、2:1 で HR ≒150 |
| | AT | 洞調律と違う形の P、HR 100–250 |
| | MAT | 3 種類以上の P、不整（COPD に多い） |
| | PSVT | narrow・整・HR 150–250、P が見えないか逆行性 |
| | 接合部調律 | P なし or 逆行性、narrow、HR 40–60 |
| 心室性 | VT | wide（≥120 ms）、HR ≥100 |
| | 多形性 VT・TdP | QRS の向きがねじれる、QT 延長に伴う |
| | VF | QRS 判別不能 → 即除細動 |
| | AIVR | wide、HR 40–100（再灌流後に多い） |
| | 心室補充調律 | wide、HR 20–40 |
| 房室ブロック | 1 度 | PR >200 ms で一定 |
| | 2 度 Wenckebach | PR が延びて QRS が 1 拍抜ける |
| | **2 度 Mobitz II** | PR 一定のまま QRS が突然抜ける → ペーシング考慮 |
| | 高度 AVB | 2 拍以上続けて抜ける |
| | **3 度（完全）** | P と QRS が無関係 → ペーシング考慮 |
| その他 | ペーシング | QRS の前にスパイク |

**書き方**：基本調律 ＋ 期外収縮 ＋ 伝導障害 の順（例：「洞調律、PVC 散発、1 度 AVB」）。
