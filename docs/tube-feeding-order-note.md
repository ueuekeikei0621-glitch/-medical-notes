# 経管栄養の食事変更メモ（指示簿にも書く）

> **ルール**：**経管栄養** を変えたら、食事オーダーだけでなく **指示簿にも書く**。書かないと看護師が動けない。
> **常食（口から食べる普通の食事）は指示簿に書かなくてよい**。食事オーダーだけで済む。

- 対象：入院患者の食事変更（病棟）
- 更新日：2026-11-11

---

## 1. やること（これだけ）

| 食事 | 食事オーダー | 指示簿 |
|---|---|---|
| 常食（経口） | 変える | 書かなくてよい |
| **経管栄養** | 変える | **必ず書く** |

当日中に変えるときは、担当看護師にも口頭で一声かける。

---

## 2. なぜ経管栄養だけ？

**常食は、オーダーだけで完結する**
- オーダー → 栄養科が作って配膳 → 患者が食べる
- メニューが変わっても、看護師のやることは変わらない（配膳するだけ）

**経管栄養は、入れるのが看護師**
- オーダーで届くのは **栄養剤そのもの** だけ
- 看護師は **指示簿を見て** 投与する。何を・何 mL・何回・何時に・速度・白湯の量は指示簿に書いてある
- オーダーだけ変えると、**届いた栄養剤と指示簿が食い違う** → 看護師は自分の判断で変えられない → 医師に確認がとれるまで止まる（＝動けない）
- 考え方は **点滴と同じ**。点滴もオーダーを変えたら指示も変える
- 栄養剤は出てくるルートがバラバラ。**医薬品**（エンシュア・ラコール・エネーボなど）は処方で出て、**食品**（メイバランスなど）は食事オーダーで出る。看護師が 1 か所で確認できるのが指示簿
- 誤嚥・嘔吐・下痢・高血糖のリスクがあるので、量や速度を変えるのは治療を変えるのと同じ

---

## 3. 指示簿に書くこと（コピペ用）

```
【経管栄養】（　/　 朝・昼・夕 〜）
ルート：経鼻胃管（マーキング　cm）/ 胃瘻 / 腸瘻
栄養剤：　　　1回　mL ×　回（　時・　時・　時）
速度：　mL/h（ポンプ 有/無）　または 持続　mL/h
白湯：前後に　mL でフラッシュ　追加　mL ×　回（　時）
体位：投与中〜投与後 30 分は 30° 以上 頭位挙上
投与前：チューブ位置・胃残を確認
中止・コール：嘔吐・腹部膨満・胃残　mL 以上・下痢　回/日 以上
前回：（　）から変更
```

**各行の意味**

| 行 | 書くこと | なぜ |
|---|---|---|
| ルート | 経鼻胃管・胃瘻・腸瘻。経鼻胃管は **マーキング位置**（鼻で何 cm） | 抜けかけ・入りすぎに気づける |
| 栄養剤 | **商品名・1 回量・回数・時間** | 看護師はこれを見て準備する |
| 速度 | 何 mL/h、ポンプを使うか | 速すぎると嘔吐・下痢・誤嚥 |
| 白湯 | フラッシュの量と、追加の水分（量・時間） | 詰まり防止と水分補充（5 章） |
| 体位 | 頭を 30° 以上あげる。投与後もしばらく続ける | 逆流・誤嚥の予防 |
| 投与前 | チューブの位置と胃残（胃に残っている量） | 位置がずれたまま入れると肺に入る |
| 中止・コール | 何があったら止めて呼ぶか。**胃残・下痢は数字で** | 数字がないと看護師が判断できない |
| 前回 | 何から何に変えたか | 変更点がひと目でわかる |

胃残・下痢の基準は病院ごとに違う。病棟の基準に合わせて数字を書く。

**記載例①：いちばん普通（胃瘻・1 日 3 回）**
```
【経管栄養】（11/12 朝〜）
ルート：胃瘻
栄養剤：ラコールNF 1回 400mL × 3回（7・12・18時）
速度：200mL/h（ポンプ有）
白湯：前後に 20mL でフラッシュ　追加 200mL × 2回（10・15時）
体位：投与中〜投与後 30 分は 30° 以上 頭位挙上
投与前：胃残を確認
中止・コール：嘔吐・腹部膨満・胃残 200mL 以上・下痢 3回/日 以上
前回：エンシュア・リキッド 250mL × 3回 から変更
```

**記載例②：開始するとき（少量から増やす）**
```
【経管栄養 開始】（11/12 朝〜）
ルート：経鼻胃管（マーキング 55cm）
栄養剤：ラコールNF
　1日目：1回 100mL × 3回（7・12・18時）50mL/h
　2日目：1回 200mL × 3回 100mL/h
　3日目〜：1回 300mL × 3回 150mL/h
白湯：前後に 20mL でフラッシュ
体位：投与中〜投与後 30 分は 30° 以上 頭位挙上
投与前：マーキング位置・胃残を確認
中止・コール：嘔吐・腹部膨満・胃残 200mL 以上・下痢 3回/日 以上
```
長く食べていない人・低栄養の人は **少量から**（リフィーディング症候群）。開始後は P・K・Mg・血糖を見る。

**その他の書き方**
- 持続投与（ICU・腸瘻など）：`ツインラインNF 20mL/h で持続（ポンプ）、6 時間ごとに白湯 20mL でフラッシュ`
- 半固形栄養剤（胃瘻）：速度ではなく **「シリンジで 10〜15 分かけて」** のように書く

---

## 4. 注意

- **古い指示は中止にする**。新旧 2 つ残すと、どちらに従うか迷って結局動けない
- **いつから** を必ず書く（「明日朝から」など）
- **経管栄養をやめるとき・口から食べる食事に戻すとき** も指示簿を書き換える。経管の指示が残っていると続けてしまう
- 病棟ごとにルールが違うことがある。迷ったら病棟の決まりを優先する

---

## 5. 白湯（さゆ）とは

指示簿で栄養剤と一緒に出てくる **「白湯」** は、**一度沸かしたお湯**（実際は常温〜ぬるめにして使う）。熱いお湯ではない。

**何に使うか**

| 用途 | 内容 |
|---|---|
| 水分の補充 | 栄養剤だけでは水分が足りない。足りない分を白湯で足す |
| フラッシュ | 投与の前後にチューブに流して、詰まりを防ぐ |
| 薄める | 栄養剤に混ぜて薄める（開始直後・下痢のとき など） |
| 薬を溶かす | 簡易懸濁法：薬を **約 55℃ のお湯 20 mL** に入れて 10 分置き、溶かしてから注入 |

**混ぜるか、別に入れるか** は病院・指示による。指示簿に **「混ぜる」「投与前」「投与後」** のどれかをはっきり書く。

**水分が足りなくなる理由**
- 栄養剤の水分は **8 割くらい**（1 kcal/mL の製剤で約 85%）。濃い製剤（1.5〜2 kcal/mL）はもっと少ない
- 1 日に必要な水分はおよそ **30〜35 mL/kg**
- 例：50 kg の人にラコールNF 1,200 mL（1,200 kcal）→ 水分は約 1,000 mL。必要量 1,500〜1,750 mL に対して **500 mL くらい足りない** → 白湯で足す
- 栄養剤を濃い製剤に変えたら、そのぶん白湯を増やす（変更時に白湯も見直す）
