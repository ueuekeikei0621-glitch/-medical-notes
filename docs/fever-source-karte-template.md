# 熱源精査カルテテンプレ（身体診察＋エコー）

> **方針**：ER は **コンパクト優先**。所見（O）だけを書き、解釈は **アセスメント（A）** へ。
> 熱源は **服を全部脱がせて頭から足まで** 見る。背中・臀部・踵・陰部・デバイスを見ないと見逃す。
> エコーは「熱源の当たり」をつけるために使う。詳しい見方は [腹部エコー](aus-karte-template.md)・[心エコー](tte-karte-template.md) のテンプレへ。

- 対象：成人の発熱（熱源がはっきりしないとき、全例の熱源確認）
- 更新日：2026-10-25

---

## 1. テンプレ（コピペ用）

```
【熱源検索】
頭頸部：口腔・歯 / 咽頭・扁桃周囲 / 項部硬直 / 甲状腺圧痛 / 頸部LN　−/＋（　）
胸：呼吸音（清/　）　心雑音 −/＋
腹・背：圧痛（　）Murphy −/＋　CVA叩打痛 右−/＋ 左−/＋　脊椎叩打痛 −/＋
皮膚・四肢：皮疹・発赤・褥瘡・刺し口 / 関節腫脹 / 下腿腫脹　−/＋（全身確認 済/未）
デバイス：なし / あり（　）刺入部発赤 −/＋
エコー：肺（　）心（　）胆（　）腎・膀胱（　）その他（　）
→ 熱源：　/ 不明
```

**書き方のルール**
- 見ていない所は「−」ではなく **「未」**（陰部・直腸診は必要なときだけ）
- 全身の皮膚を見たら **「全身確認 済」**。背中・臀部・踵・陰部まで見たときだけ「済」と書く
- エコーは見た臓器だけ書く。異常がなければ `−`、見えなければ `描出不良`

## 2. 記載例

**閉塞性腎盂腎炎**
```
O：頭頸部−、呼吸音 清、心雑音−、腹部圧痛−、CVA叩打痛 右＋ 左−、脊椎叩打痛−、皮膚−（全身確認 済）、デバイスなし。エコー：右水腎（中等度）、胆−、肺−。→ 熱源：右腎
A：右閉塞性腎盂腎炎疑い → 血培 2 セット・抗菌薬、泌尿器科に緊急ドレナージ相談。
```

**下腿の蜂窩織炎（膿瘍なし）**
```
O：右下腿 発赤・熱感・腫脹＋、痛みは見た目相応、握雪感−。エコー：右下腿 皮下の敷石状変化＋、膿瘍−、筋膜に沿った液体−、DVT−。他の熱源−（全身確認 済）。→ 熱源：右下腿
A：右下腿蜂窩織炎。切開が必要な膿瘍なし。壊死性筋膜炎は否定的だが、痛みが強くなれば再評価。
```

**熱源不明（新しい心雑音あり）**
```
O：頭頸部−、呼吸音 清、心雑音 収縮期 2/6（前回記載なし）、腹部−、CVA叩打痛−、脊椎叩打痛−、皮膚−・刺し口−（全身確認 済）、関節−。エコー：肺−、心 疣贅−（描出やや不良）、胆−、腎−。→ 熱源：不明
A：IE を否定できない → 血培 3 セット（時間をあけて）、TEE を相談。造影 CT で膿瘍を検索。
```

## 3. 部位ごとの見方と考える熱源

| 部位 | 見方 | 考える熱源 |
|---|---|---|
| 口腔・歯 | 歯肉の腫れ・歯の叩打痛 | 歯性感染・口底蜂窩織炎 |
| 咽頭・扁桃周囲 | 口蓋垂の偏位・開口障害・こもった声 | 扁桃周囲膿瘍・咽後膿瘍 |
| 頸部 | 頸部の腫れ・圧痛（胸鎖乳突筋の前） | 頸部膿瘍・**Lemierre 症候群**（咽頭炎後の内頸静脈血栓） |
| 甲状腺 | 甲状腺を押して痛いか | 亜急性甲状腺炎 |
| 項部硬直 | 首を前に曲げる。頭痛があれば jolt accentuation | 髄膜炎。**感度が低いので、陰性でも疑えば腰椎穿刺** |
| 側頭動脈 | 高齢者の頭痛：側頭動脈の圧痛・拍動低下・顎跛行 | 巨細胞性動脈炎 |
| 胸 | 呼吸音の左右差・crackles | 肺炎・膿胸 |
| 心 | **新しい** 心雑音 | 感染性心内膜炎（IE） |
| 手足・眼 | 爪下線状出血・Osler 結節（痛い）・Janeway 斑（痛くない）・眼瞼結膜の点状出血 | IE |
| 腹部 | 圧痛の場所・Murphy・McBurney・肝叩打痛 | 胆嚢炎・胆管炎・虫垂炎・憩室炎・肝膿瘍 |
| 背部 | CVA 叩打痛 | 腎盂腎炎・腎膿瘍 |
| 脊椎 | 棘突起を 1 つずつ叩く | 化膿性脊椎炎・硬膜外膿瘍（MRI） |
| 腸腰筋 | 股関節を伸ばすと痛い（psoas sign） | 腸腰筋膿瘍 |
| 皮膚 | 発赤・熱感・腫脹・水疱・紫斑・褥瘡（仙骨・踵） | 蜂窩織炎・壊死性筋膜炎・褥瘡感染 |
| 刺し口 | **陰部・腋窩・鼠径・頭皮** など隠れた所の黒いかさぶた | つつが虫病・日本紅斑熱 |
| 関節 | 腫脹・熱感・可動時痛 | 化膿性関節炎・偽痛風・痛風 |
| 下肢 | 片側の腫れ・把握痛 | DVT・蜂窩織炎 |
| デバイス | CV・末梢ルート・透析カテ・尿カテ・ペースメーカー・人工関節 | カテ関連血流感染・人工物感染 |
| 陰部・会陰 | 陰嚢・会陰の発赤・腫れ（必要時） | 精巣上体炎・**Fournier 壊疽** |
| 直腸診 | 前立腺の圧痛（**優しく**。強くもまない）・肛門周囲の腫れ | 急性前立腺炎・肛門周囲膿瘍 |
| 内診 | 下腹部痛のある女性（必要時） | PID・卵管卵巣膿瘍 |

## 4. 見逃しやすい熱源（ここだけは毎回確認）

```
□ 服を全部脱がせたか（背中・臀部・仙骨・踵・陰部）
□ 刺し口（陰部・腋窩・鼠径・頭皮）
□ デバイス刺入部（末梢ルートも）
□ 新しい心雑音・IE の末梢所見
□ 脊椎叩打痛（化膿性脊椎炎・硬膜外膿瘍）
□ 痛みが見た目より強い皮膚 → 壊死性筋膜炎
□ 肝硬変＋腹水 → SBP（腹水穿刺）
□ 水腎＋発熱 → 閉塞性腎盂腎炎（緊急ドレナージ）
□ CBD 拡張＋発熱・黄疸 → 胆管炎（ドレナージ）
□ 高齢者の頭痛 → 巨細胞性動脈炎
```

## 5. 熱源エコー

**基本の順番**：肺 → 心 → 胆 → 腎・膀胱 → 腹水。皮膚・関節・下肢は症状がある所だけ。

| 部位 | 見る所見 | 意味・次の一手 |
|---|---|---|
| **肺** | 肝臓のように見える肺（consolidation）＋中の点状の高エコーが呼吸で動く（dynamic air bronchogram） | 肺炎 |
| | 片側だけ限局した B ライン | 肺炎の初期（両側びまん性なら心不全などを考える） |
| | 胸水。隔壁や内部エコーがある | 膿胸を疑う → 胸腔穿刺 |
| **心** | 弁に付いて動く塊 | 疣贅 → IE。**TTE で見えなくても否定できない** → TEE |
| | 心嚢液 | 心膜炎・化膿性心膜炎 |
| | EF・IVC | 敗血症の循環評価（輸液反応・心機能） |
| **胆** | 胆嚢腫大・壁肥厚・sono-Murphy | 胆嚢炎 |
| | CBD 拡張・肝内胆管拡張 | **胆管炎** → ドレナージ |
| **肝** | 肝内の不均一な低エコー域 | 肝膿瘍 → 造影 CT |
| **腎** | 水腎 | **閉塞性腎盂腎炎** → 緊急ドレナージ |
| | 腎内・腎周囲の低エコー域 | 腎膿瘍・腎周囲膿瘍 → 造影 CT |
| **膀胱** | 尿が多く溜まっている | 尿閉 → 導尿 |
| **腹水** | 腹水 | 肝硬変なら **SBP** を疑って腹水穿刺（好中球 ≥250/μL で SBP） |
| **腸管** | 腸管壁の肥厚＋周囲脂肪の高エコー | 憩室炎・虫垂炎 |
| **皮膚・軟部** | 皮下の敷石状（cobblestone）変化 | 蜂窩織炎 |
| | 境界のある低〜無エコー域。押すと中身が動く | **膿瘍** → 切開排膿 |
| | 筋膜に沿った液体・皮下ガス（汚い音響陰影） | **壊死性筋膜炎** → 外科コール |
| **関節** | 関節液の貯留 | 関節穿刺（化膿性関節炎か結晶か） |
| **下肢静脈** | 総大腿静脈・膝窩静脈が押しても潰れない（2 点圧迫法） | DVT |
| **末梢ルート部** | 静脈内の血栓・周囲の液体 | 化膿性血栓性静脈炎 |

**注意**
- 胆嚢・腎・大動脈などの詳しい基準は [腹部エコー](aus-karte-template.md)、心臓は [心エコー](tte-karte-template.md) へ
- 後腹膜（腸腰筋膿瘍）・椎体・深い膿瘍はエコーでは見えにくい → 造影 CT・MRI

## 6. 熱源がわからないとき

1. **血液培養 2 セット**（IE を疑うときは時間をあけて 3 セット）・尿検査・胸部 X 線
2. もう一度 **服を全部脱がせて** 4 章のチェックリストを見直す
3. 高齢・免疫不全・状態が悪い → **造影 CT**（膿瘍・胆道・腎・腸管）
4. 感染以外も考える

| 分類 | 例 |
|---|---|
| 薬剤 | 薬剤熱・悪性症候群・セロトニン症候群 |
| 結晶 | 偽痛風・痛風 |
| 膠原病・血管炎 | 巨細胞性動脈炎・リウマチ性多発筋痛症・成人 Still 病 |
| 内分泌 | 甲状腺クリーゼ・副腎不全 |
| 血栓 | DVT・PE |
| 腫瘍 | 悪性リンパ腫・腫瘍熱 |
| その他 | 輸血後・術後 |

---

## 7. 注意

- 敗血症性ショック・敗血症の可能性が高いときは、**抗菌薬を 1 時間以内**。血液培養は抗菌薬の前に取るが、取るために抗菌薬を大きく遅らせない（SSCG 2021）
- 敗血症のスクリーニングに **qSOFA 単独は使わない**（SSCG 2021）。バイタル全体・意識・乳酸値で判断する
- 髄膜刺激徴候は感度が低い。**陰性でも髄膜炎は否定できない**
- 高齢者・ステロイド使用中・免疫不全では、熱が出にくく所見も乏しい
- 熱源が 1 つ見つかっても、**ほかの熱源を探すのをやめない**（尿路感染と思ったら IE だった、など）
