# TTE カルテテンプレ（心エコー）

> **方針**：ER は **コンパクト優先**。所見（O）だけを書き、解釈は **アセスメント（A）** へ。
> EF は **目視で十分**。計測にこだわらず、大事なのは **前回との比較**。

- 対象：ER の経胸壁心エコー（FoCUS 含む）
- 更新日：2026-10-25

---

## 1. テンプレ（コピペ用）

```
【TTE】（描出 良/不良）
LV：EF　%（目視）　壁運動異常 −/＋（　）
RV：拡大 −/＋（RV/LV　）　D-shape −/＋　TAPSE　mm
心嚢液 −/＋（　mm）　RA/RV 虚脱 −/＋
IVC：　mm　呼吸変動 有/無
弁：高度 MR/AR/AS −/＋　TRPG　mmHg
その他：（Ao 基部径・フラップ・疣贅・血栓・LVH など）
前回比：著変なし / 変化あり（　）/ 前回なし
```

---

## 2. 記載例

**正常**
```
O：TTE EF 60%（目視）壁運動異常−、RV 拡大−、心嚢液−、IVC 12mm 呼吸変動あり、高度弁膜症−、TRPG 20mmHg。前回なし。
```

**右心負荷**
```
O：TTE EF 65% 壁運動異常−、RV 拡大＋（RV/LV 1.2）D-shape＋ TAPSE 12mm、心嚢液−、IVC 24mm 呼吸変動なし、TRPG 45mmHg。前回なし。
A：急性右心負荷 → PE 疑い。造影 CT。不安定なら血栓溶解を検討。
```

**タンポナーデ**
```
O：TTE 心嚢液＋（全周 22mm）RA 虚脱＋ RV 拡張期虚脱＋、IVC 25mm 呼吸変動なし、EF 70%。Ao 基部 34mm、フラップ−。
A：心タンポナーデ → 心嚢穿刺。
```

---

## 3. 異常の目安

| 項目 | 異常 | メモ |
|---|---|---|
| LVEF | <50% で低下、<30% で高度低下 | |
| RV/LV 径比 | >1.0 で高度拡大（正常 <0.6） | 心尖部四腔像、拡張末期 |
| TAPSE | <17 mm | RV 収縮低下 |
| TRPG | >31 mmHg（TR 速度 >2.8 m/s） | 肺高血圧疑い |
| 心嚢液 | 少量 <10／中等量 10–20／大量 >20 mm | 量より **虚脱所見と貯まる速さ** |
| IVC | ≤21 mm＋変動 >50% → RAP 3／>21 mm＋変動 <50% → RAP 15 | それ以外は RAP 8。陽圧換気中は使えない |
| Ao 基部 | >40 mm | |
| E/e′（平均） | >14 | 左房圧上昇 |

---

## 4. ショックのとき

| パターン | LV | RV | 心嚢液 | IVC |
|---|---|---|---|---|
| 循環血液量減少 | 過収縮・内腔が小さい | 小さい | − | 細い・虚脱 |
| 心原性 | 収縮低下 | 正常〜拡大 | − | 拡張 |
| 閉塞性（タンポナーデ） | 過収縮・小さい | 拡張期虚脱 | ＋ | 拡張 |
| 閉塞性（PE） | 過収縮・小さい | 拡大・D-shape | − | 拡張 |
| 分布性（敗血症） | 過収縮〜低下 | 正常 | − | 細い〜正常 |

---

## 5. 見逃し注意

```
□ タンポナーデ：心嚢液＋RA/RV 虚脱＋IVC 拡張 → 心嚢穿刺。外傷・解離・術後を考える
□ A 型解離：Ao 基部拡大・フラップ・新規 AR・心嚢液 → 造影 CT（TTE で否定はできない）
□ 右心負荷：RV 拡大・D-shape・McConnell 徴候 → PE。TRPG >60・RV 壁 >5mm なら慢性も考える
□ 局所壁運動異常：胸痛＋新規の壁運動異常は ACS（ECG 変化がなくても）
□ MI 後の機械的合併症：新規の高度 MR（乳頭筋断裂）・VSD・心嚢液（自由壁破裂）
□ 高度 AS：失神・ショックで考える。血管拡張薬に注意
□ 感染性心内膜炎：TTE で疣贅がなくても、疑いが強ければ TEE
□ 心停止中：脈拍確認の 10 秒以内で終える
```
