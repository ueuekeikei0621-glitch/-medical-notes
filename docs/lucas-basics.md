# LUCAS（機械式の胸骨圧迫装置）のきほん

> [!IMPORTANT]
> **LUCAS ＝ 胸骨圧迫を代わりにやってくれる機械。**
> 疲れない・ずれない圧迫ができる。ただし **付けている間に圧迫を長く止めない**、**ずれていないか見続ける**。

---

## 1. そもそも何？

- **LUCAS（ルーカス）**：胸骨圧迫を **機械が代わりにやる装置**（機械式 CPR 装置）。日本ではストライカー社が扱っている
- 患者の **背中に板（バックプレート）**、胸の上に **アーチ型の本体（上部ユニット）** を付け、**吸盤（吸着カップ）が胸に吸い付いて、押す → 戻す** をくり返す
- たとえ：**疲れない、ぶれない圧迫係のロボット**

**設定（工場出荷時）**

| | 値 |
|---|---|
| 速さ | **毎分 102 回**（設定で 111・120 回にもできる） |
| 深さ | **53 mm**（胸の小さい人は 40–53 mm。設定で 45–53 mm） |
| 押す時間と戻す時間 | 半分ずつ（50%） |
| バッテリ | **約 45 分** |

- 似た装置に、胸にベルトを巻いて締めるタイプ（AutoPulse など）もある

---

## 2. どんなときに使う？

### 使いどころ

| 場面 | なぜ機械がいい |
|---|---|
| **搬送中**（救急車・ストレッチャー・エレベーター） | 動いている上で人が質の高い圧迫をするのは無理で、**危ない** |
| **CPR が長くなる** | 人が疲れて浅くなる。人手が足りない |
| **カテ室**（CPR しながら PCI） | 圧迫しながら治療できる。術者が X 線の中で押さなくてよい |
| **ECPR の準備中**（カニューレを入れる間） | 処置のじゃまをせずに圧迫を続けられる |

### 大事なポイント
- **人がしっかり押せるなら、手でやっても結果（生存率）は変わらない**（大きな臨床試験で差がなかった）
- だから **ルーチンで使う必要はない**。**人が質の高い圧迫を続けにくい・危ないとき** の代わりとして使う（JRC ガイドラインも同じ考え方）

---

## 3. 付け方（7 ステップ）

**大原則：LUCAS を待つ間も、付ける間も、手で圧迫を続ける。止めるのは 2 回だけ（板を入れるとき・本体を付けるとき）、どちらも短く。**

```
① 電源 ON（ケースの中で）       ON/OFF を 1 秒押す → セルフテスト → 緑のランプ（調整モード）
② バックプレート                 圧迫を一瞬止めて、脇のすぐ下に入れる → すぐ再開
③ 上部ユニット                   自分側の脚をカチッ（圧迫は続ける）→ 反対側をカチッ → 引っ張って確認
④ 位置を合わせる                 吸盤の下の縁を、胸骨の下端のすぐ上に
⑤ 高さを合わせる                 吸盤を押し下げて胸に「触れる」まで → 「中断」ボタンで固定
⑥ 開始                           「アクティブ（30:2）」か「アクティブ（連続）」
⑦ 安定用ストラップ               動き出してから、首の後ろに回して締める
```

### ① 電源を入れる
- **ON/OFF ボタンを 1 秒押す** → セルフテスト → **調整ボタンの横の緑のランプ** がつけば準備完了（**調整モード**）
- ケースから出す前に入れておくと早い
- 調整モードのまま 5 分たつと自動で切れる

### ② バックプレート（背中の板）を入れる
- 頭を支えながら、**脇のすぐ下** の高さに入れる
- 入れ方は 2 つ：**肩を持って上半身を少し持ち上げる** か、**体を横に転がす**
- **入れたらすぐ手の圧迫を再開**
- 板の位置が正しいと、あとの位置合わせが早く済む

### ③ 上部ユニット（本体）を付ける
1. **リリースリングを 1 回引いて**、脚の爪が開いていることを確かめて離す
2. 手の圧迫を **続けたまま**、**自分に近い側の脚** を板にはめる
3. 圧迫を止めて、**反対側の脚** をはめる → **カチッ** という音
4. **1 回引っ張って** 外れないことを確認

### ④ 位置を合わせる
- 指で確かめて、**吸着カップの下の縁が、胸骨の下端（みぞおちの骨の端）のすぐ上** に来るようにする
- **手で押すときと同じ場所**（胸の真ん中、胸骨の下半分）
- ずれていたら **支持脚を持って動かす**
- **位置が悪いと、肋骨・内臓のけがが増えて、血も回らない**

### ⑤ 高さを合わせる（開始位置）
1. **調整モード** であることを確認（「1」の横の緑のランプ）
2. 吸着カップを **手で** 押し下げて、**胸に触れるところまで**（**押し込まない**）
3. **「中断」ボタン（2）** を押して、その位置で固定

### コントロールパネルの見方（1 → 2 → 3 の順に進む）

| 番号 | ボタン | 何をする |
|---|---|---|
| — | **緑の電源（ON/OFF）** | 1 秒押す → 音が鳴ってセルフテスト（約 3 秒）→ **自動で「1 調整モード」になる** |
| **1** | **調整**（黄色、カップと下向き矢印） | 吸着カップを **手で上下に動かせる** 状態。**電源を入れた直後はもうこの状態なので、最初は押さなくてよい** |
| **2** | **中断**（‖） | 手で下げた位置を **微調整して固定** する。圧迫中に押すと **圧迫が止まる**（波形チェック・バッテリ交換） |
| **3** | **▶ アクティブ（連続）** | 止まらずに圧迫（挿管後）。緑のランプが毎分 10 回点滅＝換気の合図 |
| **3** | **▶ 30:2 アクティブ（30:2）** | 30 回押して止まる → 換気 2 回（挿管前） |

- **緑の電源ボタンだけでは高さは決まらない**：高さは **自分の手で吸着カップを下げて** 決め、**2 で固定** する
- **自分で 1 を押すのは、やり直すとき**：ずれた・高さが合わない → **1** を押す → カップを手で引き上げて位置を直す → 下げる → **2** → **3**
  - **圧迫中でも、いきなり 1 を押してよい**（押すと圧迫が止まって調整モードになる）。先に 2 で止めてから 1 でもよいが、1 手間増えるだけ
- 施設の設定によっては、カップが自動で高さを合わせる機種もある（工場出荷時は手動）。自分の病院の機械を確認する

### ⑥ 圧迫を始める

| ボタン | いつ | 動き |
|---|---|---|
| **アクティブ（30:2）** | **マスク** で換気しているとき（挿管していない） | 30 回押して止まる → その間に **換気 2 回** |
| **アクティブ（連続）** | **挿管・声門上デバイスのあと**（チューブにバッグをつないで換気） | 止まらずに押し続ける。**緑のランプが毎分 10 回点滅** → その合図で換気 |

> [!TIP]
> 決め手は「バッグか人工呼吸器か」ではなく、**バッグを何につないでいるか**。
> - **マスク** につないでいる → **30:2**（圧迫中に押すと、空気が肺に入らず **胃に入る** → 吐いて誤嚥する）
> - **チューブ** につないでいる → **連続**（カフで気管がふさがれているので、圧迫中でも空気は **肺にだけ入る**）
> - 声門上デバイスで空気が **大きく漏れる** なら、30:2 に戻す

### ⑦ 安定用ストラップ（ずれ止め）
- **LUCAS が動いている状態で** 付ける（付けるために圧迫を止めない）
- 首の後ろにクッション付きのネックストラップを通して、**支持脚のストラップとつないで締める**
- 締めたら、もう一度 **吸盤の位置** を確認
- 治療のじゃまになるなら、あとで付けてよい

## 4. 使っている間

### 波形チェック・除細動

**LUCAS は 2 分たっても勝手に止まらない。自分で止める。**

| モード | 勝手に止まる？ |
|---|---|
| **アクティブ（連続）** | **止まらない**（押し続ける） |
| **アクティブ（30:2）** | 30 回ごとに **約 3 秒だけ** 止まって、自動で再開する。これは **換気 2 回のため**。波形を見るための停止ではない |

- 2 分を知らせる **タイマー（音）** を設定できる機種もあるが、**工場出荷時はオフ**。設定しても **音が鳴るだけで止まらない** → 時間は **記録係が見る**

**2 分ごとの波形チェックの手順**
```
① 「2 分です」→ 「2（‖ 中断）」を押す → 圧迫が止まる（カップは位置を保ったまま）
② 波形を見る（10 秒以内。圧迫中は心電図が乱れて読めない）
   ├ 規則的な波形 → 脈を見る → 脈なし（PEA）→ ③
   ├ 平ら（心静止）                         → ③
   └ VF・VT → ③ で再開してから、充電してショック（LUCAS は動かしたままショックしてよい）
③ 「3（▶）」を押して再開
   ・挿管後  → ▶（連続）
   ・挿管前  → ▶ 30:2
```

- **止めるのは「2（‖）」**。**「1（調整）」や電源ボタンで止めない**
  - 1 を押すとカップの固定が外れて、**位置合わせからやり直し** になる
  - 電源を切ると、**セルフテストからやり直し** になる
- **心拍が戻ったら（ROSC）**：▶ を押さず、**中断のまま**。また止まったらすぐ ▶ で再開できる
- ショックのあとは、カップが **ずれていないか** 確認する
- 除細動パッドは **LUCAS を付ける前に貼ってもよい**。パッドとケーブルは **吸着カップの下に入れない**

### 挿管
- **LUCAS を動かしたまま** 挿管する（ビデオ喉頭鏡があると楽）
- 止めるなら、チューブを通す一瞬だけ **「中断」** → 入ったら **「アクティブ（連続）」** で再開（30:2 のままにしない）
- 換気は CPR 中は基本 **バッグで 6 秒に 1 回**（人工呼吸器を使うときの注意は「ICLS のきほん」の気道の章）

### ずれを見張る
- **ずれやすいとき**：**患者を動かしたあと**・**除細動のあと**・ストラップがゆるいとき
- ずれたら **すぐ「調整」ボタン** → 位置と高さを直す → 「中断」で固定 → アクティブで再開
- 胸に **エコーのジェルが残っていると吸盤がずれやすい** → 拭いておく

### バッテリ
- 約 45 分もつ。**黄色のランプが点滅＋アラーム** → 残り約 10 分
- **予備のバッテリをケースに入れておく**
- 交換は「中断」→ 抜く → 新しいのを入れる → 緑のランプ → アクティブで再開
- **60 秒以内に交換すれば、位置を覚えている**（それ以上かかると位置合わせからやり直し）

### 患者を運ぶとき
- **患者ストラップ** で腕を LUCAS に固定できる（**ストラップを持って持ち上げない**）
- LUCAS と患者が搬送具にしっかり固定され、位置と角度が保たれていれば、運びながら使える
- 本体とバッテリは **熱くなる**（48℃ 以上になることがある）

## 5. 使えない人（合わないとき）

| | 見分け方 | どうする |
|---|---|---|
| **体が大きすぎる** | 胸を押さずに本体を板にはめられない | **すぐ手の圧迫に戻る** |
| **体が小さすぎる** | 吸盤を下げると **短い音が 3 回** 鳴って、中断・アクティブにできない | **すぐ手の圧迫に戻る** |
| 位置がうまく合わない | — | 手の圧迫に戻る |

- 目安：**胸の厚み（胸骨の高さ）170–303 mm**、**胸の幅 449 mm まで**。**体重は関係ない**
- **成人用**（子どもには使わない）

## 6. よくある落とし穴

| 落とし穴 | 正しくは |
|---|---|
| LUCAS の準備中に手の圧迫を止める | 待つ間も付ける間も **手で押し続ける** |
| 付けるのに何十秒も止まる | 止めるのは **2 回だけ**、どちらも短く。練習しておく |
| 付けたら安心して見なくなる | **ずれ**（移動・除細動のあと）を見続ける |
| 挿管後も 30:2 のまま | 挿管したら **アクティブ（連続）** |
| 圧迫したまま波形を見る | **「中断」を押してから** 見る |
| 予備バッテリがない | **必ずケースに予備** |
| LUCAS を付けたら終わり | リーダーは **原因検索（5H5T）・薬・時間管理** を続ける |

---

## 7. ICLS の中での位置づけ

- LUCAS は **「胸骨圧迫係」を機械に替える** だけ。ICLS の流れ（2 分ごとの波形チェック・ショック・薬・原因検索）は **何も変わらない**
- 波形チェックは「中断」ボタン、ショックは動かしたままでもよい
- 浮いた人手を、**ルート・薬・原因検索・記録** に回せる
