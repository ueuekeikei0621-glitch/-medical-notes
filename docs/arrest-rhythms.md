# 心停止の波形の見方（かんたん版）

> [!IMPORTANT]
> 見るのは **2 分ごとの中断のときだけ**（圧迫中は揺れで読めない）。
> 決めることは 1 つ：**ショックするか、しないか**。

---

## 1. 4 つの形

```
VF（心室細動）        ∿/\_/\/∿\_/\∿/\/\_∿     ぐちゃぐちゃ・不規則          → ショック
無脈性 VT（心室頻拍）  /\/\/\/\/\/\/\/\/\     幅広い波が速く・規則正しく     → ショック
心静止               _____________________   ほぼ平ら                     → ショックしない
PEA                 _/\____/\____/\____     波はある（普通っぽくても）が脈なし → ショックしない
```

| 形 | 見た目 | ショック | その次 |
|---|---|---|---|
| **VF** | **ぐちゃぐちゃ**、規則的な波がない | **する** | すぐ圧迫 |
| **無脈性 VT** | **幅の広い波が、速く、規則正しく** 並ぶ | **する** | すぐ圧迫 |
| **心静止** | **ほぼ平ら** | しない | すぐ圧迫・アドレナリン |
| **PEA** | **規則的な波がある** のに **脈がない** | しない | すぐ圧迫・アドレナリン・**原因（5H5T）** |

---

## 2. 波形チェックの流れ（10 秒）

```
止める → 波形を見る
  ├ ぐちゃぐちゃ（VF）           → 脈は触らない → ショック → すぐ圧迫
  ├ 速い幅広（VT）               → 脈を触る（10 秒以内）→ 脈なし → ショック → すぐ圧迫
  │                                               （脈あり → 心停止ではない。頻脈の対応）
  ├ 平ら                         → 「接続・感度・誘導」を確認 → それでも平ら → 心静止 → すぐ圧迫
  └ 規則的な波（普通っぽい・ゆっくり幅広い）→ 脈を触る
        ├ 脈あり → ROSC
        └ 脈なし → PEA → すぐ圧迫
```

- **脈を触るのは「規則的な波」があるときだけ**
- **VT か PEA か・ROSC か** は、波形ではなく **脈** で決める
- **VF は脈を触らない**（VF で脈がある人はいない）→ 見たらすぐショック
- **VT は脈ありのこともある** → 中断中に脈も触る。**はっきりしなければ脈なし** としてショック

---

## 3. 平らなとき（細かい VF を見逃さない）

1. **接続**：電極・パッド・コードが外れていないか
2. **感度** を上げる（×1 → ×2・×4）
3. **誘導** を変える（または 2 つの誘導を並べて表示しておく）

- **定規で引いたようにまっすぐ** → 外れを疑う（本当の心静止は少し揺れる）
- それでも **VF か心静止か迷う** → ショックせず圧迫、次の 2 分でもう一度見る

---

## 4. 間違えやすい波形

| 見え方 | 本当は | どうする |
|---|---|---|
| 圧迫中のギザギザ | 圧迫の揺れ（アーチファクト） | **止めて見る** |
| ねじれるように大きさが変わる速い波（トルサード） | **多形性 VT** | 脈なし → **ショック**（＋マグネシウム） |
| ゆっくりで幅の広い波（1 分に数回） | **PEA**（瀕死の心臓の波） | 脈なし → 圧迫・アドレナリン |
| P 波だけで QRS がない | **心静止** として扱う | 圧迫・アドレナリン |
| ペースメーカーの鋭い線（スパイク）だけ | 心臓は動いていないことがある | 脈を見る。なければ PEA・心静止として扱う |

---

## 5. 見る画面

- **自分の病院**：波形チェックは **ベッドサイドモニター**（心電図の電極）
- ショックは **除細動器**（パッド）。VF に見えたら **除細動器の画面（パッド誘導）でも確認**
- 前もって **2 つの誘導を並べて表示**・**感度の上げ方** を知っておく
