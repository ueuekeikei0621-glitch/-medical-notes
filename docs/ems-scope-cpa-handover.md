# 救急隊ができること・心停止の引き継ぎ

> [!IMPORTANT]
> **救急隊（市民の AED も）のショックと薬は、全部数える。**
> 心臓は、誰がショックしたかを知らない。蘇生は病院に着いても **リセットされず、続き** から。

---

## 1. 救急隊の 2 種類

| | 救急隊員 | **救急救命士**（国家資格） |
|---|---|---|
| できること | 観察・酸素・BVM・**胸骨圧迫**・**AED**・吸引・止血・固定 など | 左に加えて **特定行為**（下の表） |
| 条件 | — | 多くは **医師の指示が必要**（電話などで病院の医師に指示をもらう＝メディカルコントロール） |

- 救急車には、救急救命士が **1 人以上乗っていることが多い**
- 2021 年の法改正で、救急救命士は **病院の救急外来の中でも**（入院するまで）救急救命処置ができるようになった

---

## 2. 救急救命士の特定行為

| 対象 | できること | 備考 |
|---|---|---|
| **心停止** | **器具を使った気道確保**（声門上デバイス：ラリンゲアルチューブ・ラリンゲアルマスクなど） | 最初からできた行為 |
| **心停止** | **気管挿管** | **認定を受けた人だけ**。ビデオ喉頭鏡を使える人もいる |
| **心停止** | **静脈路確保・輸液**（乳酸リンゲル液） | 最初からできた行為 |
| **心停止** | **アドレナリン投与** | **認定を受けた人だけ** |
| 心停止の前（ショックなど） | 静脈路確保・輸液 | 認定（処置範囲の拡大） |
| 低血糖が疑われる意識障害 | **血糖測定・ブドウ糖投与** | 認定（処置範囲の拡大） |
| アナフィラキシー | **エピペン**（処方されている人） | — |

**除細動**：**AED（半自動式除細動器）** で行う。医師の個別の指示なしでできる。

### 救急隊ができないこと（病院でやること）
- **抗不整脈薬**（アミオダロン・ニフェカラント・リドカイン）
- 自分で波形を読んでショックする **手動の除細動**・ペーシング
- **脱気・胸腔ドレーン・心嚢穿刺・輪状甲状靱帯切開**
- 鎮静薬・鎮痛薬・昇圧薬
- 骨髄路（救急救命処置に含まれていない）

> [!NOTE]
> 細かい範囲（アドレナリンの回数の上限など）は **地域のメディカルコントロール（MC）プロトコル** で決まっている。自分の地域のものを確認する。

## 3. 救急隊のショック・薬は数えるか？ → 数える

| 何を | どう数える | なぜ |
|---|---|---|
| **ショック**（市民の AED・救急隊の AED も） | **合計回数** に入れる | アミオダロンを使うかは **ショックの合計回数** で決まる（3 回以上で VF・VT が続く → アミオダロン） |
| **アドレナリン** | **回数と最後の時刻** を聞く | 次のアドレナリンは **前回から 3–5 分後**（回数ではなく **時間** で決める） |
| 気道・ルート | 何が入っているか | 入れ直しで圧迫を止めない |

### 例
救急隊：**AED 2 回**、**アドレナリン 1 回（10:20）**。10:25 に到着、波形は VF。

```
到着 10:25 → VF → ショック（合計 3 回目）→ すぐ圧迫
   → アミオダロン 300 mg（3 回ショックしても VF が続いているので）
   → アドレナリン：前回 10:20 から 5 分 → 今入れてよい
```

- **「病院では 1 回目」と数え直さない**。数え直すと、アミオダロンが遅れ、アドレナリンが早すぎたり重なったりする

---

## 4. 心停止の引き継ぎで聞くこと

**到着したら、圧迫を続けたまま、短く聞く**（リーダーか記録係が聞く。聞く間も圧迫は止めない）。

```
□ 時刻：倒れた（目撃）時刻・通報・救急隊の接触・CPR 開始
□ 目撃：あり／なし
□ バイスタンダー CPR：あり／なし、市民の AED：使った／ショック回数
□ 初期波形：VF・VT／PEA／心静止
□ ショック回数（市民の AED＋救急隊の AED）と最後の時刻
□ アドレナリン：回数と最後の時刻
□ 気道：BVM／声門上デバイス／挿管
□ ルート：場所・輸液
□ 途中で心拍が戻ったか（一時的な ROSC）
□ LUCAS：付けた時刻（バッテリは約 45 分）
□ 病歴・内服・DNAR（家族から聞けたか）
```

**引き継ぎの例（救急隊の言い方）**
> 「70 代男性、自宅で倒れるのを家族が目撃、10:05 です。家族が胸骨圧迫。10:12 接触、初期波形 VF。
> AED 2 回、最終 10:18。アドレナリン 1 回、10:20。ラリンゲアルチューブ挿入、左前腕にルート。
> 経過中 ROSC なし。既往は心筋梗塞」

---

## 5. 引き継いだあとの注意

| こと | どうする |
|---|---|
| **声門上デバイス**が入っている | **カプノの波形と胸の上がり** を確認。換気できていれば **すぐ入れ替えなくてよい**（入れ替えるなら圧迫を止めずに） |
| 救急隊の **ルート** | 漏れていないか確認。細ければ太いルートを追加 |
| 救急隊の **LUCAS** が付いている | ずれていないか確認（搬送でずれやすい） |
| ストレッチャーから **ベッドへ移す** | 移す瞬間だけ止めて、**すぐ再開**。移動の前後で圧迫の中断を短く |
| 救急隊の **AED パッド** | 病院の除細動器のパッドに貼り替える（機種が合えばそのまま使えることもある） |
