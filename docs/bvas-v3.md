# BVAS v3（Birmingham Vasculitis Activity Score version 3）まとめ

> **一言で**：全身性血管炎の **疾患活動性** を臓器別チェックリストで数値化する国際標準スコア。
> **診断基準ではない**。ただし 9 臓器系統・56 項目を網羅するため、
> ANCA 関連血管炎（GPA / MPA / EGPA）疑い患者の **問診・身体診察の漏れ防止チェックリスト** としても使える。

- 対象：成人の全身性血管炎（特に ANCA 関連血管炎）
- 想定読者：研修医・内科（リウマチ / 腎臓 / 呼吸器）
- 更新日：2026-10-05
- ⚠️ 点数は原典（Mukhtyar 2009）および公式フォームで必ず確認すること

## 1. BVAS とは

### 1-1. 位置づけ
- 血管炎の **活動性（いま炎症が起きているか）** を評価するスコア
- **ダメージ（不可逆な後遺症）** は評価しない → VDI を使う
- **診断・分類** には使わない → 厚労省 指定難病 44 診断基準 / 2022 ACR/EULAR 分類基準を使う
- 主要な AAV 臨床試験（RAVE、RITUXVAS、PEXIVAS、ADVOCATE など）で効果判定に使用

### 1-2. 歴史
| 年 | 版 | 内容 |
|---|---|---|
| 1994 | 初版（Luqmani ら、英国 Birmingham） | 全身性血管炎の活動性を初めて数値化 |
| 1997 | v2 | 項目改訂 |
| 2001 | BVAS/WG | GPA（旧 Wegener 肉芽腫症）専用の改変版（Stone ら） |
| 2009 | **v3**（Mukhtyar ら、EUVAS） | 現行標準。妥当性検証済み、用語集（glossary）付き |

---

## 2. 採点ルール

1. **血管炎による所見のみ** チェックする
   - 感染症・薬剤副作用・併存症・過去の血管炎による固定障害（ダメージ）で説明できるものは **チェックしない**
2. **評価期間は直近 4 週間**
3. 各項目は 2 種類のどちらかでチェック
   - **New / Worse（新規・悪化）**：直近 4 週間で新たに出現 or 悪化
   - **Persistent（持続）**：以前からあり、直近 4 週間も続いている（新規・悪化ではない）
4. **「すべての所見が持続」のときだけ Persistent 欄で採点**する
   - 1 つでも新規・悪化があれば、全体を New / Worse 欄で採点
5. 各臓器系統には **上限点** があり、項目の合計がそれを超えても上限で打ち止め
6. 最大スコア：**New / Worse 63 点、Persistent 33 点**
7. 項目の定義は **公式 glossary** に従う（例：発熱 ≥38.0℃、体重減少 ≥2 kg など）

## 4. 臨床での使い方：GPA 疑い患者のチェックリストとして

BVAS の項目を **上から順に問診 → 診察 → 検査で埋めていく** と、全身の血管炎所見を漏れなく拾える。

| 臓器 | 問診で聞く | 診察で見る | 検査で確認 |
|---|---|---|---|
| 全身 | 発熱、体重減少、筋痛、関節痛 | 体温、関節腫脹 | CRP |
| 皮膚 | 皮疹、潰瘍 | 下腿の触知性紫斑、潰瘍、壊疽 | （皮膚生検） |
| 粘膜・眼 | 口内炎、眼痛・充血、見えにくさ | 口腔潰瘍、強膜炎、眼球突出 | 眼科診察 |
| 耳鼻咽喉 | 鼻出血・痂皮・鼻閉、難聴、耳漏、嗄声 | 鼻腔、鞍鼻、鼓膜、吸気性喘鳴 | 副鼻腔 CT、聴力検査、耳鼻科内視鏡 |
| 胸部 | 咳、血痰、息切れ | 呼吸音、SpO₂ | 胸部 CT（結節・空洞・肺胞出血） |
| 心血管 | 胸痛、息切れ、むくみ | 脈拍の左右差、心雑音 | 心電図、心エコー |
| 腹部 | 腹痛、血便 | 腹膜刺激徴候 | （造影 CT） |
| 腎 | 血尿、泡尿、むくみ | 血圧、浮腫 | 尿沈渣、尿蛋白、Cr の推移 |
| 神経 | しびれ、脱力、頭痛 | 下垂足・下垂手、神経分布に沿った感覚低下 | 神経伝導検査 |

ポイント：
- GPA では **耳鼻咽喉・胸部・腎（ELK）** の項目を特に丁寧に
- 「血管炎によるものか？」を毎項目で自問する（感染症・薬剤を除外）

## 5. 寛解・再燃の定義での使われ方

| 状態 | BVAS での扱い（EULAR/EUVAS などの一般的な定義） |
|---|---|
| 寛解（Remission） | **BVAS = 0**（活動性所見なし） |
| 活動性あり | BVAS ≥1 |
| 再燃（Relapse） | 寛解後に活動性所見が再出現 |
| 重症再燃（Major relapse） | 生命・臓器を脅かす所見の再出現（肺胞出血、腎機能悪化など） |

※ 試験ごとに定義が細かく異なるので、論文を読むときは各試験の定義を確認。

## 6. 注意点・限界

- **診断ツールではない**：高得点でも血管炎とは限らない
- **帰属判断が主観的**：「血管炎による所見か」の判断で評価者間のばらつきが出る → glossary を見ながら採点、トレーニング推奨
- **ダメージと活動性の区別が難しい**：鞍鼻・慢性腎臓病・難聴などの固定障害は VDI 側
- **重症度 ≠ 点数**：点数よりも **どの臓器が侵されているか**（肺胞出血、急速進行性腎炎など）が治療方針を左右
- **時間がかかる**：日常診療では全項目採点しない施設も多い

## 7. 関連スコア

| スコア | 何を測る | 備考 |
|---|---|---|
| **BVAS/WG** | GPA の活動性 | GPA 専用。major / minor 項目に分類。RAVE 試験などで使用 |
| **VDI**（Vasculitis Damage Index） | 不可逆な臓器ダメージ | 発症後 3 か月以上続く障害をカウント |
| **FFS**（Five Factor Score, 2009 改訂版） | 予後 | 年齢 >65 歳、心病変、消化管病変、腎機能障害（Cr ≥150 µmol/L）、ENT 病変なし（GPA / EGPA） |
